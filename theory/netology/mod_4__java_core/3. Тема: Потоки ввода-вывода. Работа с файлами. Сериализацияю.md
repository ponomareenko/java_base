# Тема: Потоки ввода-вывода. Работа с файлами. Сериализация

## File

**Определение:**

`File` — это класс из пакета `java.io`, который используется для работы с информацией о файлах и каталогах.

Важно: объект `File` сам по себе не создаёт файл или папку на диске. Он только описывает путь к файлу или каталогу.

Чтобы реально создать файл или каталог, нужно вызвать специальные методы, например `createNewFile()` или `mkdir()`.

**Пример:**

```java
File directory = new File("SomeDir");
File file = new File(directory, "notes.txt");

System.out.println(file.getName()); // notes.txt
System.out.println(file.getParent()); // SomeDir
```

## Каталог

**Определение:**

Каталог — это папка в файловой системе, внутри которой могут находиться файлы и другие каталоги.

В Java каталог тоже описывается объектом класса `File`.

Проверить, является ли объект каталогом, можно методом `isDirectory()`.

**Пример:**

```java
File directory = new File("SomeDir");

if (directory.isDirectory()) {
    System.out.println("Это каталог");
}
```

---

## mkdir()

**Определение:**

`mkdir()` — это метод класса `File`, который создаёт каталог на диске.

Метод возвращает `true`, если каталог был успешно создан, и `false`, если создать его не удалось.

**Пример:**

```java
File directory = new File("SomeDir");

if (directory.mkdir()) {
    System.out.println("Каталог создан");
}
```

---

## createNewFile()

**Определение:**

`createNewFile()` — это метод класса `File`, который создаёт новый файл на диске.

Метод возвращает `true`, если файл был создан, и `false`, если файл уже существует.

Метод может выбросить `IOException`, поэтому его нужно вызывать внутри `try-catch` или пробрасывать исключение выше.

**Пример:**

```java
File file = new File("notes.txt");

try {
    if (file.createNewFile()) {
        System.out.println("Файл создан");
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## exists()

**Определение:**

`exists()` — это метод класса `File`, который проверяет, существует ли файл или каталог по указанному пути.

Возвращает `true`, если объект существует, и `false`, если его нет.

**Пример:**

```java
File file = new File("notes.txt");

if (file.exists()) {
    System.out.println("Файл существует");
} else {
    System.out.println("Файл не найден");
}
```

---

## listFiles()

**Определение:**

`listFiles()` — это метод класса `File`, который возвращает массив объектов `File`, находящихся внутри каталога.

С его помощью можно получить список файлов и папок внутри директории.

**Пример:**

```java
File directory = new File("SomeDir");

if (directory.isDirectory()) {
    for (File item : directory.listFiles()) {
        System.out.println(item.getName());
    }
}
```

## Поток ввода-вывода

**Определение:**

Поток ввода-вывода — это последовательная передача данных между источником и программой.

Источник может быть разным:

* файл;
* сеть;
* память;
* другой поток данных.

В Java данные обычно передаются как последовательность байтов или символов.

**Пример:**

```java
try (FileInputStream inputStream = new FileInputStream("notes.txt")) {
    int data = inputStream.read();

    System.out.println(data);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## Байтовый поток

**Определение:**

Байтовый поток — это поток, который работает с данными как с последовательностью байтов.

Байтовые потоки подходят для работы с бинарными файлами:

* изображениями;
* архивами;
* видео;
* аудио;
* файлами любого формата.

Основные базовые классы для байтовых потоков:

* `InputStream`;
* `OutputStream`.

**Пример:**

```java
try (FileInputStream inputStream = new FileInputStream("image.png")) {
    int byteData;

    while ((byteData = inputStream.read()) != -1) {
        System.out.println(byteData);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## Символьный поток

**Определение:**

Символьный поток — это поток, который работает с данными как с последовательностью символов.

Символьные потоки удобнее использовать для текстовых файлов, потому что они работают с `char`, а не просто с байтами.

Основные базовые классы для символьных потоков:

* `Reader`;
* `Writer`.

**Пример:**

```java
try (FileReader reader = new FileReader("notes.txt")) {
    int character;

    while ((character = reader.read()) != -1) {
        System.out.print((char) character);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## InputStream

**Определение:**

`InputStream` — это абстрактный класс для чтения байтовых данных.

Он является базовым классом для других потоков ввода, например:

* `FileInputStream`;

```java
InputStream inputStream = new FileInputStream("notes.txt");
```

## OutputStream

**Определение:**

`OutputStream` — это абстрактный класс для записи байтовых данных.

Он является базовым классом для других потоков вывода, например:

* `FileOutputStream`;
* `BufferedOutputStream`;
* `ByteArrayOutputStream`;
* `ObjectOutputStream`.

**Пример:**

```java
OutputStream outputStream = new FileOutputStream("notes.txt");

outputStream.write(65);

outputStream.close();
```

## FileInputStream

**Определение:**

`FileInputStream` — это класс для чтения байтов из файла.

Чаще всего используется для работы с бинарными файлами. Для обычного текста чаще удобнее использовать `FileReader` или `BufferedReader`.

**Пример:**

```java
try (FileInputStream inputStream = new FileInputStream("notes.txt")) {
    int data;

    while ((data = inputStream.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## FileOutputStream

**Определение:**

`FileOutputStream` — это класс для записи байтов в файл.

Если файл не существует, он может быть создан автоматически.

По умолчанию файл перезаписывается. Если нужно дозаписывать данные в конец файла, используется параметр `append`.

**Пример:**

```java
String text = "Hello world!";
byte[] bytes = text.getBytes();

try (FileOutputStream outputStream = new FileOutputStream("notes.txt")) {
    outputStream.write(bytes);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## append

**Определение:**

`append` — это режим дозаписи данных в конец файла.

Если `append` равен `true`, новые данные добавляются в конец файла.

Если `append` равен `false`, старое содержимое файла перезаписывается.

**Пример:**

```java
String text = "New line";
byte[] bytes = text.getBytes();

try (FileOutputStream outputStream = new FileOutputStream("notes.txt", true)) {
    outputStream.write(bytes);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## close()

**Определение:**

`close()` — это метод, который закрывает поток и освобождает связанные с ним ресурсы.

Потоки нужно закрывать, потому что они могут занимать системные ресурсы: файл, сетевое соединение, буфер в памяти.

В современном Java-коде чаще используют `try-with-resources`, чтобы не закрывать поток вручную.

**Пример:**

```java
FileInputStream inputStream = null;

try {
    inputStream = new FileInputStream("notes.txt");
    System.out.println(inputStream.read());
} catch (IOException exception) {
    System.out.println(exception.getMessage());
} finally {
    try {
        if (inputStream != null) {
            inputStream.close();
        }
    } catch (IOException exception) {
        System.out.println(exception.getMessage());
    }
}
```

---

## try-with-resources

**Определение:**

`try-with-resources` — это конструкция Java, которая автоматически закрывает ресурсы после завершения блока `try`.

Она работает с объектами, которые реализуют интерфейс `AutoCloseable` или `Closeable`.

В продакшене это основной способ работы с файлами и потоками, потому что он уменьшает риск забыть закрыть ресурс.

**Пример:**

```java
try (FileInputStream inputStream = new FileInputStream("notes.txt")) {
    int data;

    while ((data = inputStream.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## Closeable

**Определение:**

`Closeable` — это интерфейс для объектов, которые можно закрыть методом `close()`.

Потоки ввода-вывода реализуют этот интерфейс, поэтому их можно использовать в `try-with-resources`.

**Пример:**

```java
try (FileInputStream inputStream = new FileInputStream("notes.txt")) {
    System.out.println(inputStream.read());
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## AutoCloseable

**Определение:**

`AutoCloseable` — это интерфейс для объектов, которые могут автоматически закрываться после использования.

`Closeable` наследуется от `AutoCloseable`.

Именно благодаря этому потоки можно использовать внутри `try-with-resources`.

**Пример:**

```java
try (FileWriter writer = new FileWriter("notes.txt")) {
    writer.write("Hello");
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## Буферизация

**Определение:**

Буферизация — это использование промежуточной области памяти для временного хранения данных при чтении или записи.

Без буфера программа может часто обращаться к диску маленькими порциями. Это медленнее.

С буфером данные читаются или записываются крупными блоками, поэтому работа с файлами становится быстрее.

**Пример:**

```java
try (BufferedInputStream inputStream = new BufferedInputStream(
        new FileInputStream("notes.txt"))) {

    int data;

    while ((data = inputStream.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## BufferedInputStream

**Определение:**

`BufferedInputStream` — это класс, который добавляет буфер к байтовому потоку ввода.

Он не читает данные напрямую по одному байту с устройства каждый раз, а сначала накапливает блок данных в памяти.

Это повышает производительность чтения.

**Пример:**

```java
try (BufferedInputStream inputStream = new BufferedInputStream(
        new FileInputStream("notes.txt"))) {

    int data;

    while ((data = inputStream.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## BufferedOutputStream

**Определение:**

`BufferedOutputStream` — это класс, который добавляет буфер к байтовому потоку вывода.

Он временно накапливает байты в памяти и записывает их в файл более крупными порциями.

**Пример:**

```java
String text = "Hello world!";
byte[] bytes = text.getBytes();

try (BufferedOutputStream outputStream = new BufferedOutputStream(
        new FileOutputStream("notes.txt"))) {

    outputStream.write(bytes);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## FileReader

**Определение:**

`FileReader` — это класс для чтения символов из текстового файла.

Он удобнее для работы с текстом, чем `FileInputStream`, потому что читает символы, а не просто байты.

**Пример:**

```java
try (FileReader reader = new FileReader("notes.txt")) {
    int character;

    while ((character = reader.read()) != -1) {
        System.out.print((char) character);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## FileWriter

**Определение:**

`FileWriter` — это класс для записи текста в файл.

Он работает с символами и строками, поэтому удобен для текстовых файлов.

Как и `FileOutputStream`, может работать в режиме перезаписи или дозаписи.

**Пример:**

```java
try (FileWriter writer = new FileWriter("notes.txt", false)) {
    writer.write("Hello World");
    writer.append('\n');
    writer.append('!');
    writer.flush();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## flush()

**Определение:**

`flush()` — это метод, который принудительно записывает данные из буфера в конечное место назначения.

Например, если данные временно лежат в буфере, `flush()` заставляет поток отправить их в файл сразу.

Метод полезен, когда нужно быть уверенным, что данные уже записаны, не дожидаясь закрытия потока.

**Пример:**

```java
try (FileWriter writer = new FileWriter("notes.txt")) {
    writer.write("Important data");
    writer.flush();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## BufferedWriter

**Определение:**

`BufferedWriter` — это класс для буферизованной записи текста.

Он снижает количество обращений к файлу и делает запись эффективнее.

Часто используется вместе с `FileWriter`.

**Пример:**

```java
try (BufferedWriter writer = new BufferedWriter(new FileWriter("notes.txt"))) {
    writer.write("Hello World!");
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## BufferedReader

**Определение:**

`BufferedReader` — это класс для буферизованного чтения текста.

Он часто используется для чтения текстовых файлов построчно с помощью метода `readLine()`.

В продакшене это один из самых частых вариантов чтения текстовых файлов.

**Пример:**

```java
try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {
    String line;

    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## readLine()

**Определение:**

`readLine()` — это метод класса `BufferedReader`, который считывает одну строку текста.

Метод возвращает строку без символа переноса строки.

Если строки закончились, метод возвращает `null`.

**Пример:**

```java
try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {

} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## ZIP-архив

**Определение:**

ZIP-архив — это файл, внутри которого могут храниться один или несколько файлов в сжатом виде.

В Java для работы с ZIP-архивами используются классы из пакета `java.util.zip`.

Основные классы:

* `ZipInputStream`;
* `ZipOutputStream`;
* `ZipEntry`.

**Пример:**

```java
try (ZipOutputStream zipOutputStream = new ZipOutputStream(
        new FileOutputStream("archive.zip"))) {

    ZipEntry entry = new ZipEntry("notes.txt");
    zipOutputStream.putNextEntry(entry);

    byte[] data = "Hello ZIP".getBytes();
    zipOutputStream.write(data);

    zipOutputStream.closeEntry();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## ZipOutputStream

**Определение:**

`ZipOutputStream` — это класс для записи данных в ZIP-архив.

С его помощью можно создать архив и добавить в него файлы.

Перед записью каждого файла нужно создать `ZipEntry` и добавить его в архив через `putNextEntry()`.

**Пример:**

```java
try (ZipOutputStream zipOutputStream = new ZipOutputStream(
        new FileOutputStream("output.zip"))) {

    ZipEntry entry = new ZipEntry("notes.txt");
    zipOutputStream.putNextEntry(entry);

    zipOutputStream.write("Hello".getBytes());

    zipOutputStream.closeEntry();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## ZipInputStream

**Определение:**

`ZipInputStream` — это класс для чтения данных из ZIP-архива.

Он позволяет последовательно проходить по файлам внутри архива с помощью метода `getNextEntry()`.

**Пример:**

```java
try (ZipInputStream zipInputStream = new ZipInputStream(
        new FileInputStream("output.zip"))) {

    ZipEntry entry;

    while ((entry = zipInputStream.getNextEntry()) != null) {
        System.out.println(entry.getName());
        zipInputStream.closeEntry();
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## ZipEntry

**Определение:**

`ZipEntry` — это объект, который описывает один файл или каталог внутри ZIP-архива.

Например, если в архиве лежит файл `notes.txt`, то для него создаётся отдельный объект `ZipEntry`.

**Пример:**

```java
ZipEntry entry = new ZipEntry("notes.txt");

System.out.println(entry.getName()); // notes.txt
```

---

## putNextEntry()

**Определение:**

`putNextEntry()` — это метод класса `ZipOutputStream`, который начинает запись нового файла внутри ZIP-архива.

После вызова этого метода можно записывать содержимое файла в архив.

**Пример:**

```java
try (ZipOutputStream zipOutputStream = new ZipOutputStream(
        new FileOutputStream("output.zip"))) {

    ZipEntry entry = new ZipEntry("notes.txt");
    zipOutputStream.putNextEntry(entry);

    zipOutputStream.write("Hello".getBytes());

    zipOutputStream.closeEntry();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## getNextEntry()

**Определение:**

`getNextEntry()` — это метод класса `ZipInputStream`, который переходит к следующему файлу внутри ZIP-архива.

Метод возвращает объект `ZipEntry`.

Если файлов больше нет, возвращает `null`.

**Пример:**

```java
try (ZipInputStream zipInputStream = new ZipInputStream(
        new FileInputStream("output.zip"))) {

    ZipEntry entry;

    while ((entry = zipInputStream.getNextEntry()) != null) {
        System.out.println("Файл в архиве: " + entry.getName());
    }
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## closeEntry()

**Определение:**

`closeEntry()` — это метод, который закрывает текущую запись внутри ZIP-архива.

После закрытия текущей записи можно перейти к следующему файлу архива или добавить новый файл.

**Пример:**

```java
try (ZipOutputStream zipOutputStream = new ZipOutputStream(
        new FileOutputStream("output.zip"))) {

    ZipEntry entry = new ZipEntry("notes.txt");
    zipOutputStream.putNextEntry(entry);
    zipOutputStream.write("Hello".getBytes());
    zipOutputStream.closeEntry();
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

## Сериализация

**Определение:**

Сериализация — это процесс преобразования объекта в последовательность байтов.

Она нужна, чтобы сохранить состояние объекта, например в файл, или передать его куда-то дальше.

Простой пример из жизни: сохранение прогресса в игре. Объект с данными игрока превращается в байты и записывается в файл.

**Пример:**

```java
GameProgress progress = new GameProgress(94, 10, 2, 254.32);

try (ObjectOutputStream outputStream = new ObjectOutputStream(
        new FileOutputStream("save.dat"))) {

    outputStream.writeObject(progress);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## Десериализация

**Определение:**

Десериализация — это обратный процесс: восстановление объекта из последовательности байтов.

Если сериализация сохраняет объект, то десериализация достаёт его обратно.

**Пример:**

```java
GameProgress progress = null;

try (ObjectInputStream inputStream = new ObjectInputStream(
        new FileInputStream("save.dat"))) {

    progress = (GameProgress) inputStream.readObject();
} catch (IOException | ClassNotFoundException exception) {
    System.out.println(exception.getMessage());
}

System.out.println(progress);
```

## Serializable

**Определение:**

`Serializable` — это интерфейс-маркер, который показывает Java, что объекты этого класса можно сериализовать.

Интерфейс-маркер не содержит методов. Он просто сообщает системе: «этот класс можно сохранять в поток байтов».

**Пример:**

```java
import java.io.Serializable;

public class GameProgress implements Serializable {
    private int health;
    private int weapons;
    private int level;
    private double distance;

    public GameProgress(int health, int weapons, int level, double distance) {
        this.health = health;
        this.weapons = weapons;
        this.level = level;
        this.distance = distance;
    }
}
```

---

## serialVersionUID

**Определение:**

`serialVersionUID` — это уникальный идентификатор версии сериализуемого класса.

Он нужен, чтобы Java понимала, совместим ли сохранённый объект со структурой класса при десериализации.

Если класс изменился, а старая версия объекта уже была сохранена в файл, `serialVersionUID` помогает контролировать совместимость.

**Пример:**

```java
import java.io.Serializable;

public class GameProgress implements Serializable {
    private static final long serialVersionUID = 1L;

    private int health;
    private int weapons;
    private int level;
    private double distance;
}
```

## ObjectOutputStream

**Определение:**

`ObjectOutputStream` — это класс для записи объектов в поток байтов.

Чаще всего используется для сериализации объектов в файл.

Объект должен реализовывать интерфейс `Serializable`.

**Пример:**

```java
GameProgress progress = new GameProgress(94, 10, 2, 254.32);

try (ObjectOutputStream outputStream = new ObjectOutputStream(
        new FileOutputStream("save.dat"))) {

    outputStream.writeObject(progress);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## ObjectInputStream

**Определение:**

`ObjectInputStream` — это класс для чтения объектов из потока байтов.

Чаще всего используется для десериализации объектов из файла.

После чтения объект обычно нужно привести к нужному типу.

**Пример:**

```java
try (ObjectInputStream inputStream = new ObjectInputStream(
        new FileInputStream("save.dat"))) {

    GameProgress progress = (GameProgress) inputStream.readObject();

    System.out.println(progress);
} catch (IOException | ClassNotFoundException exception) {
    System.out.println(exception.getMessage());
}
```

---

## writeObject()

**Определение:**

`writeObject()` — это метод класса `ObjectOutputStream`, который записывает объект в поток байтов.

Этот метод используется при сериализации.

**Пример:**

```java
GameProgress progress = new GameProgress(94, 10, 2, 254.32);

try (ObjectOutputStream outputStream = new ObjectOutputStream(
        new FileOutputStream("save.dat"))) {

    outputStream.writeObject(progress);
} catch (IOException exception) {
    System.out.println(exception.getMessage());
}
```

---

## readObject()

**Определение:**

`readObject()` — это метод класса `ObjectInputStream`, который читает объект из потока байтов.

Метод возвращает `Object`, поэтому результат нужно привести к нужному типу.

**Пример:**

```java
try (ObjectInputStream inputStream = new ObjectInputStream(
        new FileInputStream("save.dat"))) {

    GameProgress progress = (GameProgress) inputStream.readObject();

    System.out.println(progress);
} catch (IOException | ClassNotFoundException exception) {
    System.out.println(exception.getMessage());
}
```
