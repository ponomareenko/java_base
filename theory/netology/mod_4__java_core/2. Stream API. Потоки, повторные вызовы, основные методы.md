# Тема 2: Stream API. Потоки, повторные вызовы, основные методы

## Stream API

**Определение:**

`Stream API` — это инструмент Java для обработки наборов данных в функциональном стиле.

Он позволяет фильтровать, преобразовывать, сортировать, искать и собирать данные без ручного написания циклов.

Важно: `Stream API` не нужно путать с потоками ввода-вывода (`InputStream`, `OutputStream`) и потоками выполнения (`Thread`).

**Пример:**

```java
List<String> names = List.of("Alex", "Bob", "Anna");

List<String> result = names.stream()
        .filter(name -> name.startsWith("A"))
        .toList();

System.out.println(result); // [Alex, Anna]
```

---

## Stream

**Определение:**

`Stream` — это поток данных из источника.

Источник может быть:

* коллекцией;
* массивом;
* файлом;
* генератором значений.

`Stream` не хранит элементы сам. Он только описывает, откуда взять данные и какие операции над ними выполнить.

**Пример:**

```java
List<String> names = List.of("Alex", "Bob", "Anna");

Stream<String> stream = names.stream();
```

---

## Stream<T>

**Определение:**

`Stream<T>` — это объектный поток данных, где `T` — тип элементов внутри потока.

Например:

```java
Stream<String>
```

означает поток строк.

```java
Stream<Integer>
```

означает поток объектов типа `Integer`.

**Пример:**

```java
Stream<String> names = Stream.of("Alex", "Bob", "Anna");

names.forEach(System.out::println);
```

---

## Источник стрима

**Определение:**

Источник стрима — это объект или механизм, из которого Stream получает данные.

Сам Stream данные не хранит. Он берёт их из источника во время выполнения терминальной операции.

**Пример:**

```java
List<Integer> numbers = List.of(1, 2, 3, 4, 5);

Stream<Integer> stream = numbers.stream();
```

Здесь `numbers` — источник данных.

---

## Поток не хранит элементы

**Определение:**

Stream не является коллекцией и не хранит элементы внутри себя.

Он работает как конвейер: берёт элементы из источника, пропускает через операции и отдаёт результат.

**Пример:**

```java
List<String> names = List.of("Alex", "Bob", "Anna");

Stream<String> stream = names.stream()
        .filter(name -> name.startsWith("A"));
```

В переменной `stream` не лежит список `[Alex, Anna]`.

Там лежит только описание операции:

```java
взять names -> оставить имена на A
```

---

## Жизненный цикл стрима

**Определение:**

Жизненный цикл стрима — это последовательность этапов работы Stream.

Обычно он состоит из трёх шагов:

1. создание стрима;
2. применение промежуточных операций;
3. применение терминальной операции.

**Пример:**

```java
List<String> result = List.of("Alex", "Bob", "Anna").stream() // создание
        .filter(name -> name.startsWith("A"))                 // промежуточная операция
        .toList();                                            // терминальная операция
```

---

## Конвейер Stream

**Определение:**

Конвейер Stream — это цепочка операций, которые последовательно применяются к данным.

Обычно выглядит так:

```java
источник -> stream() -> filter() -> map() -> collect()
```

или:

```java
источник -> stream() -> filter() -> map() -> toList()
```

**Пример:**

```java
List<String> result = List.of(" alex ", " bob ", " anna ").stream()
        .map(String::trim)
        .filter(name -> name.startsWith("a"))
        .map(String::toUpperCase)
        .toList();

System.out.println(result); // [ALEX, ANNA]
```

---

## Промежуточная операция Stream

**Определение:**

Промежуточная операция — это операция, которая возвращает новый Stream.

Она не запускает обработку данных сама по себе.

Промежуточные операции нужны, чтобы собрать цепочку обработки.

Примеры:

```java
filter()
map()
flatMap()
distinct()
limit()
skip()
sorted()
```

**Пример:**

```java
Stream<String> stream = List.of("Alex", "Bob", "Anna").stream()
        .filter(name -> name.startsWith("A"))
        .map(String::toUpperCase);
```

Здесь данные ещё не обработаны, потому что нет терминальной операции.

---

## Терминальная операция Stream

**Определение:**

Терминальная операция — это операция, которая запускает выполнение всего Stream-конвейера и возвращает итоговый результат.

После терминальной операции Stream считается использованным.

Примеры:

```java
toList()
collect()
forEach()
count()
findFirst()
findAny()
anyMatch()
allMatch()
noneMatch()
min()
max()
reduce()
toArray()
```

**Пример:**

```java
List<String> result = List.of("Alex", "Bob", "Anna").stream()
        .filter(name -> name.startsWith("A"))
        .toList();

System.out.println(result); // [Alex, Anna]
```

`toList()` запускает обработку.

---

## Одноразовость стрима

**Определение:**

Одноразовость стрима означает, что один и тот же объект `Stream` нельзя использовать повторно после терминальной операции.

После терминальной операции Stream закрывается.

**Пример с ошибкой:**

```java
Stream<String> stream = Stream.of("A", "B", "C");

stream.forEach(System.out::println);

long count = stream.count(); // ошибка
```

Результат:

```text
java.lang.IllegalStateException: stream has already been operated upon or closed
```

---

## Повторное использование данных через новый Stream

**Определение:**

Если нужно выполнить несколько разных операций над одними и теми же данными, нужно каждый раз создавать новый Stream из источника.

Переиспользовать сам Stream нельзя, но можно переиспользовать коллекцию, из которой он создаётся.

**Пример:**

```java
List<String> names = List.of("Alex", "Bob", "Anna");

long count = names.stream().count();

List<String> namesWithA = names.stream()
        .filter(name -> name.startsWith("A"))
        .toList();

System.out.println(count);      // 3
System.out.println(namesWithA); // [Alex, Anna]
```

---

## Supplier<Stream<T>> для повторных вызовов

**Определение:**

`Supplier<Stream<T>>` можно использовать, когда нужно получать новый Stream каждый раз по требованию.

Это полезно, если источник данных создаётся прямо через `Stream.of()` и его нужно использовать несколько раз.

**Пример:**

```java
Supplier<Stream<String>> streamSupplier = () -> Stream.of("A", "B", "C");

long count = streamSupplier.get().count();

Optional<String> first = streamSupplier.get().findFirst();

System.out.println(count); // 3
System.out.println(first.orElse("empty")); // A
```

Каждый вызов `get()` создаёт новый Stream.

---

## Ленивость Stream

**Определение:**

Ленивость Stream означает, что промежуточные операции не выполняются сразу.

Они начинают работать только тогда, когда вызывается терминальная операция.

**Пример:**

```java
Stream<String> stream = List.of("one", "two", "three").stream()
        .filter(value -> {
            System.out.println("filter: " + value);
            return value.length() > 3;
        });

System.out.println("Stream created");

List<String> result = stream.toList();

System.out.println(result);
```

Вывод:

```text
Stream created
filter: one
filter: two
filter: three
[three]
```

`filter()` начал выполняться только после вызова `toList()`.

---

## Short-circuit операция

**Определение:**

Short-circuit операция — это операция, которая может остановить обработку Stream раньше, чем будут просмотрены все элементы.

Такие операции экономят ресурсы.

Примеры:

```java
findFirst()
findAny()
anyMatch()
allMatch()
noneMatch()
limit()
```

**Пример:**

```java
Optional<Integer> result = List.of(1, 2, 3, 4, 5).stream()
        .filter(number -> {
            System.out.println("filter: " + number);
            return number > 2;
        })
        .findFirst();

System.out.println(result.orElse(-1));
```

Вывод:

```text
filter: 1
filter: 2
filter: 3
3
```

Числа `4` и `5` не проверялись, потому что `findFirst()` уже нашёл результат.

## Stream.empty()

**Определение:**

`Stream.empty()` создаёт пустой Stream.

Он полезен, когда нужно вернуть поток, но данных нет.

**Пример:**

```java
Stream<String> emptyStream = Stream.empty();

long count = emptyStream.count();

System.out.println(count); // 0
```

## stream()

**Определение:**

`stream()` — это метод коллекции, который создаёт последовательный Stream из элементов коллекции.

**Пример:**

```java
List<String> names = List.of("Alex", "Bob", "Anna");

Stream<String> stream = names.stream();
```

---

## parallelStream()

**Определение:**

`parallelStream()` создаёт параллельный Stream.

Такой Stream может обрабатывать данные в нескольких потоках выполнения.

Использовать его нужно осторожно: для маленьких коллекций или операций с внешним изменяемым состоянием он может сделать код хуже.

**Пример:**

```java
List<Integer> result = List.of(1, 2, 3, 4, 5).parallelStream()
        .map(number -> number * number)
        .toList();

System.out.println(result);
```

## Stream.of()

**Определение:**

`Stream.of()` создаёт Stream из перечисленных значений.

**Пример:**

```java
Stream<String> stream = Stream.of("One", "Two", "Three");

stream.forEach(System.out::println);
```

## Arrays.stream()

**Определение:**

`Arrays.stream()` создаёт Stream из массива.

Для массивов примитивов может создаваться примитивный Stream, например `IntStream`.

**Пример с массивом строк:**

```java
String[] names = {"Alex", "Bob", "Anna"};

Stream<String> stream = Arrays.stream(names);

stream.forEach(System.out::println);
```

**Пример с массивом int:**

```java
int[] numbers = {1, 2, 3};

IntStream stream = Arrays.stream(numbers);

System.out.println(stream.sum()); // 6
```

## Стрим из Map

**Определение:**

У `Map` нет прямого метода `stream()`, потому что `Map` хранит пары ключ-значение.

Чтобы создать Stream из `Map`, обычно используют:

```java
entrySet().stream()
```

**Пример:**

```java
Map<String, Integer> ages = Map.of(
        "Alex", 20,
        "Bob", 25
);

ages.entrySet().stream()
        .forEach(entry -> System.out.println(entry.getKey() + ": " + entry.getValue()));
```

## Примитивный Stream

**Определение:**

Примитивный Stream — это специальный Stream для примитивных числовых типов.

В Java есть:

```java
IntStream
LongStream
DoubleStream
```

Они полезны, потому что не требуют упаковки примитивов в объекты и имеют удобные методы для чисел.

**Пример:**

```java
int sum = IntStream.of(1, 2, 3, 4, 5)
        .sum();

System.out.println(sum); // 15
```

## IntStream

**Определение:**

`IntStream` — это Stream для значений типа `int`.

Он содержит специальные методы для работы с числами:

```java
sum()
average()
min()
max()
```

**Пример:**

```java
int max = IntStream.of(10, 5, 20)
        .max()
        .orElse(0);

System.out.println(max); // 20
```

---

## LongStream

**Определение:**

`LongStream` — это Stream для значений типа `long`.

**Пример:**

```java
long sum = LongStream.of(100L, 200L, 300L)
        .sum();

System.out.println(sum); // 600
```

---

## DoubleStream

**Определение:**

`DoubleStream` — это Stream для значений типа `double`.

**Пример:**

```java
double average = DoubleStream.of(10.0, 20.0, 30.0)
        .average()
        .orElse(0.0);

System.out.println(average); // 20.0
```

## Boxing в Stream API

**Определение:**

`Boxing` — это упаковка примитива в объект.

Например:

```java
int -> Integer
double -> Double
long -> Long
```

В Stream API boxing часто нужен, когда нужно перейти от примитивного Stream к объектному Stream.

**Пример:**

```java
List<Integer> numbers = IntStream.of(1, 2, 3)
        .boxed()
        .toList();

System.out.println(numbers); // [1, 2, 3]
```

---

## boxed()

**Определение:**

`boxed()` превращает примитивный Stream в объектный Stream.

Например:

```java
IntStream -> Stream<Integer>
LongStream -> Stream<Long>
DoubleStream -> Stream<Double>
```

**Пример:**

```java
List<Integer> result = IntStream.of(1, 2, 3)
        .map(number -> number * 10)
        .boxed()
        .toList();

System.out.println(result); // [10, 20, 30]
```

---

## filter()

**Определение:**

`filter()` — это промежуточная операция, которая оставляет в Stream только те элементы, которые проходят условие.

Метод принимает `Predicate`.

Если `Predicate` возвращает `true`, элемент остаётся.

Если `Predicate` возвращает `false`, элемент отбрасывается.

**Пример:**

```java
List<Integer> result = List.of(1, 2, 3, 4, 5).stream()
        .filter(number -> number > 2)
        .toList();

System.out.println(result); // [3, 4, 5]
```

---

## map()

**Определение:**

`map()` — это промежуточная операция, которая преобразует каждый элемент Stream.

Метод принимает `Function`.

Используется, когда из одного значения нужно получить другое.

**Пример:**

```java
List<String> result = List.of("alex", "bob", "anna").stream()
        .map(String::toUpperCase)
        .toList();

System.out.println(result); // [ALEX, BOB, ANNA]
```

---

## flatMap()

**Определение:**

`flatMap()` — это промежуточная операция, которая превращает каждый элемент в Stream, а потом объединяет все полученные Stream в один общий Stream.

Проще: `flatMap()` нужен, когда внутри элементов есть другие элементы, и нужно получить один плоский поток.

**Пример:**

```java
List<List<String>> groups = List.of(
        List.of("Alex", "Bob"),
        List.of("Anna", "John")
);

List<String> names = groups.stream()
        .flatMap(group -> group.stream())
        .toList();

System.out.println(names); // [Alex, Bob, Anna, John]
```

---

## distinct()

**Определение:**

`distinct()` — это промежуточная операция, которая удаляет дубликаты из Stream.

Для сравнения объектов используется `equals()`.

**Пример:**

```java
List<String> result = List.of("one", "two", "one", "three", "two").stream()
        .distinct()
        .toList();

System.out.println(result); // [one, two, three]
```

---

## limit()

**Определение:**

`limit(n)` — это промежуточная операция, которая оставляет не больше `n` первых элементов Stream.

**Пример:**

```java
List<String> result = List.of("one", "two", "three").stream()
        .limit(2)
        .toList();

System.out.println(result); // [one, two]
```

---

## skip()

**Определение:**

`skip(n)` — это промежуточная операция, которая пропускает первые `n` элементов Stream.

**Пример:**

```java
List<String> result = List.of("one", "two", "three", "four").stream()
        .skip(2)
        .toList();

System.out.println(result); // [three, four]
```

---

## sorted()

**Определение:**

`sorted()` — это промежуточная операция, которая сортирует элементы Stream.

Без аргументов используется естественный порядок сортировки.

С аргументом можно передать свой `Comparator`.

**Пример:**

```java
List<String> result = List.of("Bob", "Alex", "John").stream()
        .sorted()
        .toList();

System.out.println(result); // [Alex, Bob, John]
```

---

## Comparator.naturalOrder()

**Определение:**

`Comparator.naturalOrder()` возвращает компаратор для сортировки в естественном порядке.

Для строк это алфавитный порядок.

Для чисел — порядок от меньшего к большему.

**Пример:**

```java
List<Integer> result = List.of(5, 1, 3).stream()
        .sorted(Comparator.naturalOrder())
        .toList();

System.out.println(result); // [1, 3, 5]
```

---

## Comparator.reverseOrder()

**Определение:**

`Comparator.reverseOrder()` возвращает компаратор для сортировки в обратном порядке.

**Пример:**

```java
List<Integer> result = List.of(5, 1, 3).stream()
        .sorted(Comparator.reverseOrder())
        .toList();

System.out.println(result); // [5, 3, 1]
```

---

## forEach()

**Определение:**

`forEach()` — это терминальная операция, которая выполняет действие для каждого элемента Stream.

Метод принимает `Consumer` и возвращает `void`.

Часто используется для вывода данных, но в продакшене его не стоит использовать для сложной бизнес-логики.

**Пример:**

```java
List.of("Alex", "Bob", "Anna").stream()
        .forEach(System.out::println);
```

---

## collect()

**Определение:**

`collect()` — это терминальная операция, которая собирает элементы Stream в итоговую структуру данных.

Например:

* в `List`;
* в `Set`;
* в `Map`;
* в строку;
* в сгруппированные данные.

**Пример:**

```java
List<String> result = List.of("alex", "bob", "anna").stream()
        .map(String::toUpperCase)
        .collect(Collectors.toList());

System.out.println(result); // [ALEX, BOB, ANNA]
```

---

## Collector

**Определение:**

`Collector` — это объект, который описывает, как собрать элементы Stream в итоговый результат.

Обычно вручную его не создают, а используют готовые методы из класса `Collectors`.

**Пример:**

```java
List<String> result = Stream.of("A", "B", "C")
        .collect(Collectors.toList());

System.out.println(result); // [A, B, C]
```

---

## Collectors

**Определение:**

`Collectors` — это утилитный класс, в котором находятся готовые коллекторы для метода `collect()`.

Частые методы:

```java
Collectors.toList()
Collectors.toSet()
Collectors.joining()
Collectors.groupingBy()
Collectors.averagingDouble()
```

**Пример:**

```java
String result = Stream.of("Java", "Spring", "SQL")
        .collect(Collectors.joining(", "));

System.out.println(result); // Java, Spring, SQL
```

---

## toList()

**Определение:**

`toList()` — это терминальная операция, которая собирает элементы Stream в список.

Это более короткая запись по сравнению с:

```java
collect(Collectors.toList())
```

**Пример:**

```java
List<String> result = Stream.of("A", "B", "C")
        .toList();

System.out.println(result); // [A, B, C]
```

---

## count()

**Определение:**

`count()` — это терминальная операция, которая возвращает количество элементов в Stream.

Результат имеет тип `long`.

**Пример:**

```java
long count = Stream.of("one", "two", "three")
        .count();

System.out.println(count); // 3
```

---

## findFirst()

**Определение:**

`findFirst()` — это терминальная операция, которая возвращает первый элемент Stream, если он есть.

Результат возвращается в `Optional`.

**Пример:**

```java
Optional<String> result = Stream.of("one", "two", "three")
        .findFirst();

System.out.println(result.orElse("empty")); // one
```

---

## findAny()

**Определение:**

`findAny()` — это терминальная операция, которая возвращает любой элемент Stream.

В обычном последовательном Stream результат часто совпадает с первым элементом, но в параллельных Stream это не гарантируется.

**Пример:**

```java
Optional<String> result = Stream.of("one", "two", "three")
        .findAny();

System.out.println(result.orElse("empty"));
```

---

## anyMatch()

**Определение:**

`anyMatch()` — это терминальная операция, которая проверяет, есть ли хотя бы один элемент, подходящий под условие.

Возвращает `boolean`.

Может остановить обработку раньше, если подходящий элемент найден.

**Пример:**

```java
boolean result = Stream.of("one", "two", "three")
        .anyMatch(word -> word.startsWith("o"));

System.out.println(result); // true
```

---

## allMatch()

**Определение:**

`allMatch()` — это терминальная операция, которая проверяет, все ли элементы подходят под условие.

Возвращает `boolean`.

**Пример:**

```java
boolean result = Stream.of("one", "two", "three")
        .allMatch(word -> word.length() >= 3);

System.out.println(result); // true
```

---

## noneMatch()

**Определение:**

`noneMatch()` — это терминальная операция, которая проверяет, что ни один элемент не подходит под условие.

Возвращает `boolean`.

**Пример:**

```java
boolean result = Stream.of("one", "two", "three")
        .noneMatch(word -> word.startsWith("z"));

System.out.println(result); // true
```

---

## min()

**Определение:**

`min()` — это терминальная операция, которая возвращает минимальный элемент Stream по переданному `Comparator`.

Результат возвращается в `Optional`, потому что Stream может быть пустым.

**Пример:**

```java
Optional<Integer> min = Stream.of(5, 1, 10)
        .min(Integer::compareTo);

System.out.println(min.orElse(0)); // 1
```

---

## max()

**Определение:**

`max()` — это терминальная операция, которая возвращает максимальный элемент Stream по переданному `Comparator`.

Результат возвращается в `Optional`, потому что Stream может быть пустым.

**Пример:**

```java
Optional<Integer> max = Stream.of(5, 1, 10)
        .max(Integer::compareTo);

System.out.println(max.orElse(0)); // 10
```

---

## reduce()

**Определение:**

`reduce()` — это терминальная операция, которая сводит все элементы Stream к одному значению.

Используется для суммирования, умножения, объединения строк и других операций накопления.

**Пример:**

```java
int sum = Stream.of(1, 2, 3, 4, 5)
        .reduce(0, Integer::sum);

System.out.println(sum); // 15
```

Пример без начального значения:

```java
Optional<String> result = Stream.of("one", "two", "three")
        .reduce((first, second) -> first + " + " + second);

System.out.println(result.orElse("empty")); // one + two + three
```

---

## Аккумулятор в reduce()

**Определение:**

Аккумулятор в `reduce()` — это функция, которая описывает, как объединять два значения в одно.

**Пример:**

```java
int sum = Stream.of(1, 2, 3)
        .reduce(0, (currentSum, nextNumber) -> currentSum + nextNumber);

System.out.println(sum); // 6
```

Здесь:

```java
(currentSum, nextNumber) -> currentSum + nextNumber
```

это аккумулятор.

---

## Начальное значение в reduce()

**Определение:**

Начальное значение в `reduce()` — это стартовое значение, с которого начинается свёртка.

Если начальное значение указано, результат возвращается сразу обычным типом, а не `Optional`.

**Пример:**

```java
int sum = Stream.of(1, 2, 3)
        .reduce(0, Integer::sum);

System.out.println(sum); // 6
```

`0` — начальное значение.

---

## toArray()

**Определение:**

`toArray()` — это терминальная операция, которая собирает элементы Stream в массив.

Обычный `toArray()` возвращает массив `Object[]`.

**Пример:**

```java
Object[] array = Stream.of("One", "Two", "Three")
        .toArray();

System.out.println(Arrays.toString(array)); // [One, Two, Three]
```

Если нужен массив конкретного типа:

```java
String[] array = Stream.of("One", "Two", "Three")
        .toArray(String[]::new);

System.out.println(Arrays.toString(array)); // [One, Two, Three]
```

---

## IllegalStateException при повторном использовании Stream

**Определение:**

`IllegalStateException` при работе со Stream часто возникает, когда разработчик пытается повторно использовать уже закрытый Stream.

**Пример:**

```java
Stream<String> stream = Stream.of("A", "B", "C");

stream.count();

stream.forEach(System.out::println); // IllegalStateException
```

Правильно:

```java
List<String> letters = List.of("A", "B", "C");

letters.stream().count();

letters.stream().forEach(System.out::println);
```

---

## groupingBy()

**Определение:**

`groupingBy()` — это коллектор, который группирует элементы Stream по ключу.

Ключ задаётся функцией.

**Пример:**

```java
class Employee {
    private final String department;
    private final int salary;

    public Employee(String department, int salary) {
        this.department = department;
        this.salary = salary;
    }

    public String getDepartment() {
        return department;
    }

    public int getSalary() {
        return salary;
    }
}

List<Employee> employees = List.of(
        new Employee("IT", 100_000),
        new Employee("IT", 120_000),
        new Employee("HR", 80_000)
);

Map<String, List<Employee>> result = employees.stream()
        .collect(Collectors.groupingBy(Employee::getDepartment));

System.out.println(result.keySet()); // [HR, IT]
```

---

## averagingDouble()

**Определение:**

`averagingDouble()` — это коллектор, который считает среднее значение типа `double`.

Часто используется вместе с `groupingBy()`.

**Пример:**

```java
Map<String, Double> averageSalary = employees.stream()
        .collect(Collectors.groupingBy(
                Employee::getDepartment,
                Collectors.averagingDouble(Employee::getSalary)
        ));

System.out.println(averageSalary);
```

---

## joining()

**Определение:**

`joining()` — это коллектор, который объединяет строки в одну строку.

Можно указать разделитель.

**Пример:**

```java
String result = Stream.of("Java", "Spring", "SQL")
        .collect(Collectors.joining(", "));

System.out.println(result); // Java, Spring, SQL
```

---

## Неинтерферирующая операция

**Определение:**

Неинтерферирующая операция — это операция Stream, которая не изменяет источник данных во время обработки.

В хорошей практике операции внутри Stream не должны менять исходную коллекцию или внешнее состояние.

**Плохой пример:**

```java
List<String> names = new ArrayList<>(List.of("Alex", "Bob", "Anna"));

names.stream()
        .filter(name -> name.startsWith("A"))
        .forEach(name -> names.remove(name)); // плохая идея
```

Лучше создать новый результат:

```java
List<String> result = names.stream()
        .filter(name -> name.startsWith("A"))
        .toList();

System.out.println(result); // [Alex, Anna]
```

---

## Побочные эффекты в Stream

**Определение:**

Побочный эффект в Stream — это действие, которое изменяет что-то за пределами текущей операции.

Например:

* изменение внешнего списка;
* запись в файл;
* изменение поля объекта;
* отправка запроса;
* вывод в консоль.

Побочные эффекты не всегда запрещены, но их нужно контролировать. Stream лучше всего работает, когда операции чистые и предсказуемые.

**Плохой пример:**

```java
List<Integer> result = new ArrayList<>();

List.of(1, 2, 3, 4).stream()
        .filter(number -> number % 2 == 0)
        .forEach(number -> result.add(number));
```

Лучше:

```java
List<Integer> result = List.of(1, 2, 3, 4).stream()
        .filter(number -> number % 2 == 0)
        .toList();
```

---

## Stream vs цикл

**Определение:**

Stream лучше использовать, когда нужно описать цепочку обработки данных:

* отфильтровать;
* преобразовать;
* отсортировать;
* собрать результат.

Обычный цикл лучше использовать, когда логика сложная, есть много условий, ранних выходов, обработка ошибок или изменение состояния.

**Пример через цикл:**

```java
List<String> result = new ArrayList<>();

for (String name : List.of("Alex", "Bob", "Anna")) {
    if (name.startsWith("A")) {
        result.add(name.toUpperCase());
    }
}

System.out.println(result); // [ALEX, ANNA]
```

**Пример через Stream:**

```java
List<String> result = List.of("Alex", "Bob", "Anna").stream()
        .filter(name -> name.startsWith("A"))
        .map(String::toUpperCase)
        .toList();

System.out.println(result); // [ALEX, ANNA]
```
