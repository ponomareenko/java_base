# Тема 7: Коллекции HashSet и HashMap

## Хеш-таблица

**Определение:**

Хеш-таблица — это структура данных, которая хранит пары «ключ-значение» и позволяет быстро находить значение по ключу.

В Java хеш-таблицы лежат в основе таких коллекций, как `HashMap` и `HashSet`.

Главная идея хеш-таблицы: не перебирать все элементы подряд, а вычислить специальный код ключа и по нему быстро найти нужную ячейку.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);

System.out.println(ages.get("Petya")); // 8
```

---

## Хеширование

**Определение:**

Хеширование — это процесс преобразования объекта или данных в числовой код фиксированной длины.

В Java для этого используется метод `hashCode()`.

Хеширование нужно, чтобы коллекции вроде `HashMap` и `HashSet` могли быстро находить элементы.

**Пример:**

```java
String text = "qwe";

System.out.println(text.hashCode());
```

---

## hashCode()

**Определение:**

`hashCode()` — это метод Java, который возвращает числовой хеш-код объекта.

Этот хеш-код используется в хеш-таблицах для определения места хранения объекта.

Если два объекта равны по `equals()`, они обязательно должны иметь одинаковый `hashCode()`.

Но если два объекта имеют одинаковый `hashCode()`, это не значит, что они обязательно равны.

**Пример:**

```java
String first = "Petya";
String second = "Petya";

System.out.println(first.hashCode());
System.out.println(second.hashCode());
```

---

## Коллизия

**Определение:**

Коллизия — это ситуация, когда у разных объектов получается одинаковый хеш-код или они попадают в одну и ту же ячейку хеш-таблицы.

Коллизии нормальны и возможны в любой хеш-таблице.

В Java при коллизии `HashMap` сначала находит нужную ячейку по `hashCode()`, а затем сравнивает элементы внутри этой ячейки через `equals()`.

**Пример:**

```java
// У разных объектов теоретически может быть одинаковый hashCode.
// Поэтому HashMap использует не только hashCode(), но и equals().
```

---

## Bucket

**Определение:**

`Bucket` — это внутренняя ячейка массива в хеш-таблице.

Когда объект добавляется в `HashMap`, Java вычисляет хеш-код ключа и определяет, в какой bucket положить пару «ключ-значение».

Если несколько объектов попали в один bucket, возникает коллизия.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);
```

Внутри `HashMap` эти пары будут распределены по bucket на основе хеш-кодов ключей.

---

## HashMap

**Определение:**

`HashMap` — это реализация интерфейса `Map`, основанная на хеш-таблице.

`HashMap` хранит данные в формате «ключ-значение».

Эта коллекция хорошо подходит, когда нужно быстро искать, добавлять, изменять или удалять значения по ключу.

В среднем операции `put()`, `get()` и `remove()` работают за `O(1)`.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);

Integer petyaAge = ages.get("Petya");

System.out.println(petyaAge); // 8
```

---

## Ключ

**Определение:**

Ключ — это объект, по которому в `Map` находится значение.

В `HashMap` ключ должен корректно работать с методами `equals()` и `hashCode()`.

Обычно ключом делают уникальный идентификатор: номер документа, id пользователя, email, артикул товара.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
```

Здесь `"Petya"` — ключ.

---

## Значение

**Определение:**

Значение — это объект, который хранится в `Map` и связан с определённым ключом.

По одному ключу в `Map` может храниться только одно значение.

Если добавить новое значение с уже существующим ключом, старое значение будет заменено.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Petya", 9);

System.out.println(ages.get("Petya")); // 9
```

---

## Пара «ключ-значение»

**Определение:**

Пара «ключ-значение» — это одна запись в `Map`.

Ключ используется для поиска, а значение является данными, которые мы хотим получить.

Например:

`"Petya"` — ключ;

`8` — значение.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
```

---

## Ассоциативный массив

**Определение:**

Ассоциативный массив — это структура данных, в которой значение находится не по числовому индексу, а по ключу.

`Map` в Java можно воспринимать как ассоциативный массив.

Пример из жизни: словарь, где слово — ключ, а перевод — значение.

**Пример:**

```java
Map<String, String> dictionary = new HashMap<>();

dictionary.put("cat", "кот");
dictionary.put("dog", "собака");

System.out.println(dictionary.get("cat")); // кот
```

---

## O(1)

**Определение:**

`O(1)` — это сложность алгоритма, при которой время выполнения операции почти не зависит от количества элементов.

Для `HashMap` это означает, что поиск по ключу в среднем остаётся быстрым даже при большом количестве записей.

Важно: `O(1)` для `HashMap` — это средний случай. При плохом `hashCode()` и большом количестве коллизий производительность может ухудшиться.

**Пример:**

```java
Map<Integer, String> users = new HashMap<>();

users.put(1001, "Petya");
users.put(1002, "Olya");

System.out.println(users.get(1002));
```

---

## O(n)

**Определение:**

`O(n)` — это сложность алгоритма, при которой время выполнения растёт вместе с количеством элементов.

Например, если искать объект в `ArrayList` обычным перебором, в худшем случае придётся пройти по всем элементам.

Если элементов несколько тысяч или миллионов, такой поиск может быть заметно медленнее, чем поиск по ключу в `HashMap`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya");

for (String name : names) {
    if (name.equals("Tanya")) {
        System.out.println("Нашли");
    }
}
```

---

## put()

**Определение:**

`put()` — это метод `Map`, который добавляет пару «ключ-значение».

Если такого ключа ещё нет, в `Map` добавляется новая запись.

Если такой ключ уже есть, старое значение заменяется новым.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Petya", 9);

System.out.println(ages.get("Petya")); // 9
```

---

## putAll()

**Определение:**

`putAll()` — это метод `Map`, который добавляет в текущую `Map` все пары из другой `Map`.

Если некоторые ключи уже есть, их значения будут заменены.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();
ages.put("Petya", 8);

Map<String, Integer> newAges = new HashMap<>();
newAges.put("Tanya", 15);
newAges.put("Petya", 9);

ages.putAll(newAges);

System.out.println(ages); // {Petya=9, Tanya=15}
```

---

## get()

**Определение:**

`get()` — это метод `Map`, который возвращает значение по ключу.

Если ключа нет, метод возвращает `null`.

Важно: если в `Map` разрешены `null`-значения, то `null` от `get()` может означать две разные ситуации:

ключа нет;

ключ есть, но его значение равно `null`.

Для точной проверки используют `containsKey()`.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);

System.out.println(ages.get("Petya")); // 8
System.out.println(ages.get("Max"));   // null
```

---

## remove() у Map

**Определение:**

`remove()` у `Map` удаляет запись по ключу.

Метод возвращает значение, которое было связано с этим ключом.

Если ключа не было, вернётся `null`.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);

Integer removedAge = ages.remove("Petya");

System.out.println(removedAge); // 8
System.out.println(ages);       // {}
```

---

## containsKey()

**Определение:**

`containsKey()` — это метод `Map`, который проверяет, есть ли в коллекции указанный ключ.

Возвращает `true`, если ключ найден.

Для `HashMap` такая проверка обычно быстрая, потому что работает через хеш-таблицу.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);

System.out.println(ages.containsKey("Petya")); // true
System.out.println(ages.containsKey("Max"));   // false
```

---

## containsValue()

**Определение:**

`containsValue()` — это метод `Map`, который проверяет, есть ли в коллекции указанное значение.

В отличие от `containsKey()`, этот метод работает медленнее, потому что должен проверить значения перебором.

Сложность обычно `O(n)`.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);

System.out.println(ages.containsValue(15)); // true
```

---

## keySet()

**Определение:**

`keySet()` — это метод `Map`, который возвращает множество всех ключей.

Результат имеет тип `Set`, потому что ключи в `Map` не повторяются.

`keySet()` удобно использовать, когда нужно пройтись по всем ключам.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);

for (String name : ages.keySet()) {
    System.out.println(name);
}
```

---

## values()

**Определение:**

`values()` — это метод `Map`, который возвращает коллекцию всех значений.

Результат имеет тип `Collection`, а не `Set`, потому что значения в `Map` могут повторяться.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 8);

for (Integer age : ages.values()) {
    System.out.println(age);
}
```

---

## entrySet()

**Определение:**

`entrySet()` — это метод `Map`, который возвращает множество всех пар «ключ-значение».

Это обычно лучший способ перебрать `Map`, если нужны и ключ, и значение.

Такой подход лучше, чем идти по `keySet()` и для каждого ключа отдельно вызывать `get()`.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 8);
ages.put("Tanya", 15);

for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}
```

---

## Map.Entry

**Определение:**

`Map.Entry` — это объект, который представляет одну пару «ключ-значение» внутри `Map`.

Через `Map.Entry` можно получить ключ методом `getKey()` и значение методом `getValue()`.

**Пример:**

```java
for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    String key = entry.getKey();
    Integer value = entry.getValue();

    System.out.println(key + " - " + value);
}
```

---

## getKey()

**Определение:**

`getKey()` — это метод `Map.Entry`, который возвращает ключ текущей пары «ключ-значение».

**Пример:**

```java
for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getKey());
}
```

---

## getValue()

**Определение:**

`getValue()` — это метод `Map.Entry`, который возвращает значение текущей пары «ключ-значение».

**Пример:**

```java
for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getValue());
}
```

---

## null-ключ в HashMap

**Определение:**

`HashMap` позволяет использовать `null` в качестве ключа.

Такой ключ может быть только один, потому что ключи в `Map` уникальны.

Но использовать `null` как ключ нужно аккуратно: часто это усложняет понимание кода.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put(null, 125);

System.out.println(ages.get(null)); // 125
```

## Контракт equals() и hashCode()

**Определение:**

Контракт `equals()` и `hashCode()` — это набор правил, которые нужно соблюдать, чтобы объекты корректно работали в `HashMap` и `HashSet`.

Главные правила:

если два объекта равны по `equals()`, у них должен быть одинаковый `hashCode()`;

если два объекта не равны, их `hashCode()` может совпадать, но лучше, чтобы совпадений было меньше;

`hashCode()` одного и того же объекта должен возвращать одинаковое значение, пока данные объекта, участвующие в расчёте хеша, не изменились.

**Пример:**

```java
public class UserInfo {
    private final String name;
    private final String surname;

    public UserInfo(String name, String surname) {
        this.name = name;
        this.surname = surname;
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) {
            return true;
        }

        if (obj == null || getClass() != obj.getClass()) {
            return false;
        }

        UserInfo userInfo = (UserInfo) obj;

        return Objects.equals(name, userInfo.name)
                && Objects.equals(surname, userInfo.surname);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, surname);
    }
}
```

## Objects.hash()

**Определение:**

`Objects.hash()` — это статический метод Java, который помогает удобно вычислить `hashCode()` по нескольким полям объекта.

Он находится в классе `java.util.Objects`.

Часто используется при переопределении `hashCode()`.

**Пример:**

```java
@Override
public int hashCode() {
    return Objects.hash(name, surname);
}
```

## Immutable object

**Определение:**

`Immutable object` — это неизменяемый объект, состояние которого нельзя изменить после создания.

Для ключей в `HashMap` лучше использовать immutable-объекты.

Если изменить объект после добавления в `HashMap`, особенно поля, участвующие в `hashCode()`, коллекция может перестать находить этот ключ корректно.

**Пример:**

```java
public class UserKey {
    private final String passportNumber;

    public UserKey(String passportNumber) {
        this.passportNumber = passportNumber;
    }

    public String getPassportNumber() {
        return passportNumber;
    }
}
```

## final-поле

**Определение:**

`final`-поле — это поле, которому можно присвоить значение только один раз.

Обычно значение задают в конструкторе.

`final` помогает создавать неизменяемые объекты, которые безопаснее использовать как ключи в `HashMap`.

**Пример:**

```java
public class DriverLicenseKey {
    private final String licenseNumber;

    public DriverLicenseKey(String licenseNumber) {
        this.licenseNumber = licenseNumber;
    }
}
```

## HashSet

**Определение:**

`HashSet` — это реализация интерфейса `Set`, основанная на хеш-таблице.

`HashSet` хранит только уникальные элементы.

Он хорошо подходит, когда нужно быстро проверять наличие элемента и не нужны дубликаты.

Порядок элементов в `HashSet` не гарантируется.

**Пример:**

```java
Set<String> names = new HashSet<>();

names.add("Petya");
names.add("Olya");
names.add("Petya");

System.out.println(names); // порядок не гарантируется
System.out.println(names.contains("Olya")); // true
```

---

## Множество

**Определение:**

Множество — это коллекция уникальных элементов.

В Java множество описывается интерфейсом `Set`.

Множество удобно использовать, когда важен сам факт наличия элемента, а не его позиция.

Например, категории водительских прав: `"A"`, `"B"`, `"C"`, `"D"`.

**Пример:**

```java
Set<String> categories = new HashSet<>();

categories.add("A");
categories.add("B");
categories.add("B");

System.out.println(categories); // [A, B] или другой порядок
```

---

## Уникальный элемент

**Определение:**

Уникальный элемент — это элемент, который не повторяется в коллекции.

`HashSet` не хранит дубликаты.

Если добавить в `HashSet` такой же элемент второй раз, коллекция не изменится.

**Пример:**

```java
Set<String> names = new HashSet<>();

System.out.println(names.add("Petya")); // true
System.out.println(names.add("Petya")); // false
```

---

## Дубликат

**Определение:**

Дубликат — это повторяющийся элемент.

`ArrayList` может хранить дубликаты.

`HashSet` дубликаты не хранит.

**Пример:**

```java
List<String> list = new ArrayList<>();
list.add("Petya");
list.add("Petya");

Set<String> set = new HashSet<>();
set.add("Petya");
set.add("Petya");

System.out.println(list.size()); // 2
System.out.println(set.size());  // 1
```

---

## Объект-заглушка в HashSet

**Определение:**

Объект-заглушка в `HashSet` — это внутреннее значение, которое используется в `HashMap`, лежащей внутри `HashSet`.

Внутри `HashSet` элементы хранятся как ключи `HashMap`, а в качестве значения используется один общий служебный объект-заглушка.

То есть `HashSet` можно представить как `HashMap`, где важны только ключи.

**Пример:**

```java
// Упрощённая идея внутренней реализации HashSet:

private HashMap<E, Object> map;
private static final Object PRESENT = new Object();
```

---

## PRESENT

**Определение:**

`PRESENT` — это служебный объект-заглушка, который используется во внутренней реализации `HashSet`.

Когда мы добавляем элемент в `HashSet`, Java фактически кладёт этот элемент как ключ во внутреннюю `HashMap`, а значением ставит `PRESENT`.

Разработчик напрямую с `PRESENT` обычно не работает.

**Пример:**

```java
// Упрощённо:
map.put(element, PRESENT);
```

---

## Порядок элементов в HashSet

**Определение:**

Порядок элементов в `HashSet` не гарантируется.

Это значит, что элементы могут выводиться не в том порядке, в котором были добавлены.

Если нужен порядок добавления, обычно используют `LinkedHashSet`.

Если нужна сортировка, используют `TreeSet`.

**Пример:**

```java
Set<String> names = new HashSet<>();

names.add("Petya");
names.add("Olya");
names.add("Tanya");

System.out.println(names); // порядок может быть любым
```

---

## Быстрый поиск в HashSet

**Определение:**

Быстрый поиск в `HashSet` — это возможность быстро проверить наличие элемента через `contains()`.

В среднем такая проверка работает за `O(1)`.

Это быстрее, чем поиск в `ArrayList`, где в худшем случае нужно пройти все элементы.

**Пример:**

```java
Set<String> categories = new HashSet<>();

categories.add("A");
categories.add("B");
categories.add("C");

System.out.println(categories.contains("B")); // true
```

---

## HashSet vs ArrayList

**Определение:**

`HashSet` и `ArrayList` решают разные задачи.

`ArrayList` нужен, когда важен порядок элементов, индексы и возможность хранить дубликаты.

`HashSet` нужен, когда важна уникальность элементов и быстрый поиск.

Главные отличия:

`HashSet` не гарантирует порядок, `ArrayList` сохраняет порядок добавления;

`HashSet` не хранит дубликаты, `ArrayList` хранит;

поиск в `HashSet` в среднем `O(1)`, поиск в `ArrayList` обычно `O(n)`.

**Пример:**

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("A");

Set<String> set = new HashSet<>();
set.add("A");
set.add("A");

System.out.println(list); // [A, A]
System.out.println(set);  // [A]
```
