# Тема 6: Коллекции List

## Коллекция

**Определение:**

Коллекция — это объект, который хранит набор других объектов.

В Java коллекции нужны для работы с группами данных: списками, множествами, очередями, словарями и другими структурами.

Коллекции удобнее массивов, когда заранее неизвестно, сколько элементов нужно хранить, потому что многие коллекции умеют динамически изменять размер.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");
names.add("Tanya");
```

---

## Java Collections Framework

**Определение:**

`Java Collections Framework` — это набор интерфейсов и классов Java для хранения и обработки групп объектов.

В него входят интерфейсы `Collection`, `List`, `Set`, `Queue`, `Map` и их реализации: `ArrayList`, `LinkedList`, `HashSet`, `HashMap` и другие.

В продакшене почти всегда используют не массивы, а коллекции, если нужен гибкий набор данных.

**Пример:**

```java
List<String> names = new ArrayList<>();
Set<String> uniqueNames = new HashSet<>();
Map<String, Integer> scores = new HashMap<>();
```

---

## List

**Определение:**

`List` — это интерфейс коллекции, который описывает упорядоченный список элементов.

У каждого элемента в `List` есть индекс.

Через индекс можно получать, изменять, добавлять и удалять элементы.

`List` может хранить дубликаты, то есть одинаковые значения.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");
names.add("Petya");

System.out.println(names.get(0)); // Petya
```

---

## ArrayList

**Определение:**

`ArrayList` — это реализация интерфейса `List` на основе динамического массива.

`ArrayList` хорошо подходит, когда нужно часто получать элементы по индексу.

Например:

```java
names.get(10)
```

работает быстро, потому что внутри `ArrayList` лежит массив.

Но `ArrayList` не лучший выбор, если нужно часто вставлять или удалять элементы из середины списка, потому что после такой операции приходится сдвигать остальные элементы.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");
names.add("Tanya");

System.out.println(names.get(1)); // Olya
```

---

## Динамический массив

**Определение:**

Динамический массив — это массив, который может автоматически увеличиваться при добавлении новых элементов.

`ArrayList` внутри использует обычный массив.

Когда места становится недостаточно, Java создаёт новый массив большего размера и копирует туда старые элементы.

Для разработчика это выглядит как обычное добавление элемента, но внутри может происходить перераспределение памяти.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");
names.add("Tanya");
```

---

## Ёмкость ArrayList

**Определение:**

Ёмкость `ArrayList` — это размер внутреннего массива, который используется для хранения элементов.

Ёмкость не равна количеству элементов.

Количество элементов показывает `size()`, а ёмкость показывает, сколько элементов список может вместить без расширения внутреннего массива.

Если заранее известно примерное количество элементов, можно указать начальную ёмкость, чтобы уменьшить количество перераспределений памяти.

**Пример:**

```java
List<String> names = new ArrayList<>(100);
```

Такой список изначально подготовлен примерно под 100 элементов.

---

## Размер коллекции

**Определение:**

Размер коллекции — это количество элементов, которые сейчас находятся в коллекции.

Для коллекций размер получают методом `size()`.

Это не то же самое, что `length` у массива.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

System.out.println(names.size()); // 2
```

---

## length

**Определение:**

`length` — это поле массива, которое показывает длину массива.

У массивов размер фиксированный и задаётся при создании.

У коллекций поля `length` нет, для них используется метод `size()`.

**Пример:**

```java
String[] names = new String[3];

System.out.println(names.length); // 3
```

---

## size()

**Определение:**

`size()` — это метод коллекции, который возвращает количество элементов в коллекции.

Если список пустой, `size()` вернёт `0`.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");

int count = names.size();

System.out.println(count); // 1
```

---

## add()

**Определение:**

`add()` — это метод коллекции, который добавляет элемент.

В `List` метод `add()` обычно добавляет элемент в конец списка.

Метод возвращает `true`, если элемент был успешно добавлен.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

System.out.println(names); // [Petya, Olya]
```

---

## addAll()

**Определение:**

`addAll()` — это метод коллекции, который добавляет в текущую коллекцию все элементы из другой коллекции.

Метод возвращает `true`, если текущая коллекция изменилась.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");

List<String> otherNames = List.of("Olya", "Tanya");

names.addAll(otherNames);

System.out.println(names); // [Petya, Olya, Tanya]
```

---

## get()

**Определение:**

`get()` — это метод интерфейса `List`, который возвращает элемент по индексу.

Индексы в Java начинаются с `0`.

Если обратиться к индексу, которого нет, программа выбросит `IndexOutOfBoundsException`.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

String firstName = names.get(0);

System.out.println(firstName); // Petya
```

---

## Индекс

**Определение:**

Индекс — это номер позиции элемента в списке или массиве.

В Java индексация начинается с нуля.

Первый элемент имеет индекс `0`, второй — `1`, третий — `2`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya");

System.out.println(names.get(0)); // Petya
System.out.println(names.get(1)); // Olya
System.out.println(names.get(2)); // Tanya
```

---

## indexOf()

**Определение:**

`indexOf()` — это метод `List`, который возвращает индекс первого найденного элемента.

Если элемент не найден, метод возвращает `-1`.

Метод ищет элемент через сравнение по `equals()`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Petya");

int index = names.indexOf("Petya");

System.out.println(index); // 0
```

---

## lastIndexOf()

**Определение:**

`lastIndexOf()` — это метод `List`, который возвращает индекс последнего найденного элемента.

Если элемент не найден, метод возвращает `-1`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Petya");

int index = names.lastIndexOf("Petya");

System.out.println(index); // 2
```

---

## set()

**Определение:**

`set()` — это метод `List`, который заменяет элемент по указанному индексу.

Метод не добавляет новый элемент, а именно обновляет уже существующий.

Если указан несуществующий индекс, будет `IndexOutOfBoundsException`.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

names.set(1, "Max");

System.out.println(names); // [Petya, Max]
```

---

## subList()

**Определение:**

`subList()` — это метод `List`, который возвращает часть списка.

Он принимает два индекса:

`start` — начальный индекс включительно;

`end` — конечный индекс не включительно.

То есть `subList(1, 3)` вернёт элементы с индексами `1` и `2`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya", "Max");

List<String> part = names.subList(1, 3);

System.out.println(part); // [Olya, Tanya]
```

---

## clear()

**Определение:**

`clear()` — это метод коллекции, который удаляет из неё все элементы.

После вызова `clear()` коллекция становится пустой.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

names.clear();

System.out.println(names.size()); // 0
```

---

## contains()

**Определение:**

`contains()` — это метод коллекции, который проверяет, есть ли указанный объект в коллекции.

Если объект найден, метод возвращает `true`.

Если объект не найден, возвращает `false`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya");

boolean exists = names.contains("Olya");

System.out.println(exists); // true
```

---

## containsAll()

**Определение:**

`containsAll()` — это метод коллекции, который проверяет, содержит ли текущая коллекция все элементы из другой коллекции.

Если все элементы найдены, метод возвращает `true`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya");

boolean result = names.containsAll(List.of("Petya", "Tanya"));

System.out.println(result); // true
```

---

## isEmpty()

**Определение:**

`isEmpty()` — это метод коллекции, который проверяет, пустая ли коллекция.

Если в коллекции нет элементов, метод возвращает `true`.

Иначе возвращает `false`.

**Пример:**

```java
List<String> names = new ArrayList<>();

System.out.println(names.isEmpty()); // true

names.add("Petya");

System.out.println(names.isEmpty()); // false
```

---

## remove()

**Определение:**

`remove()` — это метод коллекции, который удаляет элемент.

У `List` есть два распространённых варианта:

удаление по объекту;

удаление по индексу.

При удалении по объекту метод возвращает `true`, если элемент был найден и удалён.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

names.remove("Petya");

System.out.println(names); // [Olya]
```

Удаление по индексу:

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

names.remove(0);

System.out.println(names); // [Olya]
```

---

## removeAll()

**Определение:**

`removeAll()` — это метод коллекции, который удаляет из текущей коллекции все элементы, которые есть в другой коллекции.

Метод возвращает `true`, если текущая коллекция изменилась.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Tom");
names.add("Alice");
names.add("Mark");
names.add("Maria");

names.removeAll(List.of("Mark", "Maria"));

System.out.println(names); // [Tom, Alice]
```

---

## retainAll()

**Определение:**

`retainAll()` — это метод коллекции, который оставляет в текущей коллекции только те элементы, которые есть в переданной коллекции.

Все остальные элементы удаляются.

Метод возвращает `true`, если текущая коллекция изменилась.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Tom");
names.add("Alice");
names.add("Mark");
names.add("Maria");

names.retainAll(List.of("Tom", "Alice"));

System.out.println(names); // [Tom, Alice]
```

---

## toArray()

**Определение:**

`toArray()` — это метод коллекции, который возвращает элементы коллекции в виде массива.

Обычный `toArray()` возвращает массив типа `Object[]`.

Если нужен массив конкретного типа, лучше использовать вариант с передачей массива нужного типа.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya");

String[] array = names.toArray(new String[0]);

System.out.println(array[0]); // Petya
```

## Collection

**Определение:**

`Collection` — это базовый интерфейс для простых коллекций, которые хранят набор элементов.

От `Collection` наследуются `List`, `Set` и `Queue`.

`Collection` описывает общие методы: `add()`, `remove()`, `contains()`, `size()`, `iterator()` и другие.

Важно: `Map` не наследуется от `Collection`, потому что хранит не одиночные элементы, а пары «ключ-значение».

**Пример:**

```java
Collection<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

System.out.println(names.size());
```

---

## Map

**Определение:**

`Map` — это интерфейс коллекций, который хранит данные в формате «ключ-значение».

Ключ используется для быстрого получения значения.

`Map` не является наследником `Collection`.

Пример из жизни: словарь, где слово — это ключ, а перевод — значение.

**Пример:**

```java
Map<String, Integer> ages = new HashMap<>();

ages.put("Petya", 20);
ages.put("Olya", 25);

System.out.println(ages.get("Olya")); // 25
```

---

## Set

**Определение:**

`Set` — это интерфейс коллекции, который описывает множество уникальных элементов.

`Set` не хранит дубликаты.

В отличие от `List`, у элементов `Set` нет индексов.

`Set` удобно использовать, когда важно не допустить повторяющиеся значения.

**Пример:**

```java
Set<String> names = new HashSet<>();

names.add("Petya");
names.add("Olya");
names.add("Petya");

System.out.println(names); // [Olya, Petya]
```

---

## Queue

**Определение:**

`Queue` — это интерфейс коллекции, который описывает очередь элементов.

Обычно очередь работает по принципу FIFO: первый вошёл — первый вышел.

`Queue` удобно использовать для задач, которые нужно выполнять в определённом порядке.

**Пример:**

```java
Queue<String> tasks = new LinkedList<>();

tasks.offer("Task 1");
tasks.offer("Task 2");

System.out.println(tasks.poll()); // Task 1
```

---

## FIFO

**Определение:**

`FIFO` означает `First In, First Out`.

Это принцип работы очереди: элемент, который добавили первым, будет извлечён первым.

**Пример:**

```java
Queue<String> queue = new LinkedList<>();

queue.offer("A");
queue.offer("B");
queue.offer("C");

System.out.println(queue.poll()); // A
```

---

## Deque

**Определение:**

`Deque` — это двусторонняя очередь.

В такую коллекцию можно добавлять и извлекать элементы как с начала, так и с конца.

`Deque` расшифровывается как `Double Ended Queue`.

**Пример:**

```java
Deque<String> deque = new ArrayDeque<>();

deque.addFirst("A");
deque.addLast("B");

System.out.println(deque.removeFirst()); // A
System.out.println(deque.removeLast());  // B
```

---

## offer()

**Определение:**

`offer()` — это метод очереди, который добавляет элемент в очередь.

Обычно его используют вместо `add()` при работе с `Queue`.

Метод возвращает `true`, если элемент успешно добавлен.

**Пример:**

```java
Queue<String> tasks = new LinkedList<>();

tasks.offer("Send email");
tasks.offer("Generate report");
```

---

## peek()

**Определение:**

`peek()` — это метод очереди, который возвращает первый элемент, но не удаляет его.

Если очередь пустая, `peek()` возвращает `null`.

**Пример:**

```java
Queue<String> tasks = new LinkedList<>();

tasks.offer("Task 1");
tasks.offer("Task 2");

System.out.println(tasks.peek()); // Task 1
System.out.println(tasks.peek()); // Task 1
```

---

## poll()

**Определение:**

`poll()` — это метод очереди, который возвращает первый элемент и удаляет его из очереди.

Если очередь пустая, `poll()` возвращает `null`.

**Пример:**

```java
Queue<String> tasks = new LinkedList<>();

tasks.offer("Task 1");
tasks.offer("Task 2");

System.out.println(tasks.poll()); // Task 1
System.out.println(tasks.poll()); // Task 2
```

---

## ListIterator

**Определение:**

`ListIterator` — это специальный итератор для списков.

Он позволяет перемещаться по списку в обе стороны: вперёд и назад.

Также через `ListIterator` можно изменять список во время обхода.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

ListIterator<String> iterator = names.listIterator();

while (iterator.hasNext()) {
    System.out.println(iterator.next());
}
```

---

## iterator()

**Определение:**

`iterator()` — это метод коллекции, который возвращает объект `Iterator`.

Iterator нужен для последовательного обхода элементов коллекции.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya");

Iterator<String> iterator = names.iterator();

while (iterator.hasNext()) {
    System.out.println(iterator.next());
}
```

---

## hasNext()

**Определение:**

`hasNext()` — это метод итератора, который проверяет, есть ли следующий элемент.

Перед вызовом `next()` обычно сначала вызывают `hasNext()`.

Если этого не сделать и вызвать `next()` в конце коллекции, можно получить `NoSuchElementException`.

**Пример:**

```java
Iterator<String> iterator = names.iterator();

while (iterator.hasNext()) {
    String name = iterator.next();
    System.out.println(name);
}
```

---

## next()

**Определение:**

`next()` — это метод итератора, который возвращает следующий элемент коллекции.

После вызова `next()` итератор переходит к следующей позиции.

Перед `next()` обычно вызывают `hasNext()`.

**Пример:**

```java
Iterator<String> iterator = names.iterator();

String first = iterator.next();
```

---

## remove() у Iterator

**Определение:**

`remove()` у `Iterator` удаляет последний элемент, который был получен через `next()`.

Этот способ используют, когда нужно безопасно удалять элементы во время обхода коллекции.

Если удалять элементы из списка обычным способом во время перебора, можно получить `ConcurrentModificationException`.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");
names.add("Tanya");

Iterator<String> iterator = names.iterator();

while (iterator.hasNext()) {
    String name = iterator.next();

    if (name.startsWith("O")) {
        iterator.remove();
    }
}

System.out.println(names); // [Petya, Tanya]
```

---

## foreach

**Определение:**

`foreach` — это упрощённый цикл для перебора элементов массива или коллекции.

Он удобен, когда нужно просто пройти по всем элементам и не нужен индекс.

В Java foreach записывается через двоеточие внутри `for`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya");

for (String name : names) {
    System.out.println(name);
}
```

---

## ConcurrentModificationException

**Определение:**

`ConcurrentModificationException` — это исключение, которое может возникнуть, если коллекцию изменить неправильным способом во время её обхода.

Например, если удалить элемент из `ArrayList` внутри foreach через `list.remove()`.

Для безопасного удаления во время обхода используют `Iterator.remove()`.

**Пример неправильного кода:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

for (String name : names) {
    if (name.equals("Olya")) {
        names.remove(name);
    }
}
```

Правильно:

```java
Iterator<String> iterator = names.iterator();

while (iterator.hasNext()) {
    String name = iterator.next();

    if (name.equals("Olya")) {
        iterator.remove();
    }
}
```

---

## NoSuchElementException

**Определение:**

`NoSuchElementException` — это unchecked exception, которое возникает, если попытаться получить следующий элемент, когда его уже нет.

Например, если вызвать `next()` у итератора без проверки `hasNext()`.

**Пример:**

```java
List<String> names = List.of("Petya");

Iterator<String> iterator = names.iterator();

System.out.println(iterator.next()); // Petya
System.out.println(iterator.next()); // ошибка
```

---

## LinkedList

**Определение:**

`LinkedList` — это реализация `List` на основе двусвязного списка.

Каждый элемент хранит ссылку на предыдущий и следующий элемент.

`LinkedList` может быть удобен, когда нужно часто добавлять или удалять элементы в начале, конце или в середине после перехода к нужному месту.

Но `LinkedList` обычно потребляет больше памяти, чем `ArrayList`, и медленнее работает при частом доступе по индексу.

**Пример:**

```java
LinkedList<String> names = new LinkedList<>();

names.add("Petya");
names.addFirst("Olya");
names.addLast("Tanya");

System.out.println(names); // [Olya, Petya, Tanya]
```

---

## Двусвязный список

**Определение:**

Двусвязный список — это структура данных, где каждый элемент знает предыдущий и следующий элемент.

В отличие от массива, элементы не обязаны лежать в памяти подряд.

Из-за этого вставка и удаление могут быть эффективными, но доступ по индексу медленнее, потому что нужно идти по цепочке элементов.

**Пример:**

```java
LinkedList<String> names = new LinkedList<>();

names.addFirst("First");
names.addLast("Last");
```

## Vector

**Определение:**

`Vector` — это устаревшая реализация `List`, похожая на `ArrayList`.

Главное отличие: многие методы `Vector` синхронизированы, то есть рассчитаны на работу с несколькими потоками.

В современном коде `Vector` используют редко. Обычно выбирают `ArrayList`, а для многопоточных задач — более современные коллекции из `java.util.concurrent`.

**Пример:**

```java
List<String> names = new Vector<>();

names.add("Petya");
names.add("Olya");
```

## synchronized

**Определение:**

`synchronized` — это механизм Java, который ограничивает одновременный доступ нескольких потоков к одному участку кода или объекту.

В контексте `Vector` это значит, что операции изменения коллекции выполняются с синхронизацией.

Это безопаснее для многопоточности, но может быть медленнее.

**Пример:**

```java
public synchronized void addValue(String value) {
    // одновременно этот метод сможет выполнять только один поток
}
```

## Arrays.asList()

**Определение:**

`Arrays.asList()` — это метод, который создаёт список на основе переданных элементов или массива.

Его часто используют, когда нужно быстро передать набор значений в методы вроде `removeAll()` или `retainAll()`.

Важно: список, созданный через `Arrays.asList()`, имеет фиксированный размер. В него нельзя добавлять новые элементы через `add()`.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Tom");
names.add("Alice");
names.add("Mark");

names.removeAll(Arrays.asList("Mark", "Alice"));

System.out.println(names); // [Tom]
```

---

## List.of()

**Определение:**

`List.of()` — это удобный способ создать небольшой неизменяемый список.

Такой список нельзя изменять: нельзя вызвать `add()`, `remove()` или `set()`.

Если нужен изменяемый список, его можно передать в конструктор `ArrayList`.

**Пример:**

```java
List<String> names = List.of("Petya", "Olya", "Tanya");
```

Изменяемый вариант:

```java
List<String> names = new ArrayList<>(List.of("Petya", "Olya", "Tanya"));

names.add("Max");
```

---

## Начальная ёмкость

**Определение:**

Начальная ёмкость — это размер внутреннего массива, который `ArrayList` создаёт заранее.

Если заранее известно, что в список будет добавлено много элементов, начальная ёмкость помогает уменьшить количество расширений массива.

Это может улучшить производительность при массовом добавлении данных.

**Пример:**

```java
List<Integer> numbers = new ArrayList<>(10_000);
```

---

## Доступ по индексу

**Определение:**

Доступ по индексу — это получение элемента по его номеру в списке.

`ArrayList` хорошо подходит для частого доступа по индексу.

`LinkedList` для этого подходит хуже, потому что ему нужно пройти по цепочке элементов до нужной позиции.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Olya");

System.out.println(names.get(1)); // Olya
```

---

## Вставка в середину списка

**Определение:**

Вставка в середину списка — это добавление элемента не в конец, а между уже существующими элементами.

В `ArrayList` такая операция может быть дорогой, потому что элементы справа нужно сдвинуть.

В `LinkedList` сама вставка может быть быстрой, но сначала нужно дойти до нужного места.

**Пример:**

```java
List<String> names = new ArrayList<>();

names.add("Petya");
names.add("Tanya");

names.add(1, "Olya");

System.out.println(names); // [Petya, Olya, Tanya]
```
