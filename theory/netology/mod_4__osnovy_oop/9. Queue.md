# Тема 9: Коллекции Queue

## Queue

**Определение:**

`Queue` — это интерфейс Java, который описывает очередь элементов.

Очередь обычно работает по принципу FIFO: первый добавленный элемент будет первым извлечён.

`Queue` удобно использовать, когда нужно обрабатывать элементы в порядке поступления: задачи, сообщения, события, запросы.

Очереди в Java не должны содержать `null`, потому что некоторые методы используют `null` как признак пустой очереди.

**Пример:**

```java id="5pbsgu"
Queue<String> messages = new LinkedList<>();

messages.offer("Message 1");
messages.offer("Message 2");

System.out.println(messages.poll()); // Message 1
System.out.println(messages.poll()); // Message 2
```

---

## Очередь

**Определение:**

Очередь — это структура данных, в которую элементы добавляются с одного конца, а извлекаются с другого.

Обычная очередь работает так же, как очередь в магазине: кто пришёл первым, того обслужили первым.

В Java очередь описывается интерфейсом `Queue`.

**Пример:**

```java id="izdl4z"
Queue<String> tasks = new LinkedList<>();

tasks.offer("Task 1");
tasks.offer("Task 2");
tasks.offer("Task 3");

System.out.println(tasks.poll()); // Task 1
```

---

## FIFO

**Определение:**

`FIFO` означает `First In, First Out`.

Это принцип работы очереди: первый добавленный элемент извлекается первым.

FIFO используют, когда важно сохранить порядок обработки элементов.

**Пример:**

```java id="s5gbje"
Queue<String> queue = new LinkedList<>();

queue.offer("A");
queue.offer("B");
queue.offer("C");

System.out.println(queue.poll()); // A
System.out.println(queue.poll()); // B
```

---

## add() у Queue

**Определение:**

`add()` у `Queue` добавляет элемент в очередь.

Если добавление прошло успешно, метод возвращает `true`.

Если элемент добавить нельзя, метод выбрасывает исключение.

В обычном коде для очередей чаще используют `offer()`, потому что он не падает исключением при неудачном добавлении, а возвращает `false`.

**Пример:**

```java id="iesp4h"
Queue<String> queue = new LinkedList<>();

queue.add("Task 1");
queue.add("Task 2");
```

---

## offer()

**Определение:**

`offer()` — это метод `Queue`, который добавляет элемент в конец очереди.

Если элемент успешно добавлен, метод возвращает `true`.

Если добавить элемент не удалось, метод возвращает `false`.

В продакшене `offer()` часто предпочтительнее `add()`, особенно когда очередь может иметь ограничение по размеру.

**Пример:**

```java id="eyl3fg"
Queue<String> queue = new LinkedList<>();

boolean added = queue.offer("Task 1");

System.out.println(added); // true
```

---

## element()

**Определение:**

`element()` — это метод `Queue`, который возвращает первый элемент очереди, но не удаляет его.

Если очередь пустая, метод выбрасывает `NoSuchElementException`.

Из-за исключения в пустой очереди часто удобнее использовать `peek()`.

**Пример:**

```java id="8w3ipp"
Queue<String> queue = new LinkedList<>();

queue.offer("Task 1");

System.out.println(queue.element()); // Task 1
System.out.println(queue);           // [Task 1]
```

---

## peek()

**Определение:**

`peek()` — это метод `Queue`, который возвращает первый элемент очереди, но не удаляет его.

Если очередь пустая, метод возвращает `null`.

`peek()` удобен, когда нужно посмотреть следующий элемент без изменения очереди.

**Пример:**

```java id="dqpwma"
Queue<String> queue = new LinkedList<>();

queue.offer("Task 1");

System.out.println(queue.peek()); // Task 1
System.out.println(queue.peek()); // Task 1
```

---

## remove() у Queue

**Определение:**

`remove()` у `Queue` возвращает первый элемент очереди и удаляет его.

Если очередь пустая, метод выбрасывает `NoSuchElementException`.

В обычном коде часто безопаснее использовать `poll()`, потому что он возвращает `null`, если очередь пустая.

**Пример:**

```java id="uq0a0v"
Queue<String> queue = new LinkedList<>();

queue.offer("Task 1");
queue.offer("Task 2");

System.out.println(queue.remove()); // Task 1
System.out.println(queue);          // [Task 2]
```

---

## poll()

**Определение:**

`poll()` — это метод `Queue`, который возвращает первый элемент очереди и удаляет его.

Если очередь пустая, метод возвращает `null`.

`poll()` часто используют в цикле обработки задач.

**Пример:**

```java id="k0y59o"
Queue<String> queue = new LinkedList<>();

queue.offer("Task 1");
queue.offer("Task 2");

String task;

while ((task = queue.poll()) != null) {
    System.out.println("Обрабатываем: " + task);
}
```

## Методы с исключением

**Определение:**

Методы с исключением — это методы очереди, которые выбрасывают ошибку, если операция невозможна.

В `Queue` к ним относятся:

`add()` — может выбросить исключение, если элемент нельзя добавить;

`element()` — выбрасывает `NoSuchElementException`, если очередь пустая;

`remove()` — выбрасывает `NoSuchElementException`, если очередь пустая.

**Пример:**

```java id="q531vy"
Queue<String> queue = new LinkedList<>();

System.out.println(queue.remove()); // NoSuchElementException
```

---

## Методы без исключения

**Определение:**

Методы без исключения — это методы очереди, которые при невозможности выполнить операцию возвращают специальное значение.

В `Queue` к ним относятся:

`offer()` — возвращает `false`, если элемент нельзя добавить;

`peek()` — возвращает `null`, если очередь пустая;

`poll()` — возвращает `null`, если очередь пустая.

Эти методы часто удобнее для безопасной обработки очереди.

**Пример:**

```java id="0ipj6j"
Queue<String> queue = new LinkedList<>();

String task = queue.poll();

if (task == null) {
    System.out.println("Очередь пустая");
}
```

## Извлечение элемента

**Определение:**

Извлечение элемента — это получение элемента из очереди с одновременным удалением его из коллекции.

В `Queue` для этого используют методы `poll()` или `remove()`.

`poll()` возвращает `null`, если очередь пустая.

`remove()` выбрасывает исключение, если очередь пустая.

**Пример:**

```java id="bq2rug"
Queue<String> queue = new LinkedList<>();

queue.offer("Message 1");

String message = queue.poll();

System.out.println(message); // Message 1
System.out.println(queue);   // []
```

## Просмотр элемента

**Определение:**

Просмотр элемента — это получение элемента из очереди без удаления.

В `Queue` для этого используют методы `peek()` или `element()`.

`peek()` возвращает `null`, если очередь пустая.

`element()` выбрасывает исключение, если очередь пустая.

**Пример:**

```java id="8enblj"
Queue<String> queue = new LinkedList<>();

queue.offer("Message 1");

System.out.println(queue.peek()); // Message 1
System.out.println(queue);        // [Message 1]
```

## PriorityQueue

**Определение:**

`PriorityQueue` — это реализация очереди, в которой элементы извлекаются не обязательно в порядке добавления, а по приоритету.

Приоритет определяется естественным порядком элементов или переданным `Comparator`.

`PriorityQueue` удобно использовать, когда сначала нужно обрабатывать самые важные, самые маленькие, самые ранние или самые приоритетные элементы.

`PriorityQueue` не поддерживает хранение `null`.

**Пример:**

```java id="w01vlf"
Queue<Integer> numbers = new PriorityQueue<>();

numbers.offer(30);
numbers.offer(10);
numbers.offer(20);

System.out.println(numbers.poll()); // 10
System.out.println(numbers.poll()); // 20
System.out.println(numbers.poll()); // 30
```

---

## Приоритетная очередь

**Определение:**

Приоритетная очередь — это очередь, в которой порядок обработки определяется приоритетом элементов.

В отличие от обычной FIFO-очереди, первым извлекается не обязательно тот элемент, который был добавлен первым.

В Java приоритетная очередь реализуется классом `PriorityQueue`.

**Пример:**

```java id="7jus16"
Queue<String> queue = new PriorityQueue<>();

queue.offer("C");
queue.offer("A");
queue.offer("B");

System.out.println(queue.poll()); // A
```

---

## Natural ordering

**Определение:**

`Natural ordering` — это естественный порядок сортировки элементов.

Для чисел это сортировка по возрастанию.

Для строк — лексикографический порядок.

`PriorityQueue` использует natural ordering по умолчанию, если не передан свой `Comparator`.

**Пример:**

```java id="lq5r6l"
Queue<String> queue = new PriorityQueue<>();

queue.offer("banana");
queue.offer("apple");
queue.offer("orange");

System.out.println(queue.poll()); // apple
```

## Очередь как буфер

**Определение:**

Очередь как буфер — это использование очереди между источником данных и обработчиком.

Источник добавляет элементы в очередь.

Обработчик постепенно забирает элементы из очереди.

Такой подход помогает сгладить нагрузку, если данные поступают быстрее, чем программа успевает их обрабатывать.

**Пример:**

```java id="bg4sj3"
Queue<String> emailQueue = new LinkedList<>();

emailQueue.offer("email-1");
emailQueue.offer("email-2");

String email = emailQueue.poll();

System.out.println("Отправляем: " + email);
```

## ArrayBlockingQueue

**Определение:**

`ArrayBlockingQueue` — это очередь фиксированного размера на основе массива.

Она относится к потокобезопасным очередям и используется в многопоточном программировании.

Если очередь заполнена, добавление элемента может быть заблокировано или завершиться неудачно в зависимости от метода.

**Пример:**

```java id="88t9zs"
BlockingQueue<String> queue = new ArrayBlockingQueue<>(2);

queue.offer("A");
queue.offer("B");

System.out.println(queue.offer("C")); // false
```

Она подходит для многопоточных сценариев, где несколько потоков могут одновременно добавлять и извлекать элементы.

**Пример:**

## Deque

**Определение:**

`Deque` — это интерфейс двунаправленной очереди.

Название читается как `deck` и означает `Double Ended Queue`.

В `Deque` можно добавлять и извлекать элементы с обоих концов: из начала и из конца.

`Deque` может работать и как обычная очередь FIFO, и как стек LIFO.

**Пример:**

```java id="z69e0d"
Deque<String> deque = new ArrayDeque<>();

deque.offerLast("A");
deque.offerLast("B");

System.out.println(deque.pollFirst()); // A
```

---

## Двусторонняя очередь

**Определение:**

Двусторонняя очередь — это очередь, в которой можно работать с двумя концами.

Можно добавить элемент в начало или конец.

Можно извлечь элемент из начала или конца.

В Java такую структуру описывает интерфейс `Deque`.

**Пример:**

```java id="05qebb"
Deque<String> deque = new ArrayDeque<>();

deque.addFirst("first");
deque.addLast("last");

System.out.println(deque.pollFirst()); // first
System.out.println(deque.pollLast());  // last
```

---

## LIFO

**Определение:**

`LIFO` означает `Last In, First Out`.

Это принцип работы стека: последний добавленный элемент извлекается первым.

`Deque` можно использовать как стек, если добавлять и извлекать элементы с одного конца.

**Пример:**

```java id="l3ttzj"
Deque<String> stack = new ArrayDeque<>();

stack.push("A");
stack.push("B");
stack.push("C");

System.out.println(stack.pop()); // C
System.out.println(stack.pop()); // B
```

## ArrayDeque

**Определение:**

`ArrayDeque` — это реализация интерфейса `Deque` на основе динамического массива.

`ArrayDeque` часто используют как очередь или как стек.

Обычно `ArrayDeque` быстрее и экономнее по памяти, чем `LinkedList`, если нужно работать с началом и концом очереди.

`ArrayDeque` не допускает `null`.

**Пример:**

```java id="4ip0vx"
Deque<String> messages = new ArrayDeque<>();

messages.addLast("Message 2");

```

## Возврат элемента в начало очереди

**Определение:**

Возврат элемента в начало очереди — это сценарий, когда элемент уже был извлечён, но его не удалось обработать, и его нужно вернуть обратно первым на обработку.

Для такого сценария удобен `Deque`, потому что он позволяет добавить элемент в начало через `addFirst()` или `offerFirst()`.

Обычная `Queue` может добавить элемент только в конец.

**Пример:**

```java id="l2b620"
Deque<String> messages = new ArrayDeque<>();

messages.addLast("Message 1");
messages.addLast("Message 2");

String message = messages.pollFirst();

System.out.println(messages); // [Message 2]

// обработать message не получилось
messages.addFirst(message);

System.out.println(messages); // [Message 1, Message 2]
```

## LinkedList vs ArrayDeque

**Определение:**

`LinkedList` и `ArrayDeque` оба могут использоваться как `Deque`.

Но в большинстве случаев для очереди или стека лучше выбрать `ArrayDeque`.

Причины:

`ArrayDeque` обычно быстрее при добавлении и удалении с концов;

`ArrayDeque` потребляет меньше памяти;

`LinkedList` хранит для каждого элемента дополнительные ссылки на соседние элементы.

`LinkedList` имеет смысл использовать только там, где действительно нужны особенности связанного списка.

**Пример:**

```java id="qaf21q"
Deque<String> deque = new ArrayDeque<>();
```

Обычно лучше так, чем:

```java id="8nxl2i"
Deque<String> deque = new LinkedList<>();
```

## Stack

**Определение:**

`Stack` — это класс Java, который реализует структуру данных «стек».

Стек работает по принципу LIFO: последний вошёл, первый вышел.

`Stack` считается устаревшим выбором, потому что он основан на `Vector`, а `Vector` использует синхронизированные операции.

В современном Java-коде вместо `Stack` обычно используют `Deque`, чаще всего `ArrayDeque`.

**Пример:**

```java id="l5j1vi"
Deque<Integer> stack = new ArrayDeque<>();

stack.push(10);
stack.push(20);

System.out.println(stack.pop()); // 20
```

---

## Стек

**Определение:**

Стек — это структура данных, в которой последним добавленный элемент извлекается первым.

Пример из жизни: стопка тарелок. Последнюю поставили сверху — её первой и возьмём.

В Java стек лучше реализовывать через `Deque`, а не через старый класс `Stack`.

**Пример:**

```java id="igjj9o"
Deque<String> stack = new ArrayDeque<>();

stack.push("first");
stack.push("second");

System.out.println(stack.pop()); // second
```

---

## push()

**Определение:**

`push()` — это метод `Deque`, который добавляет элемент в начало дека.

При использовании `Deque` как стека `push()` добавляет элемент на вершину стека.

**Пример:**

```java id="g4yv0d"
Deque<String> stack = new ArrayDeque<>();

stack.push("A");
stack.push("B");

System.out.println(stack); // [B, A]
```

---

## pop()

**Определение:**

`pop()` — это метод `Deque`, который возвращает и удаляет первый элемент дека.

При использовании `Deque` как стека `pop()` снимает верхний элемент стека.

Если стек пустой, метод выбрасывает `NoSuchElementException`.

**Пример:**

```java id="4ck1r6"
Deque<String> stack = new ArrayDeque<>();

stack.push("A");
stack.push("B");

System.out.println(stack.pop()); // B
System.out.println(stack.pop()); // A
```

---

## empty()

**Определение:**

`empty()` — это метод старого класса `Stack`, который проверяет, пустой ли стек.

Возвращает `true`, если элементов нет.

В современном коде при использовании `Deque` вместо него используют `isEmpty()`.

**Пример:**

```java id="u56va7"
Stack<String> stack = new Stack<>();

System.out.println(stack.empty()); // true
```

Современный вариант:

```java id="fwik02"
Deque<String> stack = new ArrayDeque<>();

System.out.println(stack.isEmpty()); // true
```

---

## search()

**Определение:**

`search()` — это метод старого класса `Stack`, который ищет элемент в стеке и возвращает его позицию.

Если элемент не найден, возвращает `-1`.

В современном коде класс `Stack` обычно не используют, поэтому `search()` встречается редко.

**Пример:**

```java id="0628qa"
Stack<String> stack = new Stack<>();

stack.push("A");
stack.push("B");

System.out.println(stack.search("B")); // 1
```

---

## BlockingQueue

**Определение:**

`BlockingQueue` — это интерфейс очереди для многопоточного программирования.

Такая очередь может блокировать поток, если очередь пустая при чтении или заполнена при записи.

`BlockingQueue` полезна, когда один поток производит задачи, а другой поток их обрабатывает.

**Пример:**

```java id="btvk4j"
BlockingQueue<String> queue = new ArrayBlockingQueue<>(10);

queue.offer("Task 1");
```

---

## Producer-consumer

**Определение:**

`Producer-consumer` — это схема, где один код производит задачи, а другой код их потребляет и обрабатывает.

Очередь используется как буфер между производителем и потребителем.

В Java для таких задач часто используют `BlockingQueue`.

**Пример:**

```java id="tki33c"
Queue<String> queue = new LinkedList<>();

queue.offer("email-1"); // producer добавил задачу

String task = queue.poll(); // consumer забрал задачу
```
