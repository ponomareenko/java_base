# Тема 5: Типы данных Java. Объекты

---

## 1. Типы данных в Java

**Определение:**

В Java типы данных делятся на две основные группы: примитивные типы и ссылочные типы.

**Пример:**

```java
int age = 25;              // примитивный тип
String name = "Danil";     // ссылочный тип
```

**Важно:**

Примитивные типы хранят само значение, а ссылочные типы хранят ссылку на объект в памяти.

---

## 2. Примитивные типы данных

**Определение:**

Примитивные типы данных — это базовые типы Java, которые хранят простые значения.

**Пример:**

```java
int count = 10;
double price = 99.99;
boolean isActive = true;
char letter = 'A';
```

**Важно:**

Примитивные типы не являются объектами.

---

## 3. Ссылочные типы данных

**Определение:**

Ссылочные типы данных — это типы, переменные которых хранят не сам объект, а ссылку на объект в памяти.

**Пример:**

```java
String text = "Hello world";
Object object = new Object();
```

**Важно:**

Почти всё в Java, кроме примитивных типов, является объектом.

---

## 4. Объект

**Определение:**

Объект — это сущность, созданная на основе класса и размещённая в памяти.

**Пример:**

```java
Object object = new Object();
```

**Важно:**

Класс описывает, каким должен быть объект, а объект — это уже конкретный экземпляр этого класса.

---

## 5. Ссылка

**Определение:**

Ссылка — это значение переменной ссылочного типа, которое указывает на объект в памяти.

**Пример:**

```java
String message = "Hello";
```

В этом примере переменная `message` хранит ссылку на объект строки.

**Важно:**

Ссылочная переменная может указывать на объект или иметь значение `null`.

---

## 6. `heap`

**Определение:**

`heap` — область памяти JVM, в которой создаются и хранятся объекты.

**Пример:**

```java
Object object = new Object();
```

В этом примере объект создаётся в `heap`, а переменная `object` хранит ссылку на него.

**Важно:**

Примитивные значения и ссылки могут храниться иначе, но сами объекты создаются в `heap`.

---

## 7. `null`

**Определение:**

`null` — специальное значение в Java, которое означает, что ссылочная переменная не указывает ни на какой объект.

**Пример:**

```java
String message = null;
Object object = null;
```

**Важно:**

Если попытаться вызвать метод у переменной со значением `null`, программа получит ошибку `NullPointerException`.

**Пример ошибки:**

```java
String message = null;

System.out.println(message.length()); // NullPointerException
```

---

## 8. `NullPointerException`

**Определение:**

`NullPointerException` — ошибка, которая возникает при попытке обратиться к объекту через ссылку, равную `null`.

**Пример:**

```java
String text = null;

System.out.println(text.length());
```

**Важно:**

Перед вызовом методов у переменной, которая может быть `null`, нужно делать проверку или писать код так, чтобы избежать обращения к `null`.

---

## 9. `new`

**Определение:**

`new` — оператор, который создаёт новый объект в памяти.

**Пример:**

```java
Object object = new Object();
```

**Важно:**

После `new` обычно вызывается конструктор класса.

---

## 10. Конструктор

**Определение:**

Конструктор — специальный метод класса, который вызывается при создании объекта.

**Пример:**

```java
Object object = new Object();
```

Здесь `Object()` — конструктор класса `Object`.

**Важно:**

Конструктор нужен для создания объекта и начальной настройки его состояния.

---

## 11. `Object`

**Определение:**

`Object` — базовый класс Java, от которого по умолчанию наследуются все классы.

**Пример:**

```java
Object object = new Object();
String text = "Hello";
```

**Важно:**

Даже `String` является объектом и наследуется от `Object`.

---

## 12. Класс

**Определение:**

Класс — это описание будущего объекта: его данных и поведения.

**Пример:**

```java
class User {
    String name;
    int age;
}
```

**Важно:**

Класс сам по себе является чертежом. Объект — это экземпляр, созданный по этому чертежу.

---

## 13. Экземпляр класса

**Определение:**

Экземпляр класса — это конкретный объект, созданный на основе класса.

**Пример:**

```java
User user = new User();
```

В этом примере `user` — ссылка на экземпляр класса `User`.

---

## 14. `String`

**Определение:**

`String` — ссылочный тип данных, который используется для хранения строк.

**Пример:**

```java
String message = "Hello world";
```

**Важно:**

`String` — это класс, а не примитивный тип.

---

## 15. Создание строки

**Определение:**

Строку можно создать с помощью строкового литерала или через конструктор класса `String`.

**Пример через литерал:**

```java
String message = "Hello world";
```

**Пример через `new`:**

```java
String message = new String("Hello world");
```

**Важно:**

Обычно строки создают через литерал. Вариант `new String(...)` почти всегда избыточен.

---

## 16. Строковый литерал

**Определение:**

Строковый литерал — это строка, написанная прямо в коде в двойных кавычках.

**Пример:**

```java
String text = "Hello";
```

В этом примере `"Hello"` — строковый литерал.

---

## 17. Конкатенация строк

**Определение:**

Конкатенация строк — это объединение строк в одну строку.

**Пример:**

```java
String first = "Hello";
String second = "world";

String result = first + " " + second;

System.out.println(result); // Hello world
```

**Важно:**

Оператор `+` можно использовать для простого объединения строк.

---

## 18. Сравнение строк

**Определение:**

Сравнение строк — это проверка, одинаковое ли содержимое находится в строковых объектах.

**Неправильный способ:**

```java
String s1 = "Welcome to netology";
String s2 = "Welcome to netology";

System.out.println(s1 == s2);
```

**Правильный способ:**

```java
String s1 = "Welcome to netology";
String s2 = "Welcome to netology";

System.out.println(s1.equals(s2));
```

**Важно:**

`==` сравнивает ссылки.
`equals()` сравнивает содержимое строк.

---

## 19. `==` для ссылочных типов

**Определение:**

Для ссылочных типов оператор `==` сравнивает не содержимое объектов, а ссылки на объекты.

**Пример:**

```java
String s1 = new String("Hello");
String s2 = new String("Hello");

System.out.println(s1 == s2);      // false
System.out.println(s1.equals(s2)); // true
```

**Важно:**

Если два объекта имеют одинаковое содержимое, это ещё не значит, что ссылки на них равны.

---

## 20. `equals()`

**Определение:**

`equals()` — метод, который используется для сравнения содержимого объектов.

**Пример:**

```java
String first = "Hello";
String second = "Hello";

System.out.println(first.equals(second)); // true
```

**Важно:**

Для строк почти всегда нужно использовать `equals()`, а не `==`.

---

## 21. `length()`

**Определение:**

`length()` — метод класса `String`, который возвращает количество символов в строке.

**Пример:**

```java
String text = "Welcome to netology";

int textLength = text.length();

System.out.println(textLength); // 19
```

---

## 22. `charAt()`

**Определение:**

`charAt()` — метод класса `String`, который возвращает символ строки по указанному индексу.

**Пример:**

```java
String text = "Welcome";

char symbol = text.charAt(0);

System.out.println(symbol); // W
```

**Важно:**

Индексация в строках начинается с нуля.

---

## 23. Индекс

**Определение:**

Индекс — это номер позиции элемента в строке, массиве или коллекции.

**Пример:**

```java
String text = "Java";

System.out.println(text.charAt(0)); // J
System.out.println(text.charAt(1)); // a
System.out.println(text.charAt(2)); // v
System.out.println(text.charAt(3)); // a
```

**Важно:**

Первый символ имеет индекс `0`, а не `1`.

---

## 24. `StringBuilder`

**Определение:**

`StringBuilder` — класс для эффективного создания и изменения строк.

**Пример:**

```java
StringBuilder result = new StringBuilder();

result.append("The lesson");
result.append(" ");
result.append("about");
result.append(" ");
result.append("objects");

String text = result.toString();

System.out.println(text);
```

**Важно:**

`StringBuilder` полезен, когда строка собирается постепенно из нескольких частей, особенно в цикле.

---

## 25. `append()`

**Определение:**

`append()` — метод класса `StringBuilder`, который добавляет значение в конец строки, собираемой внутри `StringBuilder`.

**Пример:**

```java
StringBuilder builder = new StringBuilder();

builder.append("Hello");
builder.append(" ");
builder.append("world");

System.out.println(builder.toString());
```

---

## 26. `toString()`

**Определение:**

`toString()` — метод, который возвращает строковое представление объекта.

**Пример:**

```java
Object object = new Object();

System.out.println(object.toString());
```

**Пример со `StringBuilder`:**

```java
StringBuilder builder = new StringBuilder();

builder.append("Hello");

String result = builder.toString();
```

**Важно:**

У `StringBuilder` метод `toString()` нужен, чтобы получить обычную строку `String`.

---

## 27. `Enum`

**Определение:**

`Enum` — специальный тип данных, который описывает набор именованных констант.

**Пример:**

```java
enum Season {
    AUTUMN,
    WINTER,
    SPRING,
    SUMMER
}
```

**Использование:**

```java
Season season = Season.AUTUMN;

System.out.println(season);
```

**Важно:**

`Enum` удобно использовать, когда значение может быть только одним из заранее известных вариантов.

---

## 28. Константа

**Определение:**

Константа — это значение, которое не должно изменяться во время работы программы.

**Пример в `enum`:**

```java
enum Season {
    AUTUMN,
    WINTER,
    SPRING,
    SUMMER
}
```

Здесь `AUTUMN`, `WINTER`, `SPRING`, `SUMMER` — константы перечисления.

---

## 29. Именованная константа

**Определение:**

Именованная константа — это постоянное значение, у которого есть понятное имя.

**Пример:**

```java
enum Role {
    ADMIN,
    USER,
    GUEST
}
```

**Важно:**

Именованные константы делают код понятнее и уменьшают риск ошибок из-за случайных строк или чисел.

---

## 30. Класс-оболочка

**Определение:**

Класс-оболочка — это ссылочный аналог примитивного типа данных.

**Примеры соответствий:**

```text
byte    -> Byte
short   -> Short
int     -> Integer
long    -> Long
float   -> Float
double  -> Double
char    -> Character
boolean -> Boolean
```

**Пример:**

```java
Integer age = 25;
Double price = 99.99;
Boolean isActive = true;
```

**Важно:**

Классы-оболочки нужны, когда с примитивными значениями нужно работать как с объектами.

---

## 31. `Integer`

**Определение:**

`Integer` — класс-оболочка для примитивного типа `int`.

**Пример:**

```java
Integer number = 10;
```

**Пример преобразования строки в число:**

```java
int year = Integer.parseInt("1901");
```

---

## 32. `parseInt()`

**Определение:**

`parseInt()` — метод класса `Integer`, который преобразует строку в число типа `int`.

**Пример:**

```java
int year = Integer.parseInt("1901");

System.out.println(year);
```

**Важно:**

Если строка не содержит корректное число, будет ошибка `NumberFormatException`.

**Пример ошибки:**

```java
int number = Integer.parseInt("abc"); // NumberFormatException
```

---

## 33. `NumberFormatException`

**Определение:**

`NumberFormatException` — ошибка, которая возникает при попытке преобразовать строку в число, если строка имеет неправильный формат.

**Пример:**

```java
int number = Integer.parseInt("hello");
```

**Важно:**

Перед преобразованием пользовательского ввода в число нужно учитывать, что пользователь может ввести не число.

---

## 34. Метод

**Определение:**

Метод — это именованный блок кода, который выполняет определённое действие.

**Пример:**

```java
String text = "Hello";

int length = text.length();
```

В этом примере `length()` — метод.

---

## 35. Методы класса `Object`

**Определение:**

Методы класса `Object` — это методы, которые доступны всем объектам в Java, потому что все классы наследуются от `Object`.

**Примеры методов:**

```java
toString()
equals()
hashCode()
```

**Важно:**

В презентации также упоминаются методы `wait()`, `notify()` и `notifyAll()`, но они относятся к теме многопоточности и обычно изучаются позже.
