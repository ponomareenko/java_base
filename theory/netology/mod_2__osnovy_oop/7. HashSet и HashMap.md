# Словарь разработчика — Тема 7. HashSet и HashMap

---

## 1. Хеширование (Hashing)

### Определение

Механизм преобразования объекта в числовой код (**hashCode**), который используется для быстрого поиска данных.

### Короткое определение

**Хеширование = получение цифрового адреса объекта.**

### Мини-пример

```java
String name = "Petya";

System.out.println(name.hashCode());
```

Вывод:

```text
76991546
```

---

## 2. hashCode()

### Определение

Метод объекта, который возвращает число для размещения объекта внутри хеш-таблицы.

Используется в:

* HashMap
* HashSet
* HashTable

### Короткое определение

**hashCode = код для быстрого поиска.**

### Мини-пример

```java
String s = "abc";

int hash = s.hashCode();
```

---

## 3. Хеш-таблица (Hash Table)

### Определение

Структура данных для хранения пар:
**ключ → значение**

Поиск выполняется через хеш.

### Короткое определение

**Хеш-таблица = быстрый словарь.**

### Мини-пример

```java
Map<Integer, String> users =
        new HashMap<>();

users.put(1, "Tom");
```

---

## 4. Коллизия (Collision)

### Определение

Ситуация, когда разные объекты получили одинаковый hashCode.

Тогда Java дополнительно вызывает `equals()`.

### Короткое определение

**Коллизия = одинаковый хеш у разных объектов.**

### Мини-пример

```java
"Aa".hashCode()
"BB".hashCode()
```

Могут совпасть.

---

## 5. Bucket (Бакет)

### Определение

Ячейка внутреннего массива HashMap, куда складываются элементы с одинаковым хешем.

### Короткое определение

**Bucket = корзина хранения.**

### Мини-пример

```text
bucket[5]
 ├─ Tom
 └─ Max
```

---

## 6. Map

### Определение

Интерфейс для хранения данных как:

**ключ → значение**

Ключи уникальны.

### Короткое определение

**Map = словарь.**

### Мини-пример

```java
Map<Integer, String> users =
        new HashMap<>();
```

---

## 7. HashMap

### Определение

Реализация `Map`, основанная на хеш-таблице.

Очень быстро:

* поиск
* добавление
* удаление

Средняя сложность:

```text
O(1)
```

### Короткое определение

**HashMap = быстрый поиск по ключу.**

### Мини-пример

```java
Map<Integer, String> users =
        new HashMap<>();

users.put(1, "Anna");

System.out.println(
        users.get(1)
);
```

---

### Определение

Уникальный идентификатор значения в Map.

map.put(100, "Tom");

## 9. Значение (Value)

### Определение

Данные, связанные с ключом.

### Короткое определение

**Value = что хранится.**

### Мини-пример

```java
map.put(100, "Tom");
```

Значение:

```text
Tom
```

### Определение

Тип:

Map.Entry<K, V>

## 11. equals()

### Определение

Метод сравнения объектов по содержимому.

Используется вместе с `hashCode()`.

### Короткое определение

**equals = одинаковые ли данные.**

### Мини-пример

```java
"abc".equals("abc")
```

↓

```text
true
```

---

## 12. Контракт equals() и hashCode()

### Определение

Правило Java:

Если:

```java
a.equals(b)
```

то обязательно:

```java
a.hashCode() == b.hashCode()
```

Обратное не обязательно.

### Короткое определение

**Одинаковые объекты → одинаковый hash.**

### Мини-пример

```java
user1.equals(user2);

user1.hashCode()
==
user2.hashCode()
```

## 13. Immutable (Неизменяемый объект)

### Определение

Объект, состояние которого нельзя изменить после создания.

Часто используется как ключ в HashMap.

### Короткое определение

**Immutable = создал → больше не меняется.**

### Мини-пример

```java
public final class User {
}
```

---

## 14. Set

### Определение

Коллекция уникальных элементов.

Порядок обычно не гарантируется.

### Короткое определение

**Set = без повторений.**

### Мини-пример

```java
Set<String> set =
        new HashSet<>();
```

---

## 15. HashSet

### Определение

Реализация `Set`, основанная внутри на `HashMap`.

Хранит только уникальные элементы.

### Короткое определение

**HashSet = быстрый поиск уникальных значений.**

### Мини-пример

```java
Set<String> names =
        new HashSet<>();

names.add("Tom");
names.add("Tom");

System.out.println(
        names.size()
);
```

↓

```text
1
```

---

## 16. Дубликат (Duplicate)

### Определение

Повторяющийся элемент.

### Короткое определение

**Дубликат = одинаковое значение дважды.**

### Мини-пример

```java
set.add("A");
set.add("A");
```

Второй элемент не добавится.

---

## 17. Сложность алгоритма O(1)

### Определение

Время выполнения почти не зависит от количества элементов.

### Короткое определение

**O(1) = очень быстро.**

### Мини-пример

```java
map.get(id);
```
