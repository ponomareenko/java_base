# Словарь разработчика — Тема 6. Коллекции List

## 1. Коллекция (Collection)

### Определение

Коллекция — это объект, предназначенный для хранения группы элементов и работы с ними через единый набор методов.

### Короткое определение

**Коллекция = контейнер для хранения данных.**

### Мини-пример

```java
List<String> names = new ArrayList<>();
names.add("Anna");
names.add("Ivan");
```

---

## 2. Интерфейс (Interface)

### Определение

Интерфейс — это контракт, который определяет набор методов, но не содержит их реализацию (или содержит частично).

### Короткое определение

**Интерфейс = правило, как должен выглядеть класс.**

### Мини-пример

```java
List<String> list = new ArrayList<>();
```

Тут:

* `List` — интерфейс
* `ArrayList` — реализация

---

## 3. List

### Определение

`List` — интерфейс коллекций для хранения **упорядоченного набора элементов**, где каждый элемент имеет индекс.

Разрешает дубликаты.

### Короткое определение

**List = коллекция с порядком и индексами.**

### Мини-пример

```java
List<String> list = new ArrayList<>();

list.add("A");
list.add("B");

System.out.println(list.get(1)); // B
```

---

## 4. ArrayList

### Определение

`ArrayList` — реализация `List`, построенная на основе **динамического массива**.

Хорошо подходит для:

* чтения по индексу;
* сортировки;
* поиска.

Не очень подходит для:

* частых вставок в середину.

### Короткое определение

**ArrayList = массив, который умеет расти.**

### Мини-пример

```java
ArrayList<String> users = new ArrayList<>();

users.add("Tom");
users.add("Max");
```

---

## 5. Динамический массив

### Определение

Массив, который автоматически увеличивает внутренний размер при нехватке места.

### Короткое определение

**Динамический массив = массив с авторасширением.**

### Мини-пример

```java
ArrayList<Integer> nums = new ArrayList<>();

for (int i = 0; i < 100; i++) {
    nums.add(i);
}
```

---

## 6. Ёмкость (Capacity)

### Определение

Ёмкость — внутренний размер массива, выделенного под `ArrayList`.

Это не количество элементов.

### Короткое определение

**Capacity = сколько места выделено.**

### Мини-пример

```java
ArrayList<String> list =
        new ArrayList<>(100);
```

Сейчас:

```
size = 0
capacity = 100
```

---

## 7. Размер коллекции (size)

### Определение

Количество реально находящихся элементов.

### Короткое определение

**size = сколько элементов лежит сейчас.**

### Мини-пример

```java
list.add("A");

System.out.println(list.size()); // 1
```

---

## 8. Индекс

### Определение

Позиция элемента в коллекции.

Начинается с 0.

### Короткое определение

**Индекс = номер элемента.**

### Мини-пример

```java
list.get(0);
```

---

## 9. Итератор (Iterator)

### Определение

Объект для последовательного обхода коллекции.

### Короткое определение

**Iterator = указатель для прохода по коллекции.**

### Мини-пример

```java
Iterator<String> it =
        list.iterator();

while (it.hasNext()) {
    System.out.println(it.next());
}
```

---

## 10. Итерирование

### Определение

Процесс последовательного перебора элементов.

### Короткое определение

**Итерирование = пройтись по всем элементам.**

### Мини-пример

```java
for (String s : list) {
    System.out.println(s);
}
```

---

## 11. Generics (Дженерики)

### Определение

Механизм Java для ограничения типов данных внутри коллекции.

### Короткое определение

**Generics = типобезопасность.**

### Мини-пример

```java
List<String> names =
        new ArrayList<>();
```

Только строки.

---

## 12. Типобезопасность (Type Safety)

### Определение

Гарантия, что в коллекцию нельзя положить объект неправильного типа.

### Короткое определение

**Типобезопасность = защита от неверных типов.**

### Мини-пример

```java
List<Integer> nums =
        new ArrayList<>();

nums.add(10);

// nums.add("abc"); // ошибка
```

---

## 13. LinkedList

### Определение

Реализация `List` на основе **двусвязного списка**.

Хорошо:

* вставка;
* удаление.

Плохо:

* доступ по индексу.

### Короткое определение

**LinkedList = цепочка элементов со ссылками.**

### Мини-пример

```java
LinkedList<String> list =
        new LinkedList<>();

list.addFirst("A");
list.addLast("B");
```

---

## 14. Queue (Очередь)

### Определение

Коллекция, где элементы обрабатываются по порядку.

### Короткое определение

**Queue = первый пришёл — первый ушёл.**

### Мини-пример

```java
Queue<String> q =
        new LinkedList<>();

q.offer("Task");
q.poll();
```

---

## 15. Set

### Определение

Коллекция без дубликатов.

### Короткое определение

**Set = уникальные элементы.**

### Мини-пример

```java
Set<String> set =
        new HashSet<>();

set.add("A");
set.add("A");

System.out.println(set.size()); // 1
```

---

## 16. Map

### Определение

Коллекция вида **ключ → значение**.

### Короткое определение

**Map = словарь.**

### Мини-пример

```java
Map<Integer, String> users =
        new HashMap<>();

users.put(1, "Tom");
```
