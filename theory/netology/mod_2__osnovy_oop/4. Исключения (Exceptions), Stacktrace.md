# Словарь Java — Тема 4

## Исключения (Exceptions), Stacktrace

---

## 1. Исключение (Exception)

### Определение

Объект, описывающий ошибочную или нестандартную ситуацию во время выполнения программы.

### Короткое определение

**Сообщение программе: что-то пошло не так.**

### Мини-пример

```java
int result = 10 / 0;
```

Результат:

```text
ArithmeticException
```

---

## 2. Выброс исключения (Throw Exception)

### Определение

Создание и запуск исключительной ситуации.

### Короткое определение

**Сообщить об ошибке.**

### Мини-пример

```java
throw new Exception("Ошибка");
```

или

```java
throw new IllegalArgumentException(
        "Возраст не может быть отрицательным"
);
```

---

## 3. Обработка исключения (Exception Handling)

### Определение

Действия программы после появления исключения.

### Короткое определение

**Что делать после ошибки.**

### Мини-пример

```java
try {
    dangerousMethod();
} catch (Exception e) {
    System.out.println("Ошибка");
}
```

---

## 4. try

### Определение

Блок кода, внутри которого может возникнуть исключение.

### Короткое определение

**Пробуем выполнить.**

### Мини-пример

```java
try {
    int x = 10 / 0;
}
```

---

## 5. catch

### Определение

Блок для перехвата и обработки ошибки.

### Короткое определение

**Поймали ошибку.**

### Мини-пример

```java
catch (ArithmeticException e) {
    System.out.println("На ноль делить нельзя");
}
```

---

## 6. finally

### Определение

Блок, который выполняется почти всегда независимо от ошибки.

### Короткое определение

**Убраться после работы.**

### Мини-пример

```java
finally {
    scanner.close();
}
```

💡 Часто используется для:

* закрытия файлов;
* соединений;
* освобождения ресурсов.

---

## 7. throw

### Определение

Ключевое слово для ручного создания исключения.

### Короткое определение

**Выкинуть ошибку.**

### Мини-пример

```java
if (age < 0) {
    throw new RuntimeException();
}
```

---

## 8. throws

### Определение

Объявление, что метод может выбросить исключение.

### Короткое определение

**Предупреждение вызывающему коду.**

### Мини-пример

```java
public void read()
throws IOException {

}
```

---

## 9. Checked Exception

### Определение

Исключение, которое компилятор заставляет обработать.

### Короткое определение

**Обработай обязательно.**

### Мини-пример

```java
IOException
ParseException
```

Пример:

```java
public void load()
throws IOException
```

---

## 10. Unchecked Exception

### Определение

Исключение, которое можно не обрабатывать.

### Короткое определение

**Может упасть во время выполнения.**

### Мини-пример

```java
ArithmeticException
NullPointerException
```

---

## 11. RuntimeException

### Определение

Базовый класс большинства ошибок приложения.

### Короткое определение

**Ошибки логики программы.**

### Мини-пример

```java
int x = 10 / 0;
```

↓

```text
ArithmeticException
```

---

## 12. Throwable

### Определение

Корневой класс всех ошибок и исключений в Java.

### Короткое определение

**Родитель всех проблем.**

### Мини-пример

```text
Throwable
├── Error
└── Exception
```

---

## 13. Error

### Определение

Критические ошибки JVM.

### Короткое определение

**Проблема среды, а не программы.**

### Мини-пример

```text
OutOfMemoryError
StackOverflowError
```

💡 Обычно их не ловят.

---

## 14. Stacktrace

### Определение

Цепочка вызовов методов, приведшая к ошибке.

### Короткое определение

**Маршрут до места падения.**

### Мини-пример

```text
Exception in thread "main"

at Main.getAge()
at Main.main()
```

Читать снизу вверх:

1. кто вызвал
2. кто упал

---

## 15. Stack (стек вызовов)

### Определение

Структура памяти, где хранится порядок вызова методов.

### Короткое определение

**Стопка работающих методов.**

### Мини-пример

```java
main()
 ↓
login()
 ↓
validate()
 ↓
throw Exception
```

---

## 16. printStackTrace()

### Определение

Метод для вывода полного stacktrace.

### Короткое определение

**Показать место ошибки.**

### Мини-пример

```java
catch (Exception e) {
    e.printStackTrace();
}
```

---

## 17. Пользовательское исключение (Custom Exception)

### Определение

Свой собственный класс ошибки.

### Короткое определение

**Ошибка под правила проекта.**

### Мини-пример

```java
class AgeException
extends RuntimeException {

}
```

Использование:

```java
throw new AgeException();
```

---

## 18. Цепочка исключений (Exception Chaining)

### Определение

Когда одно исключение вызвано другим.

### Короткое определение

**Ошибка породила ошибку.**

### Мини-пример

```text
Caused by:
SQLException
```

# Очень важная таблица

|             | throw                 | throws                      |
| ----------- | --------------------- | --------------------------- |
| Что делает  | выбрасывает           | объявляет                   |
| Где пишется | внутри метода         | в сигнатуре                 |
| Пример      | throw new Exception() | method() throws IOException |

1. `try`
2. `catch`
3. `finally`
4. `throw`
5. `throws`
6. checked / unchecked
7. RuntimeException
8. stacktrace

# Запомнить одной фразой

```text
throw → создаю ошибку

throws → предупреждаю об ошибке
```
