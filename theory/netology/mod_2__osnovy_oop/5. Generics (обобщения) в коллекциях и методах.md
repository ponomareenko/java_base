# Словарь Java — Тема 5

## Generics (обобщения) в коллекциях и методах

---

## 1. Generics (Обобщения)

### Определение

Механизм Java, позволяющий писать универсальный код, работающий с разными типами данных без потери типобезопасности.

### Короткое определение

**Один код → много типов.**

### Мини-пример

Без generics:

```java
Object value;
```

С generics:

```java
T value;
```

---

## 2. Generic-класс (Обобщённый класс)

### Определение

Класс, который принимает тип как параметр.

### Короткое определение

**Класс с настраиваемым типом.**

### Мини-пример

```java
class Memory<T> {

    private T value;

}
```

Использование:

```java
Memory<String> memory =
        new Memory<>();
```

---

## 3. Типизированный параметр (Type Parameter)

### Определение

Переменная типа, которая подставляется вместо конкретного класса.

### Короткое определение

**Заглушка для будущего типа.**

### Мини-пример

```java
<T>
```

или

```java
<K, V>
```

---

## 4. T (Type)

### Определение

Условное имя параметра типа.

### Короткое определение

**Любой тип.**

### Мини-пример

```java
class Box<T> {

}
```

Создание:

```java
Box<String>
```

---

## 5. Типобезопасность (Type Safety)

### Определение

Гарантия, что объект имеет ожидаемый тип.

### Короткое определение

**Ошибку ловим до запуска программы.**

### Мини-пример

```java
List<String> list =
        new ArrayList<>();

list.add("Привет");

// ошибка
list.add(10);
```

---

## 6. Raw Type (Сырой тип)

### Определение

Использование generic-класса без указания типа.

### Короткое определение

**Generics выключены.**

### Мини-пример

❌

```java
List list =
        new ArrayList();
```

Нормально:

```java
List<String> list =
        new ArrayList<>();
```

---

## 7. Приведение типа (Casting)

### Определение

Явное преобразование одного типа в другой.

### Короткое определение

**Сказать Java: считай это другим типом.**

### Мини-пример

```java
String s =
        (String) obj;
```

Generics позволяют делать это реже.

---

## 8. Generic-метод

### Определение

Метод, который принимает обобщённый тип независимо от класса.

### Короткое определение

**Метод с собственным типом.**

### Мини-пример

```java
public static <T>
T choose(
        boolean flag,
        T first,
        T second
) {

    return flag
            ? first
            : second;

}
```

Использование:

```java
String result =
        choose(
                true,
                "A",
                "B"
        );
```

---

## 9. Выведение типа (Type Inference)

### Определение

Способность Java определить тип автоматически.

### Короткое определение

**Java сама догадалась.**

### Мини-пример

```java
var list =
        new ArrayList<String>();
```

или

```java
Memory<String> memory =
        new Memory<>();
```

`<>` называется diamond operator.

---

## 10. Diamond Operator (<>)

### Определение

Сокращённая запись generic-типа при создании объекта.

### Короткое определение

**Не повторяем тип дважды.**

### Мини-пример

Вместо:

```java
new Memory<String>()
```

пишем:

```java
new Memory<>()
```

---

## 11. Ограничение типа (Bounded Type)

### Определение

Ограничение списка допустимых типов.

### Короткое определение

**Принимаем только определённые типы.**

### Мини-пример

```java
<T extends Number>
```

Теперь можно:

```java
Integer
Double
```

Нельзя:

```java
String
```

---

## 12. extends в generics

### Определение

Ограничивает допустимый тип сверху.

### Короткое определение

**Не любой тип — только наследники.**

### Мини-пример

```java
public static
<T extends Number>
T max(
        T a,
        T b
)
```

---

## 13. Generic-интерфейс

### Определение

Интерфейс с параметром типа.

### Короткое определение

**Интерфейс для разных типов.**

### Мини-пример

```java
interface Savable<T> {

    void save(T obj);

}
```

---

## 14. Несколько параметров типа

### Определение

Использование нескольких типизированных аргументов.

### Короткое определение

**Несколько настраиваемых типов.**

### Мини-пример

```java
class Box<K, V> {

}
```

Использование:

```java
Box<String, Integer>
```

---

## 15. Инвариантность generics

### Определение

`Memory<Integer>` не является `Memory<Number>`.

### Короткое определение

**Generics не наследуются автоматически.**

### Мини-пример

❌

```java
Memory<Number> memory =
        new Memory<Integer>();
```

Так нельзя.

---

## 16. Обёртки (Wrapper Classes)

### Определение

Классы-аналоги примитивов.

### Короткое определение

**Версия примитива как объекта.**

### Мини-пример

| Примитив | Обёртка |
| -------- | ------- |
| int      | Integer |
| long     | Long    |
| double   | Double  |
| boolean  | Boolean |

Потому что:

❌

```java
Memory<int>
```

а вот так:

✅

```java
Memory<Integer>
```
