# 1. Модификаторы доступа, инкапсуляция, наследование

## 1. Объектно-ориентированное программирование

### Определение

**Объектно-ориентированное программирование**, или **ООП**, — это подход к программированию, при котором программа строится из объектов.

Объекты хранят данные и умеют выполнять действия.

В Java почти всё строится вокруг классов и объектов.

### Пример

```java
public class Person {
    String name;
    int age;

    void sayHello() {
        System.out.println("Привет, меня зовут " + name);
    }
}
```

```java
Person person = new Person();
person.name = "Danil";
person.age = 25;

person.sayHello();
```

---

## 2. Класс

### Определение

**Класс** — это шаблон, по которому создаются объекты.

Класс описывает:

* какие данные будут у объекта;
* какие действия объект сможет выполнять.

### Пример

```java
public class Person {
    String name;
    int age;
}
```

Здесь `Person` — это класс.

---

## 3. Объект

### Определение

**Объект** — это конкретный экземпляр класса.

Если класс — это чертёж, то объект — это уже построенный дом по этому чертежу.

### Пример

```java
Person person = new Person();
```

Здесь `person` — объект класса `Person`.

---

## 4. Поле класса

### Определение

**Поле класса** — это переменная, которая хранит состояние объекта.

### Пример

```java
public class Person {
    String name;
    int age;
}
```

`name` и `age` — это поля класса.

---

## 5. Метод

### Определение

**Метод** — это действие, которое может выполнять объект.

Метод содержит код, который можно вызвать по имени.

### Пример

```java
public class Person {
    void sayHello() {
        System.out.println("Привет");
    }
}
```

`sayHello()` — это метод.

---

## 6. Инкапсуляция

### Определение

**Инкапсуляция** — это принцип ООП, при котором данные объекта скрываются от прямого доступа извне, а работа с ними происходит через методы.

Главная идея: нельзя давать внешнему коду напрямую ломать состояние объекта.

### Пример плохого кода

```java
public class Person {
    public int age;
}
```

```java
Person person = new Person();
person.age = -8;
```

Проблема: возраст не может быть отрицательным, но внешний код смог записать неправильное значение.

### Пример правильнее

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 200) {
            return;
        }

        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

Теперь возраст нельзя изменить напрямую. Можно только через `setAge()`, где есть проверка.

---

## 7. Getter

### Определение

**Getter** — это метод, который возвращает значение поля.

Обычно название начинается с `get`.

### Пример

```java
public int getAge() {
    return age;
}
```

Метод `getAge()` возвращает возраст.

---

## 8. Setter

### Определение

**Setter** — это метод, который устанавливает новое значение поля.

Обычно название начинается с `set`.

### Пример

```java
public void setAge(int age) {
    if (age < 0 || age > 200) {
        return;
    }

    this.age = age;
}
```

Метод `setAge()` устанавливает возраст, но только если значение корректное.

---

## 9. Early exit

### Определение

**Early exit** — это приём, когда метод завершается раньше времени, если данные не подходят.

Это помогает не писать лишние `else` и делает код чище.

### Пример

```java
public void setAge(int age) {
    if (age < 0 || age > 200) {
        return;
    }

    this.age = age;
}
```

Если возраст неправильный, метод сразу завершится.

---

## 10. Модификатор доступа

### Определение

**Модификатор доступа** — это ключевое слово, которое определяет, откуда можно обращаться к классу, полю, методу или конструктору.

В Java есть основные модификаторы доступа:

* `public`
* `private`
* `protected`
* `default`

---

## 11. public

### Определение

**public** — самый открытый модификатор доступа.

Поле, метод или класс с `public` доступен из других классов и пакетов.

### Пример

```java
public class Person {
    public void sayHello() {
        System.out.println("Привет");
    }
}
```

Метод `sayHello()` можно вызвать из другого класса.

---

## 12. private

### Определение

**private** — самый закрытый модификатор доступа.

Поле или метод с `private` доступен только внутри того же класса.

### Пример

```java
public class Person {
    private int age;
}
```

Снаружи нельзя написать:

```java
person.age = 20;
```

Потому что поле `age` закрыто.

---

## 13. protected

### Определение

**protected** — модификатор доступа, который разрешает доступ:

* внутри самого класса;
* внутри того же пакета;
* в классах-наследниках.

Часто используется при наследовании.

### Пример

```java
public class Person {
    protected String name;
    protected int age;
}
```

Класс-наследник сможет обращаться к этим полям.

---

## 14. default

### Определение

**default** — это доступ по умолчанию.

Он используется, когда мы вообще не пишем модификатор доступа.

Такой элемент доступен только внутри текущего пакета.

### Пример

```java
class Person {
    int age;
}
```

Здесь у класса `Person` и поля `age` доступ `default`.

---

## 15. Наследование

### Определение

**Наследование** — это механизм ООП, который позволяет создать новый класс на основе уже существующего класса.

Новый класс получает поля и методы родительского класса.

### Пример

```java
public class Person {
    protected String name;
    protected int age;
}
```

```java
public class Singer extends Person {
    public void sing() {
        System.out.println(name + " поёт");
    }
}
```

`Singer` наследуется от `Person`.

Значит, певец — это тоже человек, но с дополнительным поведением.

---

## 16. extends

### Определение

**extends** — это ключевое слово, которое используется для наследования одного класса от другого.

### Пример

```java
public class Singer extends Person {
}
```

Это значит: `Singer` наследуется от `Person`.

---

## 17. Родительский класс

### Определение

**Родительский класс** — это класс, от которого наследуются другие классы.

Его ещё называют:

* базовый класс;
* суперкласс;
* parent class;
* superclass.

### Пример

```java
public class Person {
}
```

```java
public class Singer extends Person {
}
```

`Person` — родительский класс.

---

## 18. Дочерний класс

### Определение

**Дочерний класс** — это класс, который наследуется от другого класса.

Его ещё называют:

* наследник;
* подкласс;
* производный класс;
* child class;
* subclass.

### Пример

```java
public class Singer extends Person {
}
```

`Singer` — дочерний класс.

---

## 19. Переопределение метода

### Определение

**Переопределение метода** — это ситуация, когда дочерний класс изменяет поведение метода, который уже есть в родительском классе.

### Пример

```java
public class Person {
    public void happyBirthday() {
        System.out.println("С днём рождения!");
    }
}
```

```java
public class Singer extends Person {
    @Override
    public void happyBirthday() {
        System.out.println("Я пою себе песню на день рождения!");
    }
}
```

Метод `happyBirthday()` был в `Person`, но в `Singer` он работает по-другому.

---

## 20. @Override

### Определение

**@Override** — это аннотация, которая показывает, что метод переопределяет метод родительского класса.

Она помогает избежать ошибок.

### Пример

```java
@Override
public void happyBirthday() {
    System.out.println("Я пою себе песню на день рождения!");
}
```

Если случайно ошибиться в названии метода, Java покажет ошибку.

---

## 21. super

### Определение

**super** — это ключевое слово, которое позволяет обратиться к родительскому классу.

Через `super` можно:

* вызвать метод родителя;
* вызвать конструктор родителя.

### Пример вызова метода родителя

```java
public class Person {
    public void happyBirthday() {
        System.out.println("С днём рождения!");
    }
}
```

```java
public class Singer extends Person {
    @Override
    public void happyBirthday() {
        super.happyBirthday();
        System.out.println("А теперь я ещё и спою!");
    }
}
```

Сначала выполнится метод родителя, потом дополнительный код дочернего класса.

---

## 22. final class

### Определение

**final class** — это класс, от которого нельзя наследоваться.

Если класс объявлен как `final`, он не может быть родительским классом.

### Пример

```java
public final class Person {
}
```

Так сделать уже нельзя:

```java
public class Singer extends Person {
}
```

Будет ошибка компиляции.

---

## 23. Конструктор

### Определение

**Конструктор** — это специальный блок кода, который вызывается при создании объекта.

Он нужен, чтобы сразу подготовить объект к работе и заполнить его поля.

### Пример

```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

```java
Person person = new Person("Danil", 25);
```

---

## 24. Конструктор при наследовании

### Определение

Если дочерний класс наследуется от родительского класса, то при создании объекта дочернего класса сначала должен быть вызван конструктор родителя.

Для этого используется `super()`.

### Пример

```java
public class Person {
    protected String name;
    protected int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

```java
public class Singer extends Person {
    private int rating;

    public Singer(String name, int age, int rating) {
        super(name, age);
        this.rating = rating;
    }
}
```

`super(name, age)` вызывает конструктор класса `Person`.

---

## 25. Цепочка вызова конструкторов

### Определение

**Цепочка вызова конструкторов** — это порядок, при котором при создании объекта сначала вызываются конструкторы родительских классов, а потом конструктор текущего класса.

В Java эта цепочка доходит до класса `Object`, потому что все классы в Java наследуются от `Object`.

### Пример

```java
public class Person {
    public Person() {
        System.out.println("Создан Person");
    }
}
```

```java
public class Singer extends Person {
    public Singer() {
        System.out.println("Создан Singer");
    }
}
```

```java
Singer singer = new Singer();
```

Вывод:

```java
Создан Person
Создан Singer
```

Сначала создаётся родительская часть объекта, потом дочерняя.

---

## 26. Object

### Определение

**Object** — это главный базовый класс в Java.

Все классы в Java прямо или косвенно наследуются от `Object`.

### Пример

```java
public class Person {
}
```

Фактически Java воспринимает это примерно так:

```java
public class Person extends Object {
}
```

Писать `extends Object` вручную не нужно.

---

# Коротко по теме

Инкапсуляция защищает данные объекта.

Модификаторы доступа управляют тем, кто может видеть поля и методы.

Наследование позволяет создавать новый класс на основе старого.

`extends` используется для наследования.

`@Override` используется при переопределении метода.

`super` позволяет обратиться к родительскому классу.

`final class` запрещает наследование.

Конструктор родителя вызывается перед конструктором дочернего класса.
