# Словарь Java — Тема 1

## Модификаторы доступа, инкапсуляция, наследование

---

## 1. Инкапсуляция (Encapsulation)

### Определение

Принцип ООП, при котором внутреннее состояние объекта скрывается, а доступ к нему происходит только через контролируемые методы.

### Короткое определение (для запоминания)

**Прячем данные → управляем доступом.**

### Мини-пример

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age >= 0) {
            this.age = age;
        }
    }

    public int getAge() {
        return age;
    }
}
```

```java
person.setAge(25);
System.out.println(person.getAge());
```

💡 Почему так делают:
чтобы никто случайно не сделал:

```java
person.age = -100;
```

---

## 2. Геттер (Getter)

### Определение

Метод для получения значения поля объекта.

### Короткое определение

**Метод чтения данных.**

### Мини-пример

```java
public int getAge() {
    return age;
}
```

Использование:

```java
int age = person.getAge();
```

---

## 3. Сеттер (Setter)

### Определение

Метод для изменения значения поля объекта.

### Короткое определение

**Метод изменения данных.**

### Мини-пример

```java
public void setAge(int age) {
    this.age = age;
}
```

Использование:

```java
person.setAge(30);
```

💡 В проде сеттеры часто содержат валидацию.

---

## 4. Модификатор доступа (Access Modifier)

### Определение

Ключевое слово, определяющее откуда можно обращаться к классу, полю или методу.

### Короткое определение

**Кто имеет право пользоваться кодом.**

### Мини-пример

```java
private String name;
public int age;
```

---

## 5. public

### Определение

Доступен отовсюду.

### Короткое определение

**Видно всем.**

### Мини-пример

```java
public class Main {
}
```

---

## 6. private

### Определение

Доступ только внутри текущего класса.

### Короткое определение

**Только для себя.**

### Мини-пример

```java
private int age;
```

---

## 7. protected

### Определение

Доступ внутри пакета и классам-наследникам.

### Короткое определение

**Для своих и потомков.**

### Мини-пример

```java
protected String name;
```

💡 В реальном коде используется заметно реже, чем кажется после курсов.

---

## 8. default (package-private)

### Определение

Доступ только внутри текущего пакета.

### Короткое определение

**Только соседи по пакету.**

### Мини-пример

```java
class Person {
}
```

(без модификатора)

---

## 9. Наследование (Inheritance)

### Определение

Механизм создания нового класса на основе существующего.

### Короткое определение

**Берём готовое → расширяем.**

### Мини-пример

```java
class Person {
}

class Singer extends Person {
}
```

---

## 10. Родительский класс (Superclass)

### Определение

Класс, от которого наследуются.

### Короткое определение

**Источник поведения.**

### Мини-пример

```java
class Person {
}
```

---

## 11. Дочерний класс (Subclass)

### Определение

Класс, который наследует другой класс.

### Короткое определение

**Расширение родителя.**

### Мини-пример

```java
class Singer extends Person {
}
```

---

## 12. extends

### Определение

Ключевое слово для наследования.

### Короткое определение

**Наследуюсь от…**

### Мини-пример

```java
class Dog extends Animal {
}
```

---

## 13. Переопределение метода (Method Overriding)

### Определение

Создание новой реализации метода родительского класса.

### Короткое определение

**Унаследовал → изменил поведение.**

### Мини-пример

```java
@Override
public void walk() {
    System.out.println("Бегу");
}
```

---

## 14. @Override

### Определение

Аннотация, показывающая, что метод переопределяется.

### Короткое определение

**Проверка: точно ли переопределяем.**

### Мини-пример

```java
@Override
public String toString() {
}
```

💡 Не обязательна, но почти всегда ставится.

---

## 15. super

### Определение

Ссылка на родительский класс.

### Короткое определение

**Обращение к родителю.**

### Мини-пример

```java
super.print();
```

или

```java
super(name, age);
```

---

## 16. Конструктор (Constructor)

### Определение

Специальный метод, который создаёт и инициализирует объект.

### Короткое определение

**Инструкция создания объекта.**

### Мини-пример

```java
public Person(String name) {
    this.name = name;
}
```

---

## 17. Цепочка конструкторов (Constructor Chaining)

### Определение

Последовательный вызов конструкторов от дочернего класса к родительскому.

### Короткое определение

**Сначала создаются родители → потом ребёнок.**

### Мини-пример

```java
super(name);
```

---

## 18. final класс

### Определение

Класс, от которого нельзя наследоваться.

### Короткое определение

**Конечный класс.**

### Мини-пример

```java
final class Person {
}
```
