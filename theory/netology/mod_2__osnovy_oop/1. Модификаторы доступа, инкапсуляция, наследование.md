# Тема 1: Модификаторы доступа, инкапсуляция и наследование

## Инкапсуляция

**Определение:**

Инкапсуляция — это принцип ООП, при котором данные объекта скрываются от прямого внешнего доступа, а работа с ними выполняется через методы самого объекта.

Главная идея инкапсуляции — не позволять другим частям программы напрямую менять внутреннее состояние объекта, если это может привести к некорректным данным.

В Java инкапсуляция обычно реализуется через `private`-поля и публичные методы для чтения и изменения данных.

**Пример:**

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 200) {
            return;
        }

        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

---

## Модификатор доступа

**Определение:**

Модификатор доступа — это ключевое слово, которое определяет, откуда можно обращаться к классу, полю, методу или конструктору.

В Java основные модификаторы доступа:

* `public`
* `private`
* `protected`
* default, то есть отсутствие явного модификатора

Модификаторы доступа нужны, чтобы контролировать границы использования кода и защищать объект от неправильного обращения.

**Пример:**

```java
public class Person {
    private int age;

    public int getAge() {
        return age;
    }
}
```

---

## public

**Определение:**

`public` — модификатор доступа, который делает класс, метод, поле или конструктор доступным из любого другого класса.

Если метод объявлен как `public`, значит он является частью внешнего интерфейса класса, то есть другие классы могут им пользоваться.

В продакшене `public` используют аккуратно: всё, что стало публичным, сложнее изменить, потому что этим уже может пользоваться другой код.

**Пример:**

```java
public class Person {
    public void sayHello() {
        System.out.println("Hello");
    }
}
```

---

## private

**Определение:**

`private` — модификатор доступа, который разрешает обращаться к полю, методу или конструктору только внутри того же класса.

Чаще всего `private` используют для полей объекта, чтобы никто не мог изменить состояние объекта напрямую.

Это основа нормальной инкапсуляции: не даём внешнему коду «лезть руками в двигатель».

**Пример:**

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age < 0) {
            return;
        }

        this.age = age;
    }
}
```

---

## protected

**Определение:**

`protected` — модификатор доступа, который разрешает обращаться к полю, методу или конструктору:

* внутри самого класса;
* внутри классов из того же пакета;
* внутри классов-наследников, даже если они находятся в другом пакете.

`protected` часто используют при наследовании, когда дочернему классу нужен доступ к данным или поведению родителя.

Но злоупотреблять `protected` не стоит: если всё сделать `protected`, наследники смогут слишком свободно менять внутреннее состояние родителя.

**Пример:**

```java
public class Person {
    protected String name;
    protected int age;
}

public class Singer extends Person {
    public void printInfo() {
        System.out.println(name + ", " + age);
    }
}
```

---

## default access

**Определение:**

`default access` — это уровень доступа, который используется, если модификатор доступа не указан явно.

Такой класс, метод, поле или конструктор доступен только внутри текущего пакета.

Важно: `default` в данном случае не пишется как ключевое слово. Это просто отсутствие модификатора доступа.

**Пример:**

```java
class Person {
    int age;

    void printAge() {
        System.out.println(age);
    }
}
```

---

## Геттер

**Определение:**

Геттер — это метод, который возвращает значение поля объекта.

Обычно геттеры называют по схеме `get + ИмяПоля`.

Геттер нужен, чтобы внешний код мог прочитать значение поля, не получая прямой доступ к самому полю.

**Пример:**

```java
public class Person {
    private int age;

    public int getAge() {
        return age;
    }
}
```

---

## Сеттер

**Определение:**

Сеттер — это метод, который изменяет значение поля объекта.

Обычно сеттеры называют по схеме `set + ИмяПоля`.

Сеттер позволяет не просто записать значение, а сначала проверить его на корректность.

**Пример:**

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 200) {
            return;
        }

        this.age = age;
    }
}
```

---

## Валидация данных

**Определение:**

Валидация данных — это проверка значения перед тем, как программа его использует или сохраняет.

В классах валидацию часто делают внутри сеттеров или конструкторов, чтобы объект не мог оказаться в некорректном состоянии.

Например, возраст человека не должен быть отрицательным.

**Пример:**

```java
public class Person {
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 200) {
            return;
        }

        this.age = age;
    }
}
```

---

## Early exit

**Определение:**

`Early exit` — это приём, при котором метод завершает работу раньше, если дальнейшее выполнение не имеет смысла.

В Java для этого часто используют `return`.

Такой подход помогает не писать лишние вложенные `if` и делает код проще для чтения.

**Пример:**

```java
public void setAge(int age) {
    if (age < 0 || age > 200) {
        return;
    }

    this.age = age;
}
```

---

## Наследование

**Определение:**

Наследование — это механизм ООП, который позволяет создать новый класс на основе уже существующего класса.

Дочерний класс получает доступ к полям и методам родительского класса, кроме тех, которые недоступны из-за модификаторов доступа, например `private`.

Наследование используют, когда один объект является частным случаем другого.

Например, певец — это человек, поэтому `Singer` может наследоваться от `Person`.

**Пример:**

```java
public class Person {
    protected String name;
    protected int age;
}

public class Singer extends Person {
    public void sing(String song) {
        System.out.println(name + " поёт: " + song);
    }
}
```

---

## extends

**Определение:**

`extends` — ключевое слово Java, которое используется для наследования одного класса от другого.

После `extends` указывается класс-родитель.

В Java класс может наследоваться только от одного класса.

**Пример:**

```java
public class Singer extends Person {
}
```

---

## Родительский класс

**Определение:**

Родительский класс — это класс, от которого наследуется другой класс.

Его также называют:

* базовый класс;
* суперкласс;
* superclass.

Родительский класс содержит общие поля и методы, которые могут использовать дочерние классы.

**Пример:**

```java
public class Person {
    protected String name;
    protected int age;
}
```

---

## Дочерний класс

**Определение:**

Дочерний класс — это класс, который наследуется от другого класса.

Его также называют:

* наследник;
* подкласс;
* производный класс;
* subclass.

Дочерний класс может использовать функциональность родителя и добавлять свою собственную.

**Пример:**

```java
public class Singer extends Person {
    public void sing() {
        System.out.println("Я пою");
    }
}
```

---

## Object

**Определение:**

`Object` — это базовый класс для всех классов в Java.

Если класс явно не наследуется от другого класса, он всё равно неявно наследуется от `Object`.

Поэтому у любого объекта в Java есть методы класса `Object`, например `toString()`, `equals()` и `hashCode()`.

**Пример:**

```java
public class Person {
}
```

Этот класс фактически можно представить так:

```java
public class Person extends Object {
}
```

---

## Переопределение метода

**Определение:**

Переопределение метода — это ситуация, когда дочерний класс создаёт свою версию метода, который уже есть в родительском классе.

Метод в дочернем классе должен иметь такую же сигнатуру, как метод в родительском классе.

Переопределение нужно, когда у наследника поведение должно отличаться от поведения родителя.

**Пример:**

```java
public class Person {
    public void happyBirthday() {
        age++;
        System.out.println("С днём рождения!");
    }

    protected int age;
}

public class Singer extends Person {
    @Override
    public void happyBirthday() {
        age++;
        System.out.println("Я пою себе песню на день рождения!");
    }
}
```

---

## @Override

**Определение:**

`@Override` — это аннотация, которая показывает, что метод переопределяет метод родительского класса.

Аннотация не обязательна, но в реальной разработке её почти всегда ставят.

Она помогает компилятору найти ошибку, если программист случайно написал метод неправильно и вместо переопределения создал новый метод.

**Пример:**

```java
public class Singer extends Person {
    @Override
    public void happyBirthday() {
        System.out.println("Пою поздравительную песню");
    }
}
```

---

## Сигнатура метода

**Определение:**

Сигнатура метода — это имя метода и список его параметров.

При переопределении метода в дочернем классе сигнатура должна совпадать с методом родительского класса.

Тип возвращаемого значения в сигнатуру не входит, но при переопределении он тоже должен быть совместимым.

**Пример:**

```java
public void sing(String song) {
    System.out.println(song);
}
```

Сигнатура этого метода:

```java
sing(String song)
```

---

## super

**Определение:**

`super` — это ключевое слово, которое позволяет обратиться к родительскому классу.

Через `super` можно:

* вызвать метод родителя;
* вызвать конструктор родителя;
* обратиться к полю родителя, если оно доступно.

Чаще всего `super` используют, когда нужно не полностью заменить поведение родителя, а немного его дополнить.

**Пример:**

```java
public class Person {
    public void happyBirthday() {
        System.out.println("С днём рождения!");
    }
}

public class Singer extends Person {
    @Override
    public void happyBirthday() {
        super.happyBirthday();
        System.out.println("А теперь песня!");
    }
}
```

---

## final class

**Определение:**

`final class` — это класс, от которого нельзя наследоваться.

Если класс объявлен как `final`, Java запретит создавать его дочерние классы.

Так делают, когда хотят зафиксировать поведение класса и не позволять другим классам его изменять через наследование.

**Пример:**

```java
public final class Person {
}
```

Такой код вызовет ошибку:

```java
public class Singer extends Person {
}
```

---

## Сокрытие поля

**Определение:**

Сокрытие поля — это ситуация, когда в дочернем классе объявляют поле с таким же именем, как в родительском классе.

Важно: поля в Java не переопределяются так, как методы.

Если в дочернем классе создать поле с тем же именем, это будет новое отдельное поле, а не новая версия старого.

Такой код обычно лучше не писать, потому что он легко запутывает.

**Пример:**

```java
public class Person {
    protected int age = 30;
}

public class Singer extends Person {
    protected int age = 40;

    public void printAge() {
        System.out.println(age);
    }
}
```

В методе `printAge()` будет использоваться поле `age` из класса `Singer`.

---

## Конструктор при наследовании

**Определение:**

Конструкторы в Java не наследуются.

Но при создании объекта дочернего класса Java обязательно должна сначала создать родительскую часть объекта.

Поэтому конструктор дочернего класса вызывает конструктор родительского класса через `super(...)`.

Вызов `super(...)` должен быть первой инструкцией в конструкторе дочернего класса.

**Пример:**

```java
public class Person {
    protected String name;
    protected int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

public class Singer extends Person {
    private int rating;

    public Singer(String name, int age, int rating) {
        super(name, age);
        this.rating = rating;
    }
}
```

---

## Конструктор по умолчанию

**Определение:**

Конструктор по умолчанию — это конструктор без параметров.

Если в классе не написан ни один конструктор, Java автоматически создаёт конструктор без параметров.

Но если в классе уже есть хотя бы один конструктор с параметрами, Java больше не создаёт конструктор по умолчанию автоматически.

**Пример:**

```java
public class Person {
    public Person() {
        System.out.println("Создан Person");
    }
}
```

---

## Цепочка вызова конструкторов

**Определение:**

Цепочка вызова конструкторов — это порядок, в котором Java вызывает конструкторы при создании объекта.

Когда создаётся объект дочернего класса, сначала вызывается конструктор родительского класса, затем конструктор дочернего класса.

В итоге цепочка поднимается до класса `Object`.

**Пример:**

```java
public class Person {
    public Person() {
        System.out.println("Person constructor");
    }
}

public class Singer extends Person {
    public Singer() {
        super();
        System.out.println("Singer constructor");
    }
}
```

Если создать объект:

```java
Singer singer = new Singer();
```

Вывод будет:

```java
Person constructor
Singer constructor
```
