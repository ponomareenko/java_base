# Словарь Java — Тема 3

## Абстракции и интерфейсы

---

## 1. Абстракция (Abstraction)

### Определение

Принцип ООП, при котором мы оставляем только важные характеристики объекта и скрываем детали реализации.

### Короткое определение

**Что делает объект, а не как делает.**

### Мини-пример

Вместо:

```text
Машина:
двигатель
свечи
поршни
форсунки
...
```

мы используем:

```java
car.drive();
```

Мы пользуемся — не думая о внутренностях.

---

## 2. Абстрактный класс (Abstract Class)

### Определение

Класс, который нельзя создать напрямую. Он нужен как основа для наследования.

### Короткое определение

**Незавершённый класс-шаблон.**

### Мини-пример

```java
public abstract class Transport {

    public abstract void transfer();
}
```

Нельзя:

```java
new Transport(); // ошибка
```

Можно:

```java
class Car extends Transport {
}
```

---

## 3. Абстрактный метод (Abstract Method)

### Определение

Метод без реализации, который обязан реализовать наследник.

### Короткое определение

**Обещание реализовать позже.**

### Мини-пример

```java
public abstract void transfer();
```

Наследник:

```java
@Override
public void transfer() {
    System.out.println("Еду");
}
```

---

## 4. Реализация метода (Implementation)

### Определение

Конкретный код, выполняющий работу метода.

### Короткое определение

**Настоящее содержимое метода.**

### Мини-пример

Объявление:

```java
void print();
```

Реализация:

```java
void print() {
    System.out.println("Привет");
}
```

---

## 5. Интерфейс (Interface)

### Определение

Контракт, описывающий набор возможностей класса.

### Короткое определение

**Что объект умеет делать.**

### Мини-пример

```java
public interface Transferer {

    void transfer(
        String from,
        String to
    );
}
```

---

## 6. Контракт (Contract)

### Определение

Набор правил, которые класс обязан выполнить.

### Короткое определение

**Подписался → реализуй.**

### Мини-пример

```java
interface Flyable {
    void fly();
}
```

Если класс написал:

```java
implements Flyable
```

то обязан реализовать:

```java
fly()
```

---

## 7. implements

### Определение

Ключевое слово для реализации интерфейса.

### Короткое определение

**Подключить интерфейс.**

### Мини-пример

```java
class Bird implements Flyable {

    @Override
    public void fly() {
    }

}
```

---

## 8. extends

### Определение

Ключевое слово для наследования класса.

### Короткое определение

**Наследовать готовое поведение.**

### Мини-пример

```java
class Car extends Transport {
}
```

---

## 9. Наследование реализации

### Определение

Получение готового кода от родителя.

### Короткое определение

**Берём уже написанный код.**

### Мини-пример

```java
class Car extends Transport
```

Получили:

* поля
* методы
* логику

---

## 10. Реализация интерфейса

### Определение

Получение только требований без готовой логики.

### Короткое определение

**Получаем правила, а не код.**

### Мини-пример

```java
class Bike
implements Transferer
```

Нужно написать всё самостоятельно.

---

## 11. Множественная реализация интерфейсов

### Определение

Один класс может реализовать несколько интерфейсов одновременно.

### Короткое определение

**Один объект — несколько ролей.**

### Мини-пример

```java
class Car
implements Transferer,
           Repairable,
           Billable {
}
```

---

## 12. Множественное наследование

### Определение

Наследование сразу от нескольких классов.

### Короткое определение

**Один ребёнок — несколько родителей.**

### Мини-пример

❌ В Java запрещено:

```java
class D
extends B, C {
}
```

---

## 13. Ромбовидное наследование (Diamond Problem)

### Определение

Проблема неоднозначности, когда один класс получает одинаковые методы от нескольких родителей.

### Короткое определение

**Непонятно, чей метод запускать.**

### Схема

```text
A
| \
B  C
 \ |
  D
```

Если у B и C разная реализация:

```java
print()
```

что запускать у D?

Java сказала:

> классы множественно не наследуем.

---

## 14. Состояние объекта (State)

### Определение

Набор значений полей объекта.

### Короткое определение

**Данные объекта сейчас.**

### Мини-пример

```java
class Car {

    private int fuel;

}
```

`fuel` — часть состояния.

# Запомнить одной фразой

```text
extends → "является"

implements → "умеет"
```

Пример:

```java
Car extends Transport
```

→ машина является транспортом

```java
Bird implements Flyable
```

→ птица умеет летать
