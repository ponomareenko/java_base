## Полиморфизм

---

## 1. Полиморфизм (Polymorphism)

### Определение

Принцип ООП, при котором разные объекты могут использоваться через один общий тип, но выполнять своё собственное поведение.

### Короткое определение

**Один интерфейс → разное поведение.**

### Мини-пример

```java
class Animal {
    public void sound() {
        System.out.println("звук");
    }
}

class Dog extends Animal {
    @Override
    public void sound() {
        System.out.println("гав");
    }
}

class Cat extends Animal {
    @Override
    public void sound() {
        System.out.println("мяу");
    }
}
```

Использование:

```java
Animal animal = new Dog();

animal.sound(); // гав
```

💡 Переменная типа `Animal`, а поведение — `Dog`.

## 2. Базовый тип (Base Type)

### Определение

Тип родительского класса, через который работают с объектом.

### Короткое определение

**Общий тип для группы объектов.**

### Мини-пример

```java
Figure figure = new Triangle();
```

Тут:

* `Figure` — базовый тип
* `Triangle` — реальный объект

---

## 3. Переопределение метода (Method Overriding)

### Определение

Создание новой реализации метода, который уже существует у родителя.

### Короткое определение

**Изменяем унаследованное поведение.**

### Мини-пример

```java
@Override
public double getArea() {
    return width * height;
}
```

---

## 4. Динамический полиморфизм (Dynamic Dispatch)

### Определение

Java выбирает, какой метод вызвать, во время выполнения программы.

### Короткое определение

**Какой объект лежит — тот метод и выполнится.**

### Мини-пример

```java
Figure figure = new Circle();

figure.getArea();
```

Вызовится:

```java
Circle.getArea()
```

а не `Figure.getArea()`.

💡 Это очень важное понятие для собеседований.

---

## 5. Расширение типа (Upcasting)

### Определение

Преобразование объекта дочернего класса в родительский тип.

### Короткое определение

**Поднимаем объект вверх по иерархии.**

### Мини-пример

```java
Triangle triangle = new Triangle();

Figure figure = triangle;
```

Явное приведение:

```java
(Figure)
```

не требуется.

---

## 6. Сужение типа (Downcasting)

### Определение

Преобразование родительского типа обратно в дочерний.

### Короткое определение

**Опускаемся вниз по иерархии.**

### Мини-пример

```java
Figure figure = new Triangle();

Triangle triangle =
        (Triangle) figure;
```

⚠️ Опасность:

```java
Rectangle rectangle =
        (Rectangle) figure;
```

Получим:

```text
ClassCastException
```

---

## 7. Приведение типов (Type Casting)

### Определение

Изменение представления объекта внутри иерархии наследования.

### Короткое определение

**Сообщаем Java, каким типом считать объект.**

### Мини-пример

```java
(Circle) figure
```

---

## 8. Runtime (Время выполнения)

### Определение

Момент, когда программа уже запущена.

### Короткое определение

**Код уже работает.**

### Мини-пример

Полиморфизм определяется именно в runtime:

```java
animal.sound();
```

---

## 9. Общий контракт

### Определение

Набор методов, который обязаны поддерживать наследники.

### Короткое определение

**Договор между родителем и потомками.**

### Мини-пример

```java
class Figure {
    public double getArea() {
        ...
    }
}
```

Все фигуры обязаны уметь считать площадь.

---

## 10. Заглушка (Stub)

### Определение

Временная упрощённая реализация для продолжения разработки.

### Короткое определение

**Временный объект вместо настоящего.**

### Мини-пример

```java
class Color {
    private String name;
}
```

Потом заменят на полноценный класс.

---

## 11. Исключение (Exception)

### Определение

Механизм обработки ошибок во время выполнения программы.

### Короткое определение

**Сообщение: произошло что-то неправильное.**

### Мини-пример

```java
throw new RuntimeException();
```

---

## 12. super

(добавляем сюда ещё одно значение — оно часто используется в полиморфизме)

### Определение

Ссылка на реализацию родительского класса.

### Короткое определение

**Обращение к версии родителя.**

### Мини-пример

```java
@Override
public Color getFillColor() {
    return super.getFillColor();
}
```

# Очень важная мысль (оставь в словарь отдельно)

```text
Тип переменной определяет,
какие методы доступны.

Реальный объект определяет,
какой код выполнится.
```

Пример:

```java
Figure figure = new Triangle();

figure.getArea();
```

IDE смотрит на `Figure`,
Java выполняет `Triangle`.
