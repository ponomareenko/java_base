# Словарь разработчика — Тема 8. TreeMap и TreeSet

---

## 1. TreeMap

### Определение

`TreeMap` — реализация `Map`, которая хранит пары:

```text
ключ → значение
```

при этом **ключи всегда отсортированы**.

Внутри использует дерево.

### Короткое определение

**TreeMap = HashMap + сортировка ключей.**

### Мини-пример

```java
TreeMap<Integer, String> users =
        new TreeMap<>();

users.put(3, "Alex");
users.put(1, "Tom");

System.out.println(users);
```

↓

```text
{1=Tom, 3=Alex}
```

---

## 2. Дерево (Tree)

### Определение

Структура данных из узлов, связанных между собой.

У дерева:

* есть корень;
* есть потомки;
* есть листья.

### Короткое определение

**Tree = структура из связанных узлов.**

### Мини-пример

```text
      10
     /  \
    5   20
```

---

## 3. Узел (Node)

### Определение

Отдельный элемент дерева.

Может содержать:

* данные;
* ссылки на потомков.

### Короткое определение

**Node = одна ячейка дерева.**

### Мини-пример

```text
Node
└─ value = 15
```

---

## 4. Корень (Root)

### Определение

Самый верхний элемент дерева.

### Короткое определение

**Root = начало дерева.**

### Мини-пример

```text
      15 ← root
```

---

## 5. Лист (Leaf)

### Определение

Узел без потомков.

### Короткое определение

**Leaf = конечный элемент дерева.**

### Мини-пример

```text
   10
  /
 5 ← leaf
```

---

## 6. Бинарное дерево (Binary Tree)

### Определение

Дерево, где каждый узел имеет максимум двух потомков.

### Короткое определение

**Binary Tree = не больше двух детей.**

### Мини-пример

```text
      8
     / \
    3  12
```

---

## 7. Красно-чёрное дерево (Red-Black Tree)

### Определение

Самобалансирующееся бинарное дерево.

На нём построен TreeMap. 

Позволяет сохранять хорошую скорость поиска.

### Короткое определение

**Red-Black Tree = дерево, которое само держит баланс.**

### Мини-пример

Не пишется вручную — Java делает это внутри.

## 8. SortedMap

### Определение

Интерфейс для Map с отсортированными ключами.

### Короткое определение

**SortedMap = Map с порядком.**

### Мини-пример

```java
firstKey();
lastKey();
subMap();
```

---

## 9. NavigableMap

### Определение

Расширение SortedMap.

Позволяет искать соседние элементы.

### Короткое определение

**NavigableMap = умеет двигаться по отсортированным данным.**

### Мини-пример

```java
map.higherKey(10);
map.lowerKey(10);
```

---

## 10. Comparable

### Определение

Интерфейс, который позволяет объекту самому знать, как себя сравнивать.

Метод:

```java
compareTo()
```

### Короткое определение

**Comparable = объект сам умеет сортироваться.**

### Мини-пример

```java
class User
implements Comparable<User> {

public int compareTo(User o){
return id - o.id;
}
}
```

---

## 11. compareTo()

### Определение

Метод сравнения объектов.

Возвращает:

```text
<0 → меньше
0 → равно
>0 → больше
```

### Короткое определение

**compareTo = кто раньше.**

### Мини-пример

```java
"abc".compareTo("zzz");
```

↓

```text
отрицательное число
```

---

## 12. Comparator

### Определение

Отдельный объект, который задаёт правила сортировки.

В отличие от Comparable — не изменяет сам класс.

### Короткое определение

**Comparator = внешний сортировщик.**

### Мини-пример

```java
Comparator<User> byId =
(a,b) -> a.id - b.id;
```

---

## 13. compare()

### Определение

Главный метод Comparator.

### Короткое определение

**compare = сравнить два объекта.**

### Мини-пример

```java
compare(user1, user2)
```

## 14. Естественный порядок (Natural Ordering)

### Определение

Стандартный порядок сортировки.

Например:

```text
1 2 3 4
a b c
```

### Короткое определение

**Natural Ordering = сортировка по умолчанию.**

### Мини-пример

```java
TreeSet<Integer> nums =
new TreeSet<>();
```

---

## 15. TreeSet

### Определение

Коллекция уникальных элементов, которая хранит их отсортированными.

Внутри использует TreeMap. 

### Короткое определение

**TreeSet = HashSet + сортировка.**

### Мини-пример

```java
TreeSet<Integer> set =
new TreeSet<>();

set.add(5);
set.add(2);

System.out.println(set);
```

↓

```text
[2, 5]
```

---

## 16. SortedSet

### Определение

Интерфейс множества с сортировкой.

### Короткое определение

**SortedSet = отсортированный Set.**

### Мини-пример

```java
set.first();
set.last();
```

---

## 17. NavigableSet

### Определение

Расширенный SortedSet для поиска соседних элементов.

### Короткое определение

**NavigableSet = навигация по множеству.**

### Мини-пример

```java
set.higher(10);
set.lower(10);
```

---

## 18. Comparator chaining (цепочка компараторов)

### Определение

Сортировка по нескольким критериям подряд.

### Короткое определение

**Сначала одно поле → потом второе.**

### Мини-пример

```java
Comparator
.comparing(User::getName)
.thenComparing(User::getAge);
```

# Очень важная таблица

| Коллекция | Порядок | Дубликаты       | Скорость поиска |
| --------- | ------- | --------------- | --------------- |
| ArrayList | ✅       | ✅               | O(n)            |
| HashSet   | ❌       | ❌               | O(1)            |
| HashMap   | ❌       | ключи уникальны | O(1)            |
| TreeSet   | ✅       | ❌               | O(log n)        |
| TreeMap   | ✅       | ключи уникальны | O(log n)        |

# Что обязательно запомнить

```text
Hash → быстро

Tree → отсортировано

Comparable →
сортировка внутри класса

Comparator →
сортировка снаружи класса
```
