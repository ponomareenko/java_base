# Словарь разработчика — Тема 9. Queue

---

## 1. Queue (Очередь)

### Определение

`Queue` — интерфейс коллекции, работающий по принципу:

```text
FIFO
First In First Out
```

Первый пришёл → первый обработался. 

### Короткое определение

**Queue = очередь как в магазине.**

### Мини-пример

```java
Queue<String> queue =
        new LinkedList<>();

queue.offer("Tom");
queue.offer("Max");

System.out.println(
        queue.poll()
);
```

↓

```text
Tom
```

---

## 2. FIFO (First In First Out)

### Определение

Принцип обработки:

первый добавленный элемент извлекается первым.

### Короткое определение

**FIFO = первый вошёл → первый вышел.**

### Мини-пример

```text
[A][B][C]

poll()

→ A
```

---

## 3. add()

### Определение

Добавляет элемент в конец очереди.

Если не получилось — бросает исключение.

### Короткое определение

**add = добавить или упасть.**

### Мини-пример

```java
queue.add("User");
```

---

## 4. offer()

### Определение

Добавляет элемент в очередь.

Если не получилось — возвращает `false`.

### Короткое определение

**offer = попробовать добавить.**

### Мини-пример

```java
queue.offer("User");
```

---

## 5. element()

### Определение

Возвращает первый элемент.

Не удаляет.

Если очередь пустая — исключение.

### Короткое определение

**element = посмотреть первый.**

### Мини-пример

```java
queue.element();
```

---

## 6. peek()

### Определение

Возвращает первый элемент.

Не удаляет.

Если пусто → `null`.

### Короткое определение

**peek = заглянуть.**

### Мини-пример

```java
queue.peek();
```

---

## 7. remove()

### Определение

Возвращает и удаляет первый элемент.

Если пусто → исключение.

### Короткое определение

**remove = забрать первый.**

### Мини-пример

```java
queue.remove();
```

---

## 8. poll()

### Определение

Возвращает и удаляет первый элемент.

Если пусто → `null`.

### Короткое определение

**poll = безопасно забрать.**

### Мини-пример

```java
queue.poll();
```

---

## 9. PriorityQueue

### Определение

Очередь, которая сама сортирует элементы.

По умолчанию — естественный порядок.

Можно задать Comparator. 

### Короткое определение

**PriorityQueue = очередь по важности.**

### Мини-пример

```java
PriorityQueue<Integer> pq =
new PriorityQueue<>();

pq.offer(5);
pq.offer(1);

System.out.println(
pq.poll()
);
```

↓

```text
1
```

---

## 10. Priority (Приоритет)

### Определение

Правило, определяющее порядок обработки.

### Короткое определение

**Priority = кто важнее.**

### Мини-пример

```text
Высокий
Средний
Низкий
```

## 11. AbstractQueue

### Определение

Абстрактный класс с базовой реализацией Queue.

### Короткое определение

**AbstractQueue = полуготовая очередь.**

### Мини-пример

Не создаётся напрямую.

---

## 12. Deque (Double Ended Queue)

### Определение

Двунаправленная очередь.

Можно работать с двумя концами. 

### Короткое определение

**Deque = очередь с двумя дверями.**

### Мини-пример

```java
Deque<String> deque =
new ArrayDeque<>();
```

---

## 13. LIFO (Last In First Out)

### Определение

Последний вошёл → первый вышел.

Принцип стека.

### Короткое определение

**LIFO = стопка тарелок.**

### Мини-пример

```text
A
B
C

pop()

→ C
```

---

## 14. addFirst()

### Определение

Добавляет элемент в начало.

### Короткое определение

**addFirst = вставить первым.**

### Мини-пример

```java

```

## 15. addLast()

### Определение


## 16. pollFirst()

### Определение

### Короткое определение

**pollFirst = забрать начало.**

### Мини-пример

```java
deque.pollFirst();
```

---

## 17. pollLast()

### Определение

Вернуть и удалить последний элемент.

### Короткое определение

**pollLast = забрать конец.**

### Мини-пример

```java
deque.pollLast();
```

## 18. ArrayDeque

### Определение

Самая популярная реализация Deque.

Основана на массиве.

Обычно быстрее `LinkedList`. 

### Короткое определение

**ArrayDeque = современная очередь/стек.**

### Мини-пример

```java
Deque<Integer> deque =
new ArrayDeque<>();
```

---

## 19. Stack

### Определение

Старая реализация стека.

Работает по LIFO.

Не рекомендуется использовать. 

### Короткое определение

**Stack = старый стек.**

### Мини-пример

```java
Stack<Integer> stack =
new Stack<>();
```

| Структура     | Принцип       |
| ------------- | ------------- |
| Queue         | FIFO          |
| Stack         | LIFO          |

```text
Deque →

очередь с сортировкой
```
