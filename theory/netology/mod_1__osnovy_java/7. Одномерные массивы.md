# Словарь Java — Тема 7. Одномерные массивы

# Основа

## 1. Массив (Array)

**Определение:**
Структура данных для хранения **фиксированного количества элементов одного типа**. 

Пример:

```java
int[] prices = {5, 3, 15, 100};
```

**Простыми словами:**
Массив — это шкаф с пронумерованными ящиками.

---

## 2. Одномерный массив

**Определение:**
Массив, где доступ к элементу происходит по одному индексу.

Пример:

```java
arr[2]
```

---

## 3. Элемент массива (Array Element)

**Определение:**
Отдельное значение внутри массива.

Пример:

```java
int[] arr = {10, 20, 30};
```

Элементы:

```text
10
20
30
```

---

## 4. Индекс (Index)

**Определение:**
Позиция элемента в массиве. Начинается с **0**. 

Пример:

```text
A B C
0 1 2
```

Получение:

```java
arr[1]
```

---

## 5. Длина массива (`length`)

**Определение:**
Количество элементов массива.

Пример:

```java
arr.length
```

Запомнить:

```text
length → поле массива
length() → метод строки
```

Это одна из самых частых ошибок новичков.

---

# Создание массива

## 6. Объявление массива (Declaration)

**Определение:**
Создание переменной массива.

Пример:

```java
int[] numbers;
```

---

## 7. Инициализация массива (Initialization)

**Определение:**
Создание массива и заполнение начальными значениями. 

Пример:

```java
int[] numbers = {1, 2, 3};
```

---

## 8. Выделение памяти (Memory Allocation)

**Определение:**
Создание места под элементы массива.

Пример:

```java
new int[5]
```

Создаётся память на 5 элементов.

---

## 9. Значения по умолчанию (Default Values)

**Определение:**
Значения, которыми Java автоматически заполняет массив. 

Примеры:

```text
int → 0
double → 0.0
boolean → false
String → null
```

---

## 10. Оператор `new`

**Определение:**
Создаёт объект массива в памяти.

Пример:

```java
new int[10]
```

---

# Работа с массивом

## 11. Доступ по индексу

**Определение:**
Получение элемента через его номер.

Пример:

```java
arr[0]
```

---

## 12. Присваивание элемента

**Определение:**
Изменение значения внутри массива.

Пример:

```java
arr[2] = 100;
```

---

## 13. Выход за границы массива

(Array Index Out Of Bounds)
**Определение:**
Попытка обратиться к несуществующему индексу.

Пример:

```java
int[] arr = {1, 2};

arr[5];
```

Результат:

```text
ArrayIndexOutOfBoundsException
```

⚠️ Очень частая ошибка.

---

# Arrays

## 14. Класс `Arrays`

**Определение:**
Утильный класс Java для работы с массивами. 

Подключение:

```java
import java.util.Arrays;
```

---

## 15. Утильный класс (Utility Class)

**Определение:**
Класс, который содержит только полезные методы.

Пример:

```text
Arrays
Math
Collections
```

---

## 16. `Arrays.toString()`

**Определение:**
Преобразует массив в читаемую строку. 

Пример:

```java
System.out.println(Arrays.toString(arr));
```

Результат:

```text
[5, 3, 15]
```

---

## 17. `Arrays.equals()`

**Определение:**
Сравнивает содержимое массивов. 

Пример:

```java
Arrays.equals(arr1, arr2)
```

---

## 18. `Arrays.sort()`

**Определение:**
Сортирует массив.

Пример:

```java
Arrays.sort(arr);
```

До:

```text
5 2 9
```

После:

```text
2 5 9
```

---

## 19. `Arrays.copyOf()`

**Определение:**
Создаёт копию массива.

Пример:

```java
Arrays.copyOf(arr, 5)
```

---

## 20. `Arrays.copyOfRange()`

**Определение:**
Копирует часть массива.

Пример:

```java
Arrays.copyOfRange(arr, 1, 4)
```

---

## 21. `Arrays.fill()`

**Определение:**
Заполняет массив одним значением.

Пример:

```java
Arrays.fill(arr, 10);
```

---

## 22. `Arrays.binarySearch()`

**Определение:**
Поиск элемента бинарным поиском.

Важно:

```text
работает только на отсортированном массиве
```

---

## 23. `Arrays.asList()`

**Определение:**
Преобразует массив в список (`List`).

Пример:

```java
Arrays.asList(arr)
```

---

# Перебор массива

## 24. Перебор массива (Iteration)

**Определение:**
Последовательный проход по всем элементам.

---

## 25. Цикл `for`

**Определение:**
Цикл со счётчиком — часто используется для массивов. 

Пример:

```java
for (int i = 0; i < arr.length; i++)
```

---

## 26. Счётчик цикла

**Определение:**
Переменная, управляющая количеством проходов.

Обычно:

```java
i
```

---

## 27. Цикл `foreach`

**Определение:**
Специальный цикл для перебора массива без индексов. 

Пример:

```java
for (String name : names)
```

---

## 28. Переменная итерации

**Определение:**
Переменная, куда кладётся текущий элемент.

Пример:

```java
for (String name : names)
```

Переменная:

```text
name
```

---

## 29. Метод `startsWith()`

**Определение:**
Проверяет, начинается ли строка с указанного текста. 

Пример:

```java
name.startsWith("P")
```
