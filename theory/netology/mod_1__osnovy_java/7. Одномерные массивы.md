# Тема 7: Одномерные массивы

---

## 1. Массив

**Определение:**

Массив — это структура данных, которая хранит набор элементов одного типа.

**Пример:**

```java
int[] prices = new int[5];
```

**Важно:**

Все элементы массива должны быть одного типа. Например, массив `int[]` может хранить только значения типа `int`.

---

## 2. Элемент массива

**Определение:**

Элемент массива — это отдельное значение, которое хранится внутри массива.

**Пример:**

```java
int[] prices = {5, 3, 15, 100, 1};

System.out.println(prices[0]); // 5
```

В этом примере `5` — первый элемент массива.

---

## 3. Индекс

**Определение:**

Индекс — это номер позиции элемента в массиве.

**Пример:**

```java
int[] prices = {5, 3, 15, 100, 1};

System.out.println(prices[0]); // 5
System.out.println(prices[1]); // 3
```

**Важно:**

Индексация в массивах начинается с нуля. Первый элемент имеет индекс `0`, второй — индекс `1`.

---

## 4. Одномерный массив

**Определение:**

Одномерный массив — это массив, в котором для доступа к элементу нужен один индекс.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Tanya"};

System.out.println(names[0]); // Petya
```

**Важно:**

В одномерном массиве элементы расположены как одна линия: каждый элемент имеет один номер позиции.

---

## 5. Объявление массива

**Определение:**

Объявление массива — это создание переменной, которая будет хранить ссылку на массив.

**Пример:**

```java
int[] prices;
```

**Альтернативная запись:**

```java
int prices[];
```

**Важно:**

В Java чаще используют запись `int[] prices`, потому что она лучше показывает, что тип переменной — массив целых чисел.

---

## 6. Создание массива

**Определение:**

Создание массива — это выделение памяти под массив с помощью оператора `new`.

**Пример:**

```java
int[] prices = new int[5];
```

**Важно:**

После создания размер массива изменить нельзя.

---

## 7. Размер массива

**Определение:**

Размер массива — это количество элементов, которое массив может хранить.

**Пример:**

```java
int[] prices = new int[5];
```

В этом примере размер массива — `5`.

**Важно:**

Размер массива задаётся при создании массива и остаётся фиксированным.

---

## 8. Инициализация массива

**Определение:**

Инициализация массива — это заполнение массива начальными значениями.

**Пример через `new`:**

```java
int[] prices = new int[5];

prices[0] = 5;
prices[1] = 3;
prices[2] = 15;
prices[3] = 100;
prices[4] = 1;
```

**Пример сразу со значениями:**

```java
int[] prices = {5, 3, 15, 100, 1};
```

---

## 9. Значения по умолчанию

**Определение:**

Значения по умолчанию — это значения, которыми Java автоматически заполняет элементы массива при создании.

**Пример:**

```java
int[] numbers = new int[3];

System.out.println(numbers[0]); // 0
System.out.println(numbers[1]); // 0
System.out.println(numbers[2]); // 0
```

**Важно:**

При создании массива элементы заполняются автоматически:

```text
числовые типы   -> 0
boolean         -> false
ссылочные типы  -> null
```

---

## 10. Доступ к элементу массива

**Определение:**

Доступ к элементу массива — это обращение к значению по его индексу.

**Пример:**

```java
int[] prices = {5, 3, 15, 100, 1};

System.out.println(prices[2]); // 15
```

---

## 11. Изменение элемента массива

**Определение:**

Изменение элемента массива — это присваивание нового значения элементу по индексу.

**Пример:**

```java
int[] prices = {5, 3, 15, 100, 1};

prices[0] = 10;

System.out.println(prices[0]); // 10
```

---

## 12. Выход за границы массива

**Определение:**

Выход за границы массива — это попытка обратиться к индексу, которого в массиве не существует.

**Пример:**

```java
int[] prices = {5, 3, 15, 100, 1};

System.out.println(prices[5]);
```

**Важно:**

В этом примере будет ошибка `ArrayIndexOutOfBoundsException`, потому что последний индекс массива — `4`, а не `5`.

---

## 13. `ArrayIndexOutOfBoundsException`

**Определение:**

`ArrayIndexOutOfBoundsException` — ошибка, которая возникает при обращении к несуществующему индексу массива.

**Пример:**

```java
int[] prices = new int[5];

System.out.println(prices[10]);
```

**Важно:**

Если размер массива `5`, допустимые индексы: `0`, `1`, `2`, `3`, `4`.

---

## 14. `length`

**Определение:**

`length` — свойство массива, которое возвращает количество элементов в массиве.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya"};

System.out.println(names.length); // 3
```

**Важно:**

У массивов используется именно свойство `length`, без круглых скобок.

```java
names.length      // правильно
names.length()    // неправильно для массива
```

У строки `String`, наоборот, используется метод `length()`.

```java
text.length()     // правильно для String
```

---

## 15. Вывод массива в консоль

**Определение:**

Вывод массива в консоль — это отображение всех элементов массива в удобном виде.

**Пример:**

```java
import java.util.Arrays;

int[] prices = {5, 3, 15, 100, 1};

System.out.println(Arrays.toString(prices));
```

**Результат:**

```text
[5, 3, 15, 100, 1]
```

**Важно:**

Если вывести массив напрямую, Java покажет не элементы массива, а техническое строковое представление объекта.

---

## 16. `Arrays.toString()`

**Определение:**

`Arrays.toString()` — метод класса `Arrays`, который возвращает элементы массива в виде строки.

**Пример:**

```java
import java.util.Arrays;

int[] prices = {5, 3, 15, 100, 1};

System.out.println(Arrays.toString(prices));
```

**Результат:**

```text
[5, 3, 15, 100, 1]
```

---

## 17. Класс `Arrays`

**Определение:**

`Arrays` — утилитный класс Java, который содержит готовые методы для работы с массивами.

**Пример:**

```java
import java.util.Arrays;

int[] prices = {5, 3, 15, 100, 1};

System.out.println(Arrays.toString(prices));
```

**Важно:**

Чтобы использовать класс `Arrays`, его нужно импортировать:

```java
import java.util.Arrays;
```

---

## 18. Утилитный класс

**Определение:**

Утилитный класс — это класс, который содержит готовые вспомогательные методы для выполнения типовых задач.

**Пример:**

```java
Arrays.toString(prices);
Arrays.equals(firstArray, secondArray);
Arrays.sort(prices);
```

**Важно:**

Класс `Arrays` не описывает конкретный объект массива, а даёт набор полезных инструментов для работы с массивами.

---

## 19. Сравнение массивов

**Определение:**

Сравнение массивов — это проверка, содержат ли два массива одинаковые элементы в одинаковом порядке.

**Неправильный способ:**

```java
int[] first = {5, 3, 15};
int[] second = {5, 3, 15};

System.out.println(first == second);      // false
System.out.println(first.equals(second)); // false
```

**Правильный способ:**

```java
import java.util.Arrays;

int[] first = {5, 3, 15};
int[] second = {5, 3, 15};

System.out.println(Arrays.equals(first, second)); // true
```

**Важно:**

Массивы являются ссылочными типами. Поэтому `==` сравнивает ссылки, а не содержимое массивов.

---

## 20. `Arrays.equals()`

**Определение:**

`Arrays.equals()` — метод класса `Arrays`, который сравнивает содержимое двух массивов.

**Пример:**

```java
import java.util.Arrays;

int[] first = {5, 3, 15};
int[] second = {5, 3, 15};

System.out.println(Arrays.equals(first, second)); // true
```

**Важно:**

Для одномерных массивов обычно используют `Arrays.equals()`. Для многомерных массивов нужен другой метод — `Arrays.deepEquals()`.

---

## 21. Массив ссылочных типов

**Определение:**

Массив ссылочных типов — это массив, элементы которого хранят ссылки на объекты.

**Пример со строками:**

```java
String[] names = {"Petya", "Olya", "Tanya"};
```

**Пример с объектами:**

```java
Singer[] singers = new Singer[4];
```

**Важно:**

При создании массива ссылочных типов через `new` его элементы по умолчанию равны `null`.

---

## 22. Массив объектов

**Определение:**

Массив объектов — это массив, который хранит ссылки на объекты определённого класса.

**Пример:**

```java
Singer[] singers = {
        new Singer("Petya", 8),
        new Singer("Olya", 15, 4)
};
```

**Важно:**

Массив хранит не сами объекты напрямую, а ссылки на них.

---

## 23. Обход массива

**Определение:**

Обход массива — это последовательная обработка элементов массива.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya"};

for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}
```

**Важно:**

Для обхода массива часто используют цикл `for` или `foreach`.

---

## 24. Обход массива через `for`

**Определение:**

Обход массива через `for` — это обработка элементов массива с использованием индекса.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya", "Pavel", "Oleg"};

for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}
```

**Важно:**

Обычный `for` нужен, когда важен индекс элемента или нужно изменять элементы массива по индексу.

---

## 25. `foreach`

**Определение:**

`foreach` — разновидность цикла `for`, которая позволяет пройти по всем элементам массива или коллекции без ручной работы с индексами.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya", "Pavel", "Oleg"};

for (String name : names) {
    System.out.println(name);
}
```

**Важно:**

`foreach` удобно использовать, когда нужно просто прочитать каждый элемент массива.

---

## 26. Переменная цикла `foreach`

**Определение:**

Переменная цикла `foreach` — это переменная, в которую Java по очереди кладёт каждый элемент массива.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya"};

for (String name : names) {
    System.out.println(name);
}
```

В этом примере `name` по очереди принимает значения `"Petya"`, `"Olya"`, `"Anya"`.

---

## 27. `startsWith()`

**Определение:**

`startsWith()` — метод класса `String`, который проверяет, начинается ли строка с указанного текста.

**Пример:**

```java
String name = "Petya";

System.out.println(name.startsWith("P")); // true
System.out.println(name.startsWith("A")); // false
```

---

## 28. Логическое отрицание `!`

**Определение:**

`!` — логический оператор, который меняет значение условия на противоположное.

**Пример:**

```java
String name = "Olya";

if (!name.startsWith("P")) {
    System.out.println(name);
}
```

**Важно:**

Если `name.startsWith("P")` возвращает `false`, то `!name.startsWith("P")` превращает результат в `true`.

---

## 29. Фильтрация массива

**Определение:**

Фильтрация массива — это выбор только тех элементов, которые подходят под заданное условие.

**Пример:**

```java
String[] names = {"Petya", "Olya", "Anya", "Pavel", "Oleg"};

for (String name : names) {
    if (!name.startsWith("P")) {
        System.out.println(name);
    }
}
```

**Результат:**

```text
Olya
Anya
Oleg
```

---

## 30. `Arrays.copyOf()`

**Определение:**

`Arrays.copyOf()` — метод класса `Arrays`, который создаёт копию массива указанной длины.

**Пример:**

```java
import java.util.Arrays;

int[] original = {1, 2, 3};
int[] copy = Arrays.copyOf(original, original.length);

System.out.println(Arrays.toString(copy)); // [1, 2, 3]
```

---

## 31. `Arrays.copyOfRange()`

**Определение:**

`Arrays.copyOfRange()` — метод класса `Arrays`, который копирует часть массива в новый массив.

**Пример:**

```java
import java.util.Arrays;

int[] numbers = {10, 20, 30, 40, 50};

int[] part = Arrays.copyOfRange(numbers, 1, 4);

System.out.println(Arrays.toString(part)); // [20, 30, 40]
```

**Важно:**

Начальный индекс включается, конечный индекс не включается.

---

## 32. `Arrays.sort()`

**Определение:**

`Arrays.sort()` — метод класса `Arrays`, который сортирует массив.

**Пример:**

```java
import java.util.Arrays;

int[] numbers = {5, 1, 10, 3};

Arrays.sort(numbers);

System.out.println(Arrays.toString(numbers)); // [1, 3, 5, 10]
```

**Важно:**

`Arrays.sort()` изменяет исходный массив.

---

## 33. `Arrays.binarySearch()`

**Определение:**

`Arrays.binarySearch()` — метод класса `Arrays`, который ищет элемент в отсортированном массиве методом бинарного поиска.

**Пример:**

```java
import java.util.Arrays;

int[] numbers = {1, 3, 5, 10};

int index = Arrays.binarySearch(numbers, 5);

System.out.println(index); // 2
```

**Важно:**

Перед использованием `binarySearch()` массив должен быть отсортирован.

---

## 34. `Arrays.fill()`

**Определение:**

`Arrays.fill()` — метод класса `Arrays`, который заполняет массив переданным значением.

**Пример:**

```java
import java.util.Arrays;

int[] numbers = new int[5];

Arrays.fill(numbers, 7);

System.out.println(Arrays.toString(numbers)); // [7, 7, 7, 7, 7]
```

---

## 35. `Arrays.asList()`

**Определение:**

`Arrays.asList()` — метод класса `Arrays`, который возвращает список на основе переданных элементов или массива.

**Пример:**

```java
import java.util.Arrays;
import java.util.List;

List<String> names = Arrays.asList("Petya", "Olya", "Anya");

System.out.println(names);
```

**Важно:**

Список, созданный через `Arrays.asList()`, имеет фиксированный размер: в него нельзя просто так добавить или удалить элемент через `add()` или `remove()`.
