# Словарь Java — Тема 5. Типы данных в Java. Объекты

# Основа ООП

## 1. Объект (Object)

**Определение:**
Экземпляр класса, который хранит данные и умеет выполнять действия.

**Простыми словами:**
Класс — это чертёж.
Объект — это уже построенный дом.

Пример:

```java
String name = "Агапи";
```

Здесь объект:

```java
"Агапи"
```

---

## 2. Ссылочный тип (Reference Type)

**Определение:**
Тип данных, в котором хранится не само значение, а ссылка на объект в памяти. 

Примеры:

```java
String
Scanner
Object
Integer
ArrayList
```

---

## 3. Ссылка (Reference)

**Определение:**
Переменная, которая хранит адрес объекта.

Пример:

```java
String text = "Hello";
```

Тут:

```text
text → ссылка
"Hello" → объект
```

---

## 4. Примитивный тип (Primitive Type)

**Определение:**
Тип, который хранит само значение напрямую.

Пример:

```java
int age = 25;
```

---

## 5. Heap (Куча)

**Определение:**
Область памяти JVM, где создаются объекты. 

**Упрощённо:**

```text
Stack → ссылки
Heap → объекты
```

Пока этого понимания достаточно.

---

# Создание объектов

## 6. Оператор `new`

**Определение:**
Оператор создания нового объекта в памяти. 

Пример:

```java
Scanner scanner = new Scanner(System.in);
```

Что происходит:

1. выделяется память;
2. создаётся объект;
3. возвращается ссылка.

---

## 7. Конструктор (Constructor)

**Определение:**
Специальный метод, который вызывается при создании объекта.

Пример:

```java
new String("Hello")
```

Конструктор:

```java
String(...)
```

---

## 8. Экземпляр класса (Instance)

**Определение:**
Другое название объекта.

Пример:

```java
Car bmw = new Car();
```

`bmw` — экземпляр класса `Car`.

---

## 9. `null`

**Определение:**
Специальное значение — ссылка никуда не указывает. 

Пример:

```java
String text = null;
```

Это НЕ пустая строка.

❌

```java
""
```

Это настоящий объект.

---

# String

## 10. `String`

**Определение:**
Класс для хранения текста. 

Пример:

```java
String city = "Москва";
```

---

## 11. Литерал строки (String Literal)

**Определение:**
Строка, записанная прямо в коде.

Пример:

```java
"Hello"
```

---

## 12. Конкатенация (Concatenation)

**Определение:**
Объединение строк.

Пример:

```java
String result = "Hello " + "world";
```

Результат:

```text
Hello world
```

---

## 13. Метод

**Определение:**
Функция внутри класса.

Пример:

```java
text.length()
```

---

## 14. `length()`

**Определение:**
Метод получения длины строки.

Пример:

```java
String text = "Java";

text.length();
```

Результат:

```text
4
```

---

## 15. `charAt(index)`

**Определение:**
Метод получения символа по индексу. 

Пример:

```java
text.charAt(0)
```

Результат:

```text
J
```

---

## 16. Индекс (Index)

**Определение:**
Позиция элемента.

В Java начинается с:

```text
0
```

Пример:

```text
J a v a
0 1 2 3
```

---

# Сравнение объектов

## 17. `==`

**Определение:**
Для объектов сравнивает ссылки.

Пример:

```java
s1 == s2
```

Вопрос:

> Это один объект?

---

## 18. `equals()`

**Определение:**
Сравнивает содержимое объектов. 

Пример:

```java
s1.equals(s2)
```

Вопрос:

> Значения одинаковые?

---

Запомни золотое правило:

```text
== → один объект?

equals() → одинаковые данные?
```

---

# Оптимизация строк

## 19. `StringBuilder`

**Определение:**
Класс для эффективной сборки строк. 

Плохо:

```java
result = a + b + c;
```

Лучше:

```java
StringBuilder sb = new StringBuilder();

sb.append("Java");
```

---

## 20. `append()`

**Определение:**
Метод добавления текста в `StringBuilder`.

Пример:

```java
builder.append("Hello");
```

---

## 21. `toString()`

**Определение:**
Метод преобразования объекта в строку.

Пример:

```java
builder.toString();
```

---

# Enum

## 22. `enum`

**Определение:**
Тип данных для фиксированного набора значений. 

Пример:

```java
enum Season {

    SPRING,
    SUMMER
}
```

---

## 23. Константа (Constant)

**Определение:**
Значение, которое не изменяется.

Пример:

```java
final int MAX = 100;
```

---

# Wrapper

## 24. Класс-обёртка (Wrapper Class)

**Определение:**
Объектная версия примитивного типа. 

Таблица:

```text
int      → Integer
double   → Double
char     → Character
boolean  → Boolean
```

---

## 25. Парсинг (Parsing)

**Определение:**
Преобразование текста в другой тип.

Пример:

```java
Integer.parseInt("1901")
```

Результат:

```text
1901
```
