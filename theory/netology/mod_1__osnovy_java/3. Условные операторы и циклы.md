# Словарь Java — Тема 3. Условные операторы и циклы

## 1. Условный оператор (Conditional Statement)

**Определение:**
Конструкция языка, которая позволяет выполнять разный код в зависимости от выполнения условия.

**Простыми словами:**
«Если произошло А → делаем одно, иначе → другое».

**Пример:**

```java
if (age >= 18) {
    System.out.println("Доступ разрешён");
}
```

**Важно:**
Условные операторы создают **ветвление программы**.

---

## 2. Ветвление (Branching)

**Определение:**
Изменение пути выполнения программы в зависимости от условий.

**Простыми словами:**
Программа идёт не по одной дороге, а выбирает направление.

---

## 3. Условие (Condition)

**Определение:**
Выражение, которое возвращает только два значения:

```java
true
false
```

**Пример:**

```java
temperature > 100
```

---

# Оператор if

## 4. Оператор `if`

**Определение:**
Условный оператор, который выполняет код только если условие истинно.

**Синтаксис:**

```java
if (условие) {
    код
}
```

**Пример:**

```java
if (score >= 60) {
    System.out.println("Экзамен сдан");
}
```

---

## 5. Блок кода (Code Block)

**Определение:**
Набор инструкций внутри фигурных скобок `{}`.

**Пример:**

```java
{
   int x = 10;
   System.out.println(x);
}
```

---

## 6. `else`

**Определение:**
Блок, который выполнится, если условие оказалось ложным.

```java
if (rain) {
    takeUmbrella();
} else {
    goOutside();
}
```

---

## 7. `else if`

**Определение:**
Дополнительная проверка следующего условия.

```java
if (score == 5) {

} else if (score == 4) {

}
```

---

# Оператор switch

## 8. `switch`

**Определение:**
Условный оператор для выбора одного варианта из нескольких.

**Когда используют:**
Когда сравнивают **одно значение с несколькими вариантами**.

```java
switch (day) {
    case 1:
        break;
}
```

---

## 9. `case`

**Определение:**
Отдельный вариант внутри `switch`.

```java
case 1:
```

---

## 10. `default`

**Определение:**
Выполняется, если ни один `case` не подошёл.

Аналог:

```java
else
```

---

## 11. `break`

**Определение:**
Оператор немедленного выхода из конструкции.

Чаще всего:

* из `switch`
* из цикла

```java
break;
```

**Типичная ошибка новичков:**
забыть `break` внутри `switch`.

---

# Тернарный оператор

## 12. Тернарный оператор `?:`

**Определение:**
Короткая форма записи `if-else`, которая возвращает значение.

**Синтаксис:**

```java
условие ? значение1 : значение2
```

**Пример:**

```java
int max = a > b ? a : b;
```

**Важно:**
Используют для простого выбора значения, а не для сложной логики.

---

# Сравнение значений

## 13. Оператор `==`

**Определение:**
Проверяет равенство значений.

Для примитивов:

```java
int
double
boolean
char
```

Пример:

```java
x == y
```

---

## 14. Метод `equals()`

**Определение:**
Метод сравнения содержимого объектов.

Для строк:

```java
name.equals("Иван")
```

❌ Неправильно:

```java
name == "Иван"
```

✅ Правильно:

```java
name.equals("Иван")
```

---

# Логические операторы

## 15. Конъюнкция (`&&`)

**Определение:**
Логическое И.

Все условия должны быть истинными.

```java
age >= 18 && age < 60
```

---

## 16. Дизъюнкция (`||`)

**Определение:**
Логическое ИЛИ.

Достаточно одного истинного условия.

```java
age < 18 || age > 60
```

---

## 17. Таблица истинности

**Определение:**
Таблица результатов логических операций.

Пример для `&&`:

| A    | B     | Результат |
| ---- | ----- | --------- |
| true | true  | true      |
| true | false | false     |

---

# Циклы

## 18. Цикл (Loop)

**Определение:**
Конструкция для многократного выполнения кода.

---

## 19. Итерация

**Определение:**
Одно выполнение тела цикла.

```java
for (...) {
}
```

Каждый проход → одна итерация.

---

## 20. `while`

**Определение:**
Цикл с предусловием.

Сначала проверка → потом выполнение.

```java
while (x < 10)
```

---

## 21. `do while`

**Определение:**
Цикл с постусловием.

Сначала выполняется → потом проверяется.

Минимум одна итерация гарантирована.

---

## 22. `for`

**Определение:**
Цикл со счётчиком.

```java
for (int i = 0; i < 10; i++)
```

---

## 23. Счётчик цикла

**Определение:**
Переменная, управляющая количеством повторений.

Обычно:

```java
i
```

---

## 24. Инкремент (`++`)

**Определение:**
Увеличение значения на 1.

```java
i++
```

---

## 25. `foreach`

**Определение:**
Цикл для перебора массива или коллекции.

```java
for (String item : list)
```

---

## 26. `continue`

**Определение:**
Пропускает текущую итерацию и переходит к следующей.

```java
continue;
```

---

## 27. Бесконечный цикл

**Определение:**
Цикл без условия завершения.

```java
while (true)
```

---

## 28. `Scanner`

**Определение:**
Класс для чтения данных от пользователя.

```java
Scanner scanner = new Scanner(System.in);
```

---

## 29. `nextLine()`

**Определение:**
Метод чтения строки из консоли.

```java
scanner.nextLine();
```

---
