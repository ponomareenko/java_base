# Тема: 3. Условные операторы и циклы

---

## 1. Условный оператор

**Определение:**

Конструкция языка, которая позволяет выполнять разный код в зависимости от выполнения условия.

**Пример:**

```java
int age = 18;

if (age >= 18) {
    System.out.println("Доступ разрешён");
}
```

**Коротко:**

Условный оператор отвечает на вопрос:
«Если условие верное — что делать?»

---

## 2. Ветвление

**Определение:**

Ветвление — это ситуация, когда программа может пойти по разным путям выполнения в зависимости от условия.

**Пример:**

```java
int temperature = 100;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else {
    System.out.println("Чайник ещё греется");
}
```

**Коротко:**

Ветвление = развилка в программе.

---

## 3. `if`

**Определение:**

`if` — условный оператор, который выполняет блок кода, если условие истинно.

**Пример:**

```java
int temperature = 100;

if (temperature == 100) {
    System.out.println("Выключить чайник");
}
```

**Важно:**

Код внутри `{}` выполнится только тогда, когда условие вернёт `true`.

---

## 4. `else`

**Определение:**

`else` — блок кода, который выполняется, если условие в `if` оказалось ложным.

**Пример:**

```java
int temperature = 70;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else {
    System.out.println("Чайник ещё не вскипел");
}
```

**Коротко:**

`else` = «иначе».

---

## 5. `else if`

**Определение:**

`else if` используется, когда нужно проверить несколько условий подряд.

**Пример:**

```java
int temperature = 85;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else if (temperature == 85) {
    System.out.println("Осталось 20 секунд");
} else if (temperature == 60) {
    System.out.println("Включить дополнительный нагрев");
} else {
    System.out.println("Продолжить нагрев");
}
```

**Коротко:**

`else if` = дополнительная проверка, если предыдущий `if` не сработал.

---

## 6. Блок кода

**Определение:**

Блок кода — это группа инструкций, заключённая в фигурные скобки `{}`.

**Пример:**

```java
if (age >= 18) {
    System.out.println("Можно войти");
    System.out.println("Добро пожаловать");
}
```

**Важно:**

В Java принято использовать `{}` даже для одной строки.
Так код безопаснее и понятнее.

---

## 7. `switch`

**Определение:**

`switch` — условный оператор, который сравнивает значение переменной с несколькими вариантами `case`.

**Пример:**

```java
int temperature = 0;

switch (temperature) {
    case 0:
        System.out.println("Включить компрессор");
        break;
    case -20:
        System.out.println("Отключить компрессор");
        break;
    default:
        System.out.println("Оставить текущий режим");
}
```

**Коротко:**

`switch` удобно использовать, когда есть одна переменная и несколько конкретных вариантов её значения.

---

## 8. `case`

**Определение:**

`case` — вариант значения внутри оператора `switch`.

**Пример:**

```java
switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
}
```

**Коротко:**

`case` = «если значение равно вот этому варианту».

---

## 9. `default`

**Определение:**

`default` — блок внутри `switch`, который выполняется, если ни один `case` не подошёл.

**Пример:**

```java
int day = 10;

switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    default:
        System.out.println("Неизвестный день");
}
```

**Коротко:**

`default` в `switch` похож на `else` в `if`.

---

## 10. `break`

**Определение:**

`break` — оператор, который прерывает выполнение `switch` или цикла.

**Пример в `switch`:**

```java
int command = 1;

switch (command) {
    case 1:
        System.out.println("Старт");
        break;
    case 2:
        System.out.println("Стоп");
        break;
}
```

**Пример в цикле:**

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

**Коротко:**

`break` = «немедленно выйти отсюда».

---

## 11. Тернарный оператор

**Определение:**

Тернарный оператор — короткая форма условия, которая возвращает одно из двух значений.

**Синтаксис:**

```java
условие ? значение_если_true : значение_если_false
```

**Пример:**

```java
int age = 18;

String result = age >= 18 ? "Взрослый" : "Несовершеннолетний";

System.out.println(result);
```

**Коротко:**

Тернарный оператор — это компактный `if-else` для выбора значения.

**Важно:**

Его лучше использовать только для простых условий.
Если условие сложное — обычный `if` читается лучше.

---

## 12. Примитивные типы

**Определение:**

Примитивные типы — базовые типы данных, которые хранят простые значения.

**Примеры:**

```java
int age = 25;
double price = 99.9;
boolean isActive = true;
char letter = 'A';
```

**Коротко:**

Примитив хранит само значение.

---

## 13. Ссылочные типы

**Определение:**

Ссылочные типы — типы данных, которые хранят ссылку на объект в памяти.

**Пример:**

```java
String name = "Danil";
```

**Коротко:**

Ссылочный тип хранит не само значение напрямую, а ссылку на объект.

---

## 14. Оператор `==`

**Определение:**

`==` — оператор сравнения.

Для примитивных типов он сравнивает значения.

**Пример:**

```java
int a = 10;
int b = 10;

if (a == b) {
    System.out.println("Значения равны");
}
```

**Важно:**

Для строк и других объектов `==` обычно использовать не нужно, потому что он сравнивает ссылки, а не содержимое объектов.

---

## 15. Метод `equals()`

**Определение:**

`equals()` — метод, который используется для сравнения содержимого объектов.

**Пример:**

```java
String mode = "eco";

if (mode.equals("eco")) {
    System.out.println("Выбран экономичный режим");
}
```

**Более безопасный вариант:**

```java
String mode = "eco";

if ("eco".equals(mode)) {
    System.out.println("Выбран экономичный режим");
}
```

**Почему так лучше:**

Если `mode` окажется `null`, код `"eco".equals(mode)` не упадёт с ошибкой.

---

## 16. Логические операторы

**Определение:**

Логические операторы используются для создания сложных условий.

**Основные операторы:**

```java
&&  // логическое И
||  // логическое ИЛИ
```

**Пример:**

```java
int age = 20;

if (age >= 18 && age <= 65) {
    System.out.println("Возраст подходит");
}
```

---

## 17. Конъюнкция `&&`

**Определение:**

Конъюнкция — логическая операция «И».

В Java обозначается оператором `&&`.

Условие с `&&` истинно только тогда, когда обе части истинны.

**Пример:**

```java
int x = 3;

if (x >= 2 && x <= 5) {
    System.out.println("x находится в диапазоне от 2 до 5");
}
```

**Коротко:**

`&&` = должны выполниться все условия.

---

## 18. Дизъюнкция `||`

**Определение:**

Дизъюнкция — логическая операция «ИЛИ».

В Java обозначается оператором `||`.

Условие с `||` истинно, если хотя бы одна часть условия истинна.

**Пример:**

```java
int x = -10;

if (x >= 2 || x <= -5) {
    System.out.println("x подходит хотя бы под одно условие");
}
```

**Коротко:**

`||` = достаточно выполнения хотя бы одного условия.

---

## 19. Таблица истинности

**Определение:**

Таблица истинности показывает все возможные результаты логических операций.

**Пример для `&&`:**

```text
true  && true  = true
true  && false = false
false && true  = false
false && false = false
```

**Пример для `||`:**

```text
true  || true  = true
true  || false = true
false || true  = true
false || false = false
```

**Коротко:**

Таблица истинности помогает понять, как работают сложные условия.

---

## 20. Цикл

**Определение:**

Цикл — конструкция языка, которая позволяет выполнять один и тот же код несколько раз.

**Пример:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println("Привет");
}
```

**Коротко:**

Цикл = повторение кода.

---

## 21. Итерация

**Определение:**

Итерация — одно выполнение тела цикла.

**Пример:**

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

В этом примере будет 3 итерации.

**Коротко:**

Итерация = один круг цикла.

---

## 22. `while`

**Определение:**

`while` — цикл, который выполняется, пока условие истинно.

**Пример:**

```java
int temperature = 27;

while (temperature < 100) {
    temperature++;
    System.out.println("Температура: " + temperature);
}
```

**Коротко:**

`while` = «пока условие верное — повторяй».

---

## 23. Цикл с предусловием

**Определение:**

Цикл с предусловием — цикл, который сначала проверяет условие, а потом выполняет тело цикла.

**Пример:**

```java
int count = 0;

while (count < 3) {
    System.out.println(count);
    count++;
}
```

**Коротко:**

Сначала проверка, потом выполнение.

**Пример из жизни:**

Пока чайник не вскипел — грей.
Но сначала проверь: может, он уже вскипел.

---

## 24. `do while`

**Определение:**

`do while` — цикл, который сначала выполняет тело цикла, а потом проверяет условие.

**Пример:**

```java
int count = 0;

do {
    System.out.println(count);
    count++;
} while (count < 3);
```

**Коротко:**

`do while` выполнится минимум один раз.

---

## 25. Цикл с постусловием

**Определение:**

Цикл с постусловием — цикл, который проверяет условие после выполнения тела цикла.

**Пример:**

```java
int pasta = 0;
int potSize = 1000;

do {
    pasta += 100;
    System.out.println("Макарон в кастрюле: " + pasta);
} while (pasta < potSize);
```

**Коротко:**

Сначала действие, потом проверка.

---

## 26. `for`

**Определение:**

`for` — цикл со счётчиком, который удобно использовать, когда заранее известно количество повторений.

**Пример:**

```java
for (int i = 0; i < 10; i++) {
    System.out.println("Итерация: " + i);
}
```

**Коротко:**

`for` = цикл, когда известно, сколько раз повторять.

---

## 27. Счётчик цикла

**Определение:**

Счётчик цикла — переменная, которая управляет количеством повторений цикла.

**Пример:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

Здесь `i` — счётчик цикла.

**Коротко:**

Счётчик показывает, на каком повторении находится цикл.

---

## 28. Инкремент `++`

**Определение:**

Инкремент `++` увеличивает значение переменной на 1.

**Пример:**

```java
int count = 0;

count++;

System.out.println(count); // 1
```

**В цикле:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

**Коротко:**

`i++` = увеличить `i` на 1 после текущей операции.

---

## 29. `foreach`

**Определение:**

`foreach` — разновидность цикла `for`, которая используется для перебора элементов массива или коллекции.

**Пример:**

```java
char[] letters = {'Б', 'о', 'р', 'щ'};

for (char letter : letters) {
    System.out.print(letter);
}
```

**Коротко:**

`foreach` = пройтись по каждому элементу.

---

## 30. Массив

**Определение:**

Массив — структура данных, которая хранит несколько значений одного типа.

**Пример:**

```java
String[] vegetables = {"картошка", "морковь", "лук"};
```

**Коротко:**

Массив = набор значений под одним именем.

---

## 31. `continue`

**Определение:**

`continue` — оператор, который пропускает текущую итерацию цикла и переходит к следующей.

**Пример:**

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 != 0) {
        continue;
    }

    System.out.println(i);
}
```

**Коротко:**

`continue` = «эту итерацию пропускаем, идём дальше».

---

## 32. Остаток от деления `%`

**Определение:**

`%` — оператор, который возвращает остаток от деления.

**Пример:**

```java
int result = 10 % 3;

System.out.println(result); // 1
```

**Пример проверки чётности:**

```java
int number = 8;

if (number % 2 == 0) {
    System.out.println("Число чётное");
}
```

**Коротко:**

`%` часто используют, чтобы проверить чётность или кратность числа.

---

## 33. Бесконечный цикл

**Определение:**

Бесконечный цикл — цикл, который сам по себе никогда не завершится, потому что его условие всегда истинно.

**Пример:**

```java
while (true) {
    System.out.println("Введите значение");
}
```

**Важно:**

Бесконечный цикл должен иметь условие выхода, иначе программа может зависнуть.

---

## 34. Условие выхода из цикла

**Определение:**

Условие выхода — проверка, при которой цикл должен завершиться.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);

while (true) {
    System.out.println("Введите значение:");
    String value = scanner.nextLine();

    if ("end".equals(value)) {
        break;
    }
}
```

**Коротко:**

Условие выхода отвечает на вопрос:
«Когда цикл должен остановиться?»

---

## 35. `Scanner`

**Определение:**

`Scanner` — класс Java, который позволяет считывать данные, например из консоли.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);

String value = scanner.nextLine();

System.out.println(value);
```

**Важно:**

Чтобы использовать `Scanner`, нужно импортировать его:

```java
import java.util.Scanner;
```

---

## 36. `System.in`

**Определение:**

`System.in` — стандартный поток ввода, обычно связанный с вводом данных из консоли.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);
```

**Коротко:**

`System.in` = ввод с клавиатуры.

---

## 37. `nextLine()`

**Определение:**

`nextLine()` — метод класса `Scanner`, который считывает строку целиком до нажатия Enter.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);

String name = scanner.nextLine();

System.out.println("Привет, " + name);
```

**Коротко:**

`nextLine()` читает строку из консоли.
