# Тема 3: Условные операторы и циклы

---

## 1. Условный оператор

**Определение:**

Условный оператор — это конструкция языка, которая позволяет выполнять разный код в зависимости от результата проверки условия.

**Пример:**

```java
int age = 18;

if (age >= 18) {
    System.out.println("Доступ разрешён");
}
```

---

## 2. Ветвление

**Определение:**

Ветвление — это ситуация, когда программа может выполнять разные действия в зависимости от условия.

**Пример:**

```java
int temperature = 100;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else {
    System.out.println("Чайник ещё греется");
}
```

**Важно:**

Ветвление делает программу не просто последовательной, а вариативной: программа может выбирать разные сценарии выполнения.

---

## 3. `if`

**Определение:**

`if` — условный оператор, который выполняет блок кода, если условие истинно.

**Пример:**

```java
int temperature = 100;

if (temperature == 100) {
    System.out.println("Выключить чайник");
}
```

**Важно:**

Код внутри блока `if` выполнится только тогда, когда условие вернёт `true`.

---

## 4. `else`

**Определение:**

`else` — блок кода, который выполняется, если условие в `if` оказалось ложным.

**Пример:**

```java
int temperature = 70;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else {
    System.out.println("Чайник ещё не вскипел");
}
```

---

## 5. `else if`

**Определение:**

`else if` используется, когда нужно проверить несколько условий подряд.

**Пример:**

```java
int temperature = 85;

if (temperature == 100) {
    System.out.println("Чайник вскипел");
} else if (temperature == 85) {
    System.out.println("Осталось 20 секунд");
} else if (temperature == 60) {
    System.out.println("Включить дополнительный нагрев");
} else {
    System.out.println("Продолжить нагрев");
}
```

**Важно:**

Java проверяет условия сверху вниз. Как только одно условие оказалось истинным, остальные блоки `else if` уже не проверяются.

---

## 6. Блок кода

**Определение:**

Блок кода — это группа инструкций, заключённая в фигурные скобки `{}`.

**Пример:**

```java
if (age >= 18) {
    System.out.println("Можно войти");
    System.out.println("Добро пожаловать");
}
```

**Важно:**

В Java лучше всегда использовать `{}` даже для одной инструкции. Так код проще читать и безопаснее изменять.

---

## 7. `switch`

**Определение:**

`switch` — условный оператор, который сравнивает значение переменной с несколькими вариантами `case`.

**Пример:**

```java
int temperature = 0;

switch (temperature) {
    case 0:
        System.out.println("Включить компрессор");
        break;
    case -20:
        System.out.println("Отключить компрессор");
        break;
    default:
        System.out.println("Оставить текущий режим");
}
```

**Важно:**

`switch` удобно использовать, когда есть одна переменная и несколько конкретных вариантов её значения.

---

## 8. `case`

**Определение:**

`case` — вариант значения внутри оператора `switch`.

**Пример:**

```java
int day = 1;

switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
}
```

---

## 9. `default`

**Определение:**

`default` — блок внутри `switch`, который выполняется, если ни один `case` не подошёл.

**Пример:**

```java
int day = 10;

switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    default:
        System.out.println("Неизвестный день");
}
```

**Важно:**

`default` в `switch` выполняет похожую роль на `else` в конструкции `if-else`.

---

## 10. `break`

**Определение:**

`break` — оператор, который прерывает выполнение `switch` или цикла.

**Пример в `switch`:**

```java
int command = 1;

switch (command) {
    case 1:
        System.out.println("Старт");
        break;
    case 2:
        System.out.println("Стоп");
        break;
}
```

**Пример в цикле:**

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

**Важно:**

Если не написать `break` внутри старого варианта `switch`, выполнение может перейти в следующий `case`.

---

## 11. Тернарный оператор

**Определение:**

Тернарный оператор — это короткая форма условия, которая возвращает одно из двух значений.

**Синтаксис:**

```java
условие ? значение_если_true : значение_если_false
```

**Пример:**

```java
int age = 18;

String result = age >= 18 ? "Взрослый" : "Несовершеннолетний";

System.out.println(result);
```

**Важно:**

Тернарный оператор лучше использовать только для простых условий. Если условие сложное, обычный `if-else` читается лучше.

---

## 12. Условие

**Определение:**

Условие — это выражение, результатом которого является `true` или `false`.

**Пример:**

```java
int age = 20;

if (age >= 18) {
    System.out.println("Совершеннолетний");
}
```

В этом примере условие:

```java
age >= 18
```

---

## 13. `true`

**Определение:**

`true` — логическое значение, которое означает истину.

**Пример:**

```java
boolean isAdult = true;
```

---

## 14. `false`

**Определение:**

`false` — логическое значение, которое означает ложь.

**Пример:**

```java
boolean isAdult = false;
```

---

## 15. Оператор сравнения `==`

**Определение:**

`==` — оператор сравнения, который проверяет равенство двух значений.

**Пример с примитивами:**

```java
int a = 10;
int b = 10;

if (a == b) {
    System.out.println("Значения равны");
}
```

**Важно:**

Для примитивных типов `==` сравнивает значения.
Для ссылочных типов `==` сравнивает ссылки, поэтому строки обычно сравнивают через `equals()`.

---

## 16. Примитивные типы

**Определение:**

Примитивные типы — это базовые типы данных Java, которые хранят простые значения.

**Пример:**

```java
int age = 25;
double price = 99.99;
boolean isActive = true;
char letter = 'A';
```

---

## 17. Ссылочные типы

**Определение:**

Ссылочные типы — это типы данных, переменные которых хранят ссылку на объект в памяти.

**Пример:**

```java
String name = "Danil";
```

**Важно:**

`String` — ссылочный тип, поэтому строки сравнивают через метод `equals()`.

---

## 18. Метод `equals()`

**Определение:**

`equals()` — метод, который используется для сравнения содержимого объектов.

**Пример:**

```java
String mode = "eco";

if (mode.equals("eco")) {
    System.out.println("Выбран экономичный режим");
}
```

**Более безопасный вариант:**

```java
String mode = "eco";

if ("eco".equals(mode)) {
    System.out.println("Выбран экономичный режим");
}
```

**Важно:**

Вариант `"eco".equals(mode)` безопаснее, потому что не вызовет ошибку, если переменная `mode` окажется `null`.

---

## 19. Логические операторы

**Определение:**

Логические операторы используются для создания сложных условий.

**Основные логические операторы:**

```java
&&  // логическое И
||  // логическое ИЛИ
```

**Пример:**

```java
int age = 20;

if (age >= 18 && age <= 65) {
    System.out.println("Возраст подходит");
}
```

---

## 20. Конъюнкция `&&`

**Определение:**

Конъюнкция — логическая операция «И». В Java она записывается оператором `&&`.

Условие с `&&` истинно только тогда, когда обе части условия истинны.

**Пример:**

```java
int x = 3;

if (x >= 2 && x <= 5) {
    System.out.println("x находится в диапазоне от 2 до 5");
}
```

---

## 21. Дизъюнкция `||`

**Определение:**

Дизъюнкция — логическая операция «ИЛИ». В Java она записывается оператором `||`.

Условие с `||` истинно, если хотя бы одна часть условия истинна.

**Пример:**

```java
int x = -10;

if (x >= 2 || x <= -5) {
    System.out.println("x подходит хотя бы под одно условие");
}
```

---

## 22. Таблица истинности

**Определение:**

Таблица истинности показывает все возможные результаты логических операций.

**Пример для `&&`:**

```text
true  && true  = true
true  && false = false
false && true  = false
false && false = false
```

**Пример для `||`:**

```text
true  || true  = true
true  || false = true
false || true  = true
false || false = false
```

---

## 23. Цикл

**Определение:**

Цикл — это конструкция языка, которая позволяет выполнять один и тот же код несколько раз.

**Пример:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println("Привет");
}
```

---

## 24. Итерация

**Определение:**

Итерация — это одно выполнение тела цикла.

**Пример:**

```java
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
```

В этом примере будет 3 итерации.

---

## 25. `while`

**Определение:**

`while` — цикл, который выполняется, пока условие истинно.

**Пример:**

```java
int temperature = 27;

while (temperature < 100) {
    temperature++;
    System.out.println("Температура: " + temperature);
}
```

**Важно:**

`while` сначала проверяет условие, а потом выполняет тело цикла. Поэтому тело цикла может не выполниться ни разу.

---

## 26. Цикл с предусловием

**Определение:**

Цикл с предусловием — это цикл, который сначала проверяет условие, а затем выполняет тело цикла.

**Пример:**

```java
int count = 0;

while (count < 3) {
    System.out.println(count);
    count++;
}
```

---

## 27. `do while`

**Определение:**

`do while` — цикл, который сначала выполняет тело цикла, а потом проверяет условие.

**Пример:**

```java
int count = 0;

do {
    System.out.println(count);
    count++;
} while (count < 3);
```

**Важно:**

`do while` выполнится минимум один раз, даже если условие изначально ложное.

---

## 28. Цикл с постусловием

**Определение:**

Цикл с постусловием — это цикл, который проверяет условие после выполнения тела цикла.

**Пример:**

```java
int pasta = 0;
int potSize = 1000;

do {
    pasta += 100;
    System.out.println("Макарон в кастрюле: " + pasta);
} while (pasta < potSize);
```

---

## 29. `for`

**Определение:**

`for` — цикл со счётчиком, который удобно использовать, когда заранее известно количество повторений.

**Пример:**

```java
for (int i = 0; i < 10; i++) {
    System.out.println("Итерация: " + i);
}
```

**Структура цикла:**

```java
for (начальное_значение; условие; изменение_счётчика) {
    // тело цикла
}
```

---

## 30. Счётчик цикла

**Определение:**

Счётчик цикла — это переменная, которая управляет количеством повторений цикла.

**Пример:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

В этом примере `i` — счётчик цикла.

---

## 31. Инкремент `++`

**Определение:**

Инкремент `++` — это операция увеличения значения переменной на 1.

**Пример:**

```java
int count = 0;

count++;

System.out.println(count); // 1
```

**Пример в цикле:**

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

---

## 32. `foreach`

**Определение:**

`foreach` — разновидность цикла `for`, которая используется для перебора элементов массива или коллекции.

**Пример:**

```java
char[] letters = {'Б', 'о', 'р', 'щ'};

for (char letter : letters) {
    System.out.print(letter);
}
```

**Важно:**

`foreach` улучшает читаемость кода, когда нужно просто пройти по всем элементам и не нужен индекс.

---

## 33. Массив

**Определение:**

Массив — структура данных, которая хранит несколько значений одного типа.

**Пример:**

```java
String[] vegetables = {"картошка", "морковь", "лук"};
```

---

## 34. Коллекция

**Определение:**

Коллекция — объект, который хранит группу элементов и предоставляет методы для работы с ними.

**Пример:**

```java
ArrayList<String> names = new ArrayList<>();

names.add("Danil");
names.add("Ivan");
```

---

## 35. `continue`

**Определение:**

`continue` — оператор, который пропускает текущую итерацию цикла и переходит к следующей.

**Пример:**

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 != 0) {
        continue;
    }

    System.out.println(i);
}
```

**Важно:**

`continue` не завершает весь цикл. Он завершает только текущую итерацию.

---

## 36. Остаток от деления `%`

**Определение:**

`%` — оператор, который возвращает остаток от деления.

**Пример:**

```java
int result = 10 % 3;

System.out.println(result); // 1
```

**Пример проверки чётности:**

```java
int number = 8;

if (number % 2 == 0) {
    System.out.println("Число чётное");
}
```

---

## 37. Бесконечный цикл

**Определение:**

Бесконечный цикл — это цикл, который сам по себе никогда не завершится, потому что его условие всегда истинно.

**Пример:**

```java
while (true) {
    System.out.println("Введите значение");
}
```

**Важно:**

Бесконечный цикл должен иметь условие выхода, иначе программа может зависнуть.

---

## 38. Условие выхода из цикла

**Определение:**

Условие выхода — это проверка, при которой цикл должен завершиться.

**Пример:**

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.println("Введите значение:");
            String value = scanner.nextLine();

            if ("end".equals(value)) {
                break;
            }
        }
    }
}
```

**Важно:**

В бесконечных циклах условие выхода обычно пишут через `if` и `break`.

---

## 39. `Scanner`

**Определение:**

`Scanner` — класс Java, который позволяет считывать данные, например из консоли.

**Пример:**

```java
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);

String value = scanner.nextLine();

System.out.println(value);
```

**Важно:**

Чтобы использовать `Scanner`, его нужно импортировать:

```java
import java.util.Scanner;
```

---

## 40. `System.in`

**Определение:**

`System.in` — стандартный поток ввода, который обычно связан с вводом данных из консоли.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);
```

---

## 41. `nextLine()`

**Определение:**

`nextLine()` — метод класса `Scanner`, который считывает строку целиком до нажатия Enter.

**Пример:**

```java
Scanner scanner = new Scanner(System.in);

String name = scanner.nextLine();

System.out.println("Привет, " + name);
```
