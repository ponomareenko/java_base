# Тема 4: Типы данных Java. Примитивы

---

## 1. Тип данных

**Определение:**

Тип данных — это характеристика переменной, которая определяет, какие значения она может хранить и какие операции с этими значениями можно выполнять.

**Пример:**

```java
int age = 25;
double price = 99.99;
boolean isActive = true;
```

---

## 2. Примитивные типы данных

**Определение:**

Примитивные типы данных — это базовые типы Java, которые хранят простые значения: числа, символы и логические значения.

**Пример:**

```java
int count = 10;
double price = 99.99;
char letter = 'A';
boolean isValid = true;
```

**Важно:**

Примитивная переменная хранит само значение, а не ссылку на объект.

---

## 3. Целочисленные типы данных

**Определение:**

Целочисленные типы данных используются для хранения целых чисел без дробной части.

**Основные типы:**

```java
byte
short
int
long
```

**Пример:**

```java
byte smallNumber = 10;
short year = 2026;
int count = 1000;
long population = 8_000_000_000L;
```

---

## 4. `byte`

**Определение:**

`byte` — целочисленный примитивный тип данных размером 8 бит.

**Диапазон значений:**

```text
от -128 до 127
```

**Пример:**

```java
byte value = 100;
```

**Важно:**

`byte` используется редко. Обычно для целых чисел выбирают `int`, если нет причины экономить память или работать с бинарными данными.

---

## 5. `short`

**Определение:**

`short` — целочисленный примитивный тип данных размером 16 бит.

**Диапазон значений:**

```text
от -32_768 до 32_767
```

**Пример:**

```java
short temperature = 250;
```

**Важно:**

`short`, как и `byte`, используется реже, чем `int`.

---

## 6. `int`

**Определение:**

`int` — основной целочисленный тип данных в Java.

**Размер:**

```text
32 бита
```

**Диапазон значений:**

```text
от -2_147_483_648 до 2_147_483_647
```

**Пример:**

```java
int age = 25;
int count = 1_000_000;
```

**Важно:**

По умолчанию целые числовые значения без специальных суффиксов Java воспринимает как `int`.

---

## 7. `long`

**Определение:**

`long` — целочисленный тип данных для хранения больших целых чисел.

**Размер:**

```text
64 бита
```

**Диапазон значений:**

```text
от -9_223_372_036_854_775_808 до 9_223_372_036_854_775_807
```

**Пример:**

```java
long population = 8_000_000_000L;
```

**Важно:**

Для литералов типа `long` обычно добавляют суффикс `L`.

```java
long value = 3_000_000_000L;
```

Без `L` Java сначала попытается воспринять число как `int`.

---

## 8. Бит

**Определение:**

Бит — минимальная единица информации в компьютере. Он может хранить только одно из двух значений: `0` или `1`.

**Пример:**

```text
0
1
```

---

## 9. Размер типа данных

**Определение:**

Размер типа данных показывает, сколько памяти занимает значение этого типа.

**Пример:**

```text
byte  — 8 бит
short — 16 бит
int   — 32 бита
long  — 64 бита
```

**Важно:**

Чем больше размер типа, тем больший диапазон значений он может хранить.

---

## 10. Диапазон значений

**Определение:**

Диапазон значений — это минимальное и максимальное значение, которое может хранить конкретный тип данных.

**Пример:**

```java
int maxInt = 2_147_483_647;
int minInt = -2_147_483_648;
```

---

## 11. Двоичное представление числа

**Определение:**

Двоичное представление числа — это способ записи числа с помощью нулей и единиц.

**Пример:**

```text
2 в двоичном виде: 00000010
```

**Важно:**

Компьютер хранит числа не в привычной десятичной форме, а в виде набора битов.

---

## 12. Дополнительный код

**Определение:**

Дополнительный код — это способ представления отрицательных целых чисел в памяти компьютера.

**Пример:**

```text
2  -> 00000010
-2 -> 11111110
```

**Важно:**

Дополнительный код используется в вычислительной технике, чтобы удобно выполнять операции с отрицательными числами.

---

## 13. Подчёркивание в числах `_`

**Определение:**

Подчёркивание `_` можно использовать внутри числовых литералов для визуального разделения разрядов.

**Пример:**

```java
int number = 1_234_000;
long money = 1_000_000L;
```

**Важно:**

Подчёркивание не меняет значение числа.

```java
int a = 1000000;
int b = 1_000_000;
```

Значения `a` и `b` одинаковые.

---

## 14. Числовой литерал

**Определение:**

Числовой литерал — это число, написанное прямо в коде.

**Пример:**

```java
int age = 18;
long population = 8_000_000_000L;
double price = 99.99;
```

В этом примере `18`, `8_000_000_000L` и `99.99` — числовые литералы.

---

## 15. Литерал `L`

**Определение:**

`L` — суффикс числового литерала, который указывает Java, что число нужно воспринимать как значение типа `long`.

**Пример:**

```java
long value = 3_000_000_000L;
```

**Важно:**

Лучше использовать большую букву `L`, а не маленькую `l`, потому что маленькую `l` легко перепутать с цифрой `1`.

---

## 16. Приведение типов

**Определение:**

Приведение типов — это преобразование значения из одного типа данных в другой.

**Пример:**

```java
int value = 10;
long result = value;
```

**Важно:**

Приведение бывает автоматическим и явным.

---

## 17. Автоматическое приведение типов

**Определение:**

Автоматическое приведение типов происходит, когда Java сама преобразует значение меньшего типа в больший тип.

**Пример:**

```java
int value = 10;
long result = value;
```

**Важно:**

Такое преобразование безопасно, потому что значение из `int` помещается в `long`.

---

## 18. Явное приведение типов

**Определение:**

Явное приведение типов — это преобразование, которое разработчик указывает вручную с помощью записи типа в скобках.

**Пример:**

```java
long bigValue = 10L;
int value = (int) bigValue;
```

**Важно:**

Явное приведение может привести к потере данных, если значение не помещается в новый тип.

---

## 19. Потеря данных при приведении типов

**Определение:**

Потеря данных при приведении типов возникает, когда значение большего типа преобразуют к меньшему типу, и оно не помещается в допустимый диапазон нового типа.

**Пример:**

```java
long bigValue = 10_000_000_000L;
int value = (int) bigValue;

System.out.println(value);
```

**Важно:**

Java не всегда предупреждает о такой ошибке во время выполнения. В результате можно получить некорректное число.

---

## 20. Переполнение типа

**Определение:**

Переполнение типа — это ситуация, когда значение выходит за пределы допустимого диапазона типа данных.

**Пример:**

```java
int number = 2_147_483_647;

number++;

System.out.println(number);
```

**Результат:**

```text
-2147483648
```

**Важно:**

При переполнении `int` значение не становится больше максимума, а переходит к минимальному значению диапазона.

---

## 21. Арифметические операции

**Определение:**

Арифметические операции — это операции над числами.

**Основные операции:**

```java
+  // сложение
-  // вычитание
*  // умножение
/  // деление
%  // остаток от деления
```

**Пример:**

```java
int a = 10;
int b = 3;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);
System.out.println(a % b);
```

---

## 22. Оператор `%`

**Определение:**

`%` — арифметический оператор, который возвращает остаток от деления.

**Пример:**

```java
int result = 10 % 3;

System.out.println(result); // 1
```

**Пример проверки чётности:**

```java
int number = 8;

if (number % 2 == 0) {
    System.out.println("Число чётное");
}
```

---

## 23. Сложение `byte`

**Определение:**

При арифметических операциях значения типов меньше `int` автоматически вычисляются как `int`.

**Пример ошибки:**

```java
byte value1 = 120;
byte value2 = 3;

// byte result = value1 + value2; // ошибка компиляции
```

**Правильный вариант:**

```java
byte value1 = 120;
byte value2 = 3;

int result = value1 + value2;
```

**Важно:**

`byte + byte` даёт результат типа `int`, а не `byte`.

---

## 24. Вещественные типы данных

**Определение:**

Вещественные типы данных используются для хранения чисел с дробной частью.

**Основные типы:**

```java
float
double
```

**Пример:**

```java
float temperature = 36.6F;
double price = 99.99;
```

---

## 25. `float`

**Определение:**

`float` — вещественный тип данных одинарной точности.

**Размер:**

```text
32 бита
```

**Пример:**

```java
float temperature = 36.6F;
```

**Важно:**

Для литералов типа `float` обычно добавляют суффикс `F`.

---

## 26. `double`

**Определение:**

`double` — основной вещественный тип данных в Java для хранения дробных чисел.

**Размер:**

```text
64 бита
```

**Пример:**

```java
double price = 99.99;
double weight = 72.5;
```

**Важно:**

Дробные литералы без суффикса по умолчанию считаются типом `double`.

---

## 27. Погрешность `double`

**Определение:**

Погрешность `double` — это небольшая неточность, которая может возникать при хранении и вычислении дробных чисел.

**Пример:**

```java
double d1 = 0.3 + 0.3 + 0.3;
double d2 = 0.9;

System.out.println(d1 == d2); // false
System.out.println(d1);       // 0.8999999999999999
System.out.println(d2);       // 0.9
```

**Важно:**

Не все дробные числа можно точно представить в двоичной системе, поэтому вычисления с `double` могут давать небольшую погрешность.

---

## 28. Сравнение `double`

**Определение:**

Сравнение `double` — это проверка равенства дробных чисел с учётом допустимой погрешности.

**Плохой пример:**

```java
double d1 = 0.3 + 0.3 + 0.3;
double d2 = 0.9;

System.out.println(d1 == d2); // false
```

**Правильный пример:**

```java
double d1 = 0.3 + 0.3 + 0.3;
double d2 = 0.9;

if (Math.abs(d1 - d2) < 0.000001) {
    System.out.println("Числа равны");
} else {
    System.out.println("Числа не равны");
}
```

**Важно:**

Дробные числа типа `double` обычно не сравнивают напрямую через `==`.

---

## 29. Погрешность сравнения

**Определение:**

Погрешность сравнения — это допустимая разница между двумя дробными числами, при которой они считаются равными.

**Пример:**

```java
double a = 0.8999999999999999;
double b = 0.9;

double epsilon = 0.000001;

if (Math.abs(a - b) < epsilon) {
    System.out.println("Числа равны");
}
```

**Важно:**

Значение погрешности выбирают исходя из задачи.

---

## 30. `Math.abs()`

**Определение:**

`Math.abs()` — метод, который возвращает модуль числа, то есть значение без знака.

**Пример:**

```java
System.out.println(Math.abs(-10)); // 10
```

**Пример при сравнении `double`:**

```java
double a = 0.8999999999999999;
double b = 0.9;

if (Math.abs(a - b) < 0.000001) {
    System.out.println("Числа равны");
}
```

---

## 31. `System.out.format()`

**Определение:**

`System.out.format()` — метод для форматированного вывода данных в консоль.

**Пример:**

```java
System.out.format("%.2f", 0.257674);
```

**Результат:**

```text
0.26
```

**Важно:**

`format()` позволяет управлять внешним видом вывода, например количеством знаков после запятой.

---

## 32. Форматирование дробных чисел

**Определение:**

Форматирование дробных чисел — это настройка вывода дробного числа, например количества знаков после запятой.

**Пример:**

```java
System.out.format("%.2f", 0.257674);
System.out.format("%.4f", 0.257674);
```

**Пример результата:**

```text
0.26
0.2577
```

**Важно:**

Форматирование меняет способ отображения числа, но не обязательно меняет само значение, которое хранится в переменной.

---

## 33. `Infinity`

**Определение:**

`Infinity` — специальное значение типа `double`, которое обозначает бесконечность.

**Пример:**

```java
double x = 5;
double y = 0;

System.out.println(x / y); // Infinity
```

**Важно:**

При делении вещественного числа на ноль Java может вернуть `Infinity`.
При делении целого числа на ноль будет ошибка выполнения.

---

## 34. `NaN`

**Определение:**

`NaN` означает `Not a Number`, то есть «не число».

**Пример:**

```java
double x = 5;
double y = 0;

double d1 = 5 / y;
double d2 = 4 / y;

System.out.println(d1 - d2); // NaN
```

**Важно:**

`NaN` появляется, когда результат вычисления невозможно представить как обычное число.

---

## 35. `char`

**Определение:**

`char` — примитивный тип данных для хранения одного символа.

**Размер:**

```text
16 бит
```

**Пример:**

```java
char letter = 'A';
char symbol = 'Ж';
```

**Важно:**

Значение типа `char` записывается в одинарных кавычках.

```java
char letter = 'A';
```

---

## 36. Unicode

**Определение:**

Unicode — стандарт кодирования символов, который позволяет представлять символы разных языков и специальные знаки.

**Пример:**

```java
char letter = 'Я';
char symbol = '€';
```

**Важно:**

В Java `char` хранит один Unicode-символ размером 16 бит.

---

## 37. `boolean`

**Определение:**

`boolean` — примитивный тип данных, который хранит только два значения: `true` или `false`.

**Пример:**

```java
boolean isAdult = true;
boolean hasAccess = false;
```

**Важно:**

`boolean` часто используется в условиях, флагах и результатах проверок.

---

## 38. `true`

**Определение:**

`true` — логическое значение, которое означает истину.

**Пример:**

```java
boolean isActive = true;
```

---

## 39. `false`

**Определение:**

`false` — логическое значение, которое означает ложь.

**Пример:**

```java
boolean isActive = false;
```
