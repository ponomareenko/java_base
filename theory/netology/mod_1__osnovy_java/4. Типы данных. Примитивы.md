# Словарь Java — Тема 4. Типы данных. Примитивы

# База

## 1. Тип данных (Data Type)

**Определение:**
Правило, которое определяет:

* какие значения можно хранить;
* сколько памяти займёт переменная;
* какие операции над ней доступны.

**Простыми словами:**
Тип данных — это инструкция для Java: «что лежит внутри коробки».

Пример:

```java
int age = 25;
```

---

## 2. Примитивный тип (Primitive Type)

**Определение:**
Встроенный тип Java, который хранит само значение напрямую.

В Java 8 примитивов:

```text
byte
short
int
long
float
double
char
boolean
```

**Важно запомнить:**
Примитив ≠ объект.

---

# Целочисленные типы

## 3. Целочисленный тип (Integer Type)

**Определение:**
Тип данных для хранения целых чисел без дробной части. 

---

## 4. `byte`

**Определение:**
Самый маленький целочисленный тип.

Размер:

```text
8 бит = 1 байт
```

Диапазон:

```text
от -128 до 127
```

Пример:

```java
byte age = 100;
```

---

## 5. `short`

**Определение:**
Маленький целочисленный тип.

Размер:

```text
16 бит
```

Диапазон:

```text
-32 768 … 32 767
```

---

## 6. `int`

**Определение:**
Основной целочисленный тип в Java.

Размер:

```text
32 бита
```

Диапазон:

```text
−2^31 … 2^31−1
```

Пример:

```java
int salary = 100000;
```

**Продакшен:**
90% целых чисел → `int`.

---

## 7. `long`

**Определение:**
Тип для очень больших целых чисел.

Размер:

```text
64 бита
```

Пример:

```java
long population = 8_000_000_000L;
```

---

## 8. Литерал (Literal)

**Определение:**
Значение, записанное прямо в коде.

Примеры:

```java
10
15.5
true
'A'
```

---

## 9. Литерал `L`

**Определение:**
Суффикс, который говорит Java считать число типом `long`. 

Пример:

```java
long x = 5_000_000_000L;
```

Без `L`:

```java
long x = 5000000000;
```

❌ ошибка компиляции

---

## 10. Бит (Bit)

**Определение:**
Минимальная единица хранения данных.

Может содержать:

```text
0
или
1
```

---

## 11. Байт (Byte)

**Определение:**
Группа из 8 бит.

```text
1 byte = 8 bit
```

---

## 12. Дополнительный код (Two's Complement)

**Определение:**
Способ хранения отрицательных чисел в памяти компьютера. 

**Пока глубоко не копай.**
Достаточно помнить:

> отрицательные числа хранятся не как «минус перед числом», а специальным двоичным способом.

---

## 13. Переполнение (Overflow)

**Определение:**
Ситуация, когда число вышло за пределы диапазона типа.

Пример:

```java
int x = Integer.MAX_VALUE;

x++;

System.out.println(x);
```

Результат:

```text
-2147483648
```

Java не ругается.

---

## 14. Приведение типов (Type Casting)

**Определение:**
Преобразование одного типа в другой. 

---

## 15. Неявное приведение (Implicit Casting)

**Определение:**
Java сама расширяет тип.

```java
int a = 10;

long b = a;
```

---

## 16. Явное приведение (Explicit Casting)

**Определение:**
Разработчик явно указывает преобразование.

```java
long a = 10;

int b = (int) a;
```

---

# Операции

## 17. Арифметические операции

**Определение:**
Операции над числами.

```text
+
-
*
/
%
```

---

## 18. Продвижение типов (Type Promotion)

**Определение:**
Java автоматически приводит маленькие типы к более крупным при вычислениях. 

Пример:

```java
byte a = 10;
byte b = 20;

int c = a + b;
```

Результат:

```text
int
```

Не `byte`.

---

# Вещественные числа

## 19. Вещественный тип (Floating Point Type)

**Определение:**
Тип для хранения дробных чисел. 

---

## 20. `float`

**Определение:**
Тип для дробных чисел средней точности.

Размер:

```text
32 бита
```

Пример:

```java
float pi = 3.14F;
```

---

## 21. `double`

**Определение:**
Основной тип для дробных чисел.

Размер:

```text
64 бита
```

Пример:

```java
double price = 99.99;
```

---

## 22. Погрешность вычислений (Precision Error)

**Определение:**
Ошибка округления при работе с дробями. 

Пример:

```java
0.1 + 0.2
```

не всегда равно:

```java
0.3
```

---

## 23. Эпсилон (Epsilon)

**Определение:**
Допустимая погрешность при сравнении `double`.

Пример:

```java
Math.abs(a - b) < 0.000001
```

---

## 24. `Infinity`

**Определение:**
Специальное значение для бесконечности. 

Пример:

```java
double x = 5.0 / 0;
```

---

## 25. `NaN`

**Определение:**
Специальное значение:

```text
Not a Number
```

Получается при невозможных вычислениях. 

Пример:

```java
0.0 / 0.0
```

---

# Остальные примитивы

## 26. `char`

**Определение:**
Тип для хранения одного символа.

Пример:

```java
char letter = 'A';
```

---

## 27. `Unicode`

**Определение:**
Международная таблица символов.

Пример:

```java
'A'
'Ж'
'中'
```

---

## 28. `boolean`

**Определение:**
Логический тип.

Значения:

```text
true
false
```

---
