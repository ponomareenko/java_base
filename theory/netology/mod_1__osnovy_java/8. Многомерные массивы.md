# Словарь Java — Тема 8. Многомерные массивы

# Основа

## 1. Многомерный массив (Multidimensional Array)

**Определение:**
Массив, элементами которого являются другие массивы. 

Пример:

```java
int[][] matrix;
```

Простыми словами:

```text
массив из массивов
```

---

## 2. Двумерный массив (Two-Dimensional Array)

**Определение:**
Массив, для доступа к элементу которого нужны два индекса. 

Пример:

```java
table[1][2]
```

Первый индекс:

```text
строка
```

Второй:

```text
столбец
```

---

## 3. Размерность массива (Dimension)

**Определение:**
Количество индексов для доступа к элементу.

Примеры:

```java
int[] a;
```

одномерный

```java
int[][] b;
```

двумерный

```java
int[][][] c;
```

трёхмерный

---

## 4. Матрица (Matrix)

**Определение:**
Двумерный массив, у которого одинаковое количество строк и столбцов. 

Пример:

```text
1 2
3 4
```

Размер:

```text
2 × 2
```

---

# Создание

## 5. Объявление двумерного массива

**Определение:**
Создание ссылки на двумерный массив.

Пример:

```java
int[][] arr;
```

---

## 6. Инициализация двумерного массива

**Определение:**
Создание массива и выделение памяти. 

Пример:

```java
int[][] arr = new int[3][5];
```

Что получилось:

```text
3 строки
5 столбцов
```

---

## 7. Ступенчатый массив (Jagged Array)

**Определение:**
Двумерный массив, где строки имеют разную длину. Это очень важный термин, его нет явно в презентации, но это реальная терминология. 

Пример:

```java
int[][] arr = {
    {1},
    {2, 3},
    {4, 5, 6}
};
```

Размеры разные.

---

## 8. Вложенный массив (Nested Array)

**Определение:**
Внутренний массив внутри многомерного.

Пример:

```java
arr[0]
```

может вернуть:

```text
[1, 2, 3]
```

---

# Работа с элементами

## 9. Двойная индексация

**Определение:**
Обращение к элементу через два индекса. 

Пример:

```java
arr[1][3]
```

Читается:

```text
строка 1
столбец 3
```

---

## 10. Внутренний элемент

**Определение:**
Конкретное значение внутри вложенного массива.

Пример:

```java
arr[2][1]
```

---

## 11. Заполнение массива

**Определение:**
Присвоение значений ячейкам.

Пример:

```java
arr[1][3] = 15;
```

---

# Вывод массива

## 12. `Arrays.deepToString()`

**Определение:**
Метод вывода многомерного массива в читаемом виде. 

Пример:

```java
System.out.println(
    Arrays.deepToString(arr)
);
```

Результат:

```text
[[1, 2], [3, 4]]
```

---

## 13. `Arrays.toString()`

**Определение:**
Выводит только один уровень массива.

Пример:

```java
Arrays.toString(arr)
```

Для двумерного массива часто покажет мусор:

```text
[[I@2a84aee7
```

---

# Перебор многомерных массивов

## 14. Вложенный цикл (Nested Loop)

**Определение:**
Цикл внутри другого цикла.

Пример: 

```java
for (...) {

    for (...) {

    }

}
```

---

## 15. Внешний цикл (Outer Loop)

**Определение:**
Цикл, который проходит по строкам.

Пример:

```java
for (int i = 0; i < arr.length; i++)
```

---

## 16. Внутренний цикл (Inner Loop)

**Определение:**
Цикл, который проходит по столбцам.

Пример:

```java
for (int j = 0; j < arr[i].length; j++)
```

---

## 17. Координаты элемента

**Определение:**
Пара индексов, определяющая положение элемента.

Пример:

```text
[2][4]
```

---

# Размеры

## 18. Количество строк

**Определение:**
Размер первой размерности.

Пример:

```java
arr.length
```

---

## 19. Количество столбцов

**Определение:**
Размер внутреннего массива.

Пример:

```java
arr[i].length
```

---

## 20. Трёхмерный массив

**Определение:**
Массив с тремя индексами. 

Пример:

```java
String[][][] products
    = new String[2][4][5];
```

---

# Очень полезное правило (добавляю сверх курса)

Запомни визуально:

```text
int[][] arr = {
    {1, 2, 3},
    {4, 5, 6}
};

индексы:

      0  1  2
0 → [1, 2, 3]
1 → [4, 5, 6]
```

Чтение:

```java
arr[1][2]
```

↓

```text
6
```
