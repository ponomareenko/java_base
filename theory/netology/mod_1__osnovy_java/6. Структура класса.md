# Тема 6: Структура класса

---

## 1. Парадигма программирования

**Определение:**

Парадигма программирования — это общий подход к построению программы: как организуется код, данные и взаимодействие между частями программы.

**Пример:**

```text
Императивное программирование
Функциональное программирование
Объектно-ориентированное программирование
```

**Важно:**

Java в первую очередь относится к объектно-ориентированным языкам программирования.

---

## 2. Императивное программирование

**Определение:**

Императивное программирование — это подход, при котором программа описывает последовательность действий шаг за шагом.

**Пример:**

```java
int x = 10;
x = x + 5;
System.out.println(x);
```

---

## 3. Функциональное программирование

**Определение:**

Функциональное программирование — это подход, при котором основное внимание уделяется функциям и результатам их выполнения.

**Пример:**

```java
List<Integer> numbers = List.of(1, 2, 3);

List<Integer> doubled = numbers.stream()
        .map(number -> number * 2)
        .toList();
```

**Важно:**

В Java есть элементы функционального программирования, например lambda-выражения и Stream API, но базово Java изучают через ООП.

---

## 4. Объектно-ориентированное программирование

**Определение:**

Объектно-ориентированное программирование, или ООП, — это подход, при котором программа строится вокруг объектов, их состояния и поведения.

**Пример:**

```java
Singer singer = new Singer("Petya", 8, 3);

singer.sing("Good morning");
```

**Важно:**

В ООП объект обычно имеет данные и действия.
Данные описываются полями, а действия — методами.

---

## 5. Класс

**Определение:**

Класс — это структура Java, с помощью которой описываются будущие объекты: их поля, методы и конструкторы.

**Пример:**

```java
class Record {

}
```

**Важно:**

Класс — это не сам объект, а описание того, каким объект должен быть.

---

## 6. Объект

**Определение:**

Объект — это конкретный экземпляр класса, созданный во время работы программы.

**Пример:**

```java
Singer singer = new Singer();
```

**Важно:**

Класс можно воспринимать как чертёж, а объект — как конкретную вещь, созданную по этому чертежу.

---

## 7. Экземпляр класса

**Определение:**

Экземпляр класса — это объект, созданный на основе конкретного класса.

**Пример:**

```java
Singer singer = new Singer();
```

В этом примере `singer` — ссылка на экземпляр класса `Singer`.

---

## 8. `class`

**Определение:**

`class` — ключевое слово Java, которое используется для объявления класса.

**Пример:**

```java
class Singer {

}
```

**Важно:**

После ключевого слова `class` указывается имя класса.

---

## 9. Имя класса

**Определение:**

Имя класса — это название, по которому класс используется в программе.

**Пример:**

```java
class Singer {

}
```

В этом примере имя класса — `Singer`.

**Важно:**

В Java имена классов принято писать с заглавной буквы в стиле `PascalCase`.

**Пример:**

```java
class MusicTrack {

}
```

---

## 10. Файл класса

**Определение:**

Файл класса — это файл с расширением `.java`, в котором находится код класса.

**Пример:**

```text
Singer.java
Record.java
MusicTrack.java
```

**Важно:**

Если класс объявлен как `public`, имя файла должно совпадать с именем класса.

**Пример:**

```java
public class Singer {

}
```

Такой класс должен находиться в файле:

```text
Singer.java
```

---

## 11. Тело класса

**Определение:**

Тело класса — это часть класса внутри фигурных скобок `{}`.

**Пример:**

```java
class Singer {
    String name;
    int age;
}
```

В этом примере тело класса содержит поля `name` и `age`.

---

## 12. Поле класса

**Определение:**

Поле класса — это переменная, объявленная внутри класса и описывающая состояние объекта или общее состояние класса.

**Пример:**

```java
public class Singer {
    public String name;
    public int age;
    public int rating;
}
```

**Важно:**

Поля описывают характеристики объекта.
Например, у певца могут быть имя, возраст и рейтинг.

---

## 13. Нестатическое поле

**Определение:**

Нестатическое поле — это поле, которое принадлежит конкретному объекту.

**Пример:**

```java
public class Singer {
    public String name;
    public int age;
}
```

**Использование:**

```java
Singer singer1 = new Singer();
singer1.name = "Petya";

Singer singer2 = new Singer();
singer2.name = "Anya";
```

**Важно:**

У каждого объекта своё значение нестатического поля.

---

## 14. Статическое поле

**Определение:**

Статическое поле — это поле, которое принадлежит классу, а не конкретному объекту.

**Пример:**

```java
public class Singer {
    public static int maxRating = 0;
}
```

**Использование:**

```java
Singer.maxRating = 5;
```

**Важно:**

Статическое поле общее для всех объектов класса.

---

## 15. `static`

**Определение:**

`static` — ключевое слово, которое делает поле или метод принадлежащим классу, а не конкретному объекту.

**Пример:**

```java
public class Singer {
    public static int maxRating = 0;
}
```

**Важно:**

К статическому полю обычно обращаются через имя класса:

```java
Singer.maxRating
```

---

## 16. Глобальная переменная

**Определение:**

Глобальная переменная — это переменная, доступная из разных частей программы.

**Пример через статическое поле:**

```java
public class Singer {
    public static int maxRating = 0;
}
```

**Важно:**

В Java нет классических глобальных переменных как в некоторых языках, но статические поля могут использоваться похожим образом.

---

## 17. Метод класса

**Определение:**

Метод класса — это блок кода внутри класса, который описывает действие или поведение объекта.

**Пример:**

```java
public class Singer {
    public String name;

    public void sing(String verse) {
        System.out.println("Я, " + name + ", пою тебе: " + verse);
    }
}
```

**Важно:**

Если поля описывают, что объект хранит, то методы описывают, что объект умеет делать.

---

## 18. Поведение объекта

**Определение:**

Поведение объекта — это действия, которые объект может выполнять с помощью методов.

**Пример:**

```java
Singer singer = new Singer();

singer.name = "Petya";
singer.sing("Good morning");
```

Здесь поведение объекта — выполнение метода `sing()`.

---

## 19. Сигнатура метода

**Определение:**

Сигнатура метода — это имя метода и список его параметров.

**Пример:**

```java
public void sing(String verse) {
    System.out.println(verse);
}
```

Сигнатура метода:

```java
sing(String verse)
```

**Важно:**

Тип возвращаемого значения не входит в сигнатуру метода.

---

## 20. Тип возвращаемого значения

**Определение:**

Тип возвращаемого значения показывает, какой тип данных метод вернёт после выполнения.

**Пример:**

```java
public boolean isTooYoung() {
    return age < 10;
}
```

В этом примере метод возвращает значение типа `boolean`.

---

## 21. `void`

**Определение:**

`void` — ключевое слово, которое означает, что метод ничего не возвращает.

**Пример:**

```java
public void sing(String verse) {
    System.out.println(verse);
}
```

**Важно:**

Метод с `void` может выполнять действия, но не возвращает результат вызывающему коду.

---

## 22. Имя метода

**Определение:**

Имя метода — это название, по которому метод вызывается в программе.

**Пример:**

```java
public void sing(String verse) {
    System.out.println(verse);
}
```

В этом примере имя метода — `sing`.

**Важно:**

Имя метода должно описывать действие, которое метод выполняет.

---

## 23. Параметр метода

**Определение:**

Параметр метода — это переменная, указанная в круглых скобках при объявлении метода.

**Пример:**

```java
public void sing(String verse) {
    System.out.println(verse);
}
```

В этом примере `verse` — параметр метода.

---

## 24. Аргумент метода

**Определение:**

Аргумент метода — это конкретное значение, которое передаётся в метод при его вызове.

**Пример:**

```java
singer.sing("Good morning");
```

В этом примере `"Good morning"` — аргумент метода.

**Важно:**

Параметр находится в объявлении метода, а аргумент передаётся при вызове метода.

---

## 25. Тело метода

**Определение:**

Тело метода — это код внутри фигурных скобок метода.

**Пример:**

```java
public void sing(String verse) {
    System.out.println("Я пою: " + verse);
}
```

В этом примере тело метода:

```java
System.out.println("Я пою: " + verse);
```

---

## 26. `return`

**Определение:**

`return` — оператор, который завершает выполнение метода и возвращает значение из метода.

**Пример:**

```java
public boolean isTooYoung() {
    return age < 10;
}
```

**Важно:**

Если метод не `void`, он должен вернуть значение указанного типа.

---

## 27. Метод `isTooYoung()`

**Определение:**

`isTooYoung()` — пример метода, который проверяет состояние объекта и возвращает логический результат.

**Пример:**

```java
public boolean isTooYoung() {
    return age < 10;
}
```

**Важно:**

Методы, которые возвращают `boolean`, часто называют в форме вопроса: `isTooYoung`, `hasAccess`, `canDrive`.

---

## 28. Конструктор

**Определение:**

Конструктор — это специальный метод класса, который вызывается при создании объекта и задаёт начальное состояние объекта.

**Пример:**

```java
public class Singer {
    public String name;
    public int age;
    public int rating;

    public Singer(String name, int age, int rating) {
        this.name = name;
        this.age = age;
        this.rating = rating;
    }
}
```

**Важно:**

Конструктор не имеет типа возвращаемого значения, даже `void`.

---

## 29. Конструктор по умолчанию

**Определение:**

Конструктор по умолчанию — это конструктор без параметров, который Java создаёт автоматически, если в классе не объявлен ни один конструктор.

**Пример:**

```java
public class Singer {
    public String name;
    public int age;
}
```

Такой класс можно создать так:

```java
Singer singer = new Singer();
```

**Важно:**

Если ты сам написал хотя бы один конструктор, Java уже не добавляет конструктор по умолчанию автоматически.

---

## 30. Оператор `new`

**Определение:**

`new` — оператор, который создаёт новый объект в памяти и вызывает конструктор класса.

**Пример:**

```java
Singer singer = new Singer();
```

**Важно:**

После `new` вызывается конструктор:

```java
new Singer()
```

---

## 31. Инициализация объекта

**Определение:**

Инициализация объекта — это задание начальных значений полям объекта при его создании.

**Пример:**

```java
Singer singer = new Singer("Petya", 8, 3);
```

**Важно:**

Обычно начальное состояние объекта задают через конструктор, а не через ручное присваивание полям после создания объекта.

---

## 32. `this`

**Определение:**

`this` — ключевое слово, которое указывает на текущий объект.

**Пример:**

```java
public Singer(String name, int age, int rating) {
    this.name = name;
    this.age = age;
    this.rating = rating;
}
```

**Важно:**

`this.name` означает поле объекта, а `name` без `this` в данном примере означает параметр конструктора.

---

## 33. Перегрузка конструкторов

**Определение:**

Перегрузка конструкторов — это создание нескольких конструкторов в одном классе с разным набором параметров.

**Пример:**

```java
public class Singer {
    public String name;
    public int age;
    public int rating;

    public Singer(String name, int age, int rating) {
        this.name = name;
        this.age = age;
        this.rating = rating;
    }

    public Singer(String name, int age) {
        this(name, age, 3);
    }
}
```

**Важно:**

Java выбирает подходящий конструктор по количеству, порядку и типам переданных аргументов.

---

## 34. Вызов одного конструктора из другого

**Определение:**

Один конструктор может вызвать другой конструктор того же класса с помощью `this(...)`.

**Пример:**

```java
public Singer(String name, int age) {
    this(name, age, 3);
}
```

**Важно:**

Вызов `this(...)` должен быть первой строкой в конструкторе.

---

## 35. `Math.max()`

**Определение:**

`Math.max()` — метод, который возвращает большее из двух переданных чисел.

**Пример:**

```java
int max = Math.max(10, 25);

System.out.println(max); // 25
```

**Пример в классе:**

```java
maxRating = Math.max(maxRating, rating);
```

---

## 36. Инкапсуляция

**Определение:**

Инкапсуляция — это принцип ООП, при котором внутреннее состояние объекта скрывается от прямого доступа извне, а работа с ним происходит через методы.

**Пример:**

```java
public class Singer {
    private String name;

    public String getName() {
        return name;
    }
}
```

**Важно:**

В презентации поля показаны как `public`, но в реальном продакшен-коде поля обычно делают `private`, чтобы защитить состояние объекта от неконтролируемого изменения.

---

## 37. `public`

**Определение:**

`public` — модификатор доступа, который делает класс, поле, метод или конструктор доступным из других частей программы.

**Пример:**

```java
public class Singer {
    public String name;

    public void sing(String verse) {
        System.out.println(verse);
    }
}
```

**Важно:**

Не всё стоит делать `public`. Поля объектов чаще делают `private`, а наружу дают методы для работы с ними.

---

## 38. `private`

**Определение:**

`private` — модификатор доступа, который делает поле, метод или конструктор доступным только внутри текущего класса.

**Пример:**

```java
public class Singer {
    private String name;
    private int age;
}
```

**Важно:**

`private` помогает защитить объект от неправильного использования извне.

---

## 39. Геттер

**Определение:**

Геттер — это метод, который возвращает значение приватного поля.

**Пример:**

```java
public class Singer {
    private String name;

    public String getName() {
        return name;
    }
}
```

---

## 40. Сеттер

**Определение:**

Сеттер — это метод, который изменяет значение приватного поля.

**Пример:**

```java
public class Singer {
    private int rating;

    public void setRating(int rating) {
        this.rating = rating;
    }
}
```

**Важно:**

В сеттере можно добавить проверку перед изменением поля.

**Пример:**

```java
public void setRating(int rating) {
    if (rating < 1 || rating > 5) {
        throw new IllegalArgumentException("Рейтинг должен быть от 1 до 5");
    }

    this.rating = rating;
}
```
