# Словарь Java — Тема 6. Структура класса

# Общая архитектура

## 1. Парадигма программирования (Programming Paradigm)

**Определение:**
Подход к построению программы. 

Основные:

### Императивная

Программа = последовательность команд.

```text
Сделай шаг 1
Сделай шаг 2
Сделай шаг 3
```

---

### Функциональная

Программа = вычисления через функции.

---

### ООП (Объектно-ориентированное программирование)

Программа = взаимодействующие объекты.

Java в основном использует именно ООП.

---

# Класс и объект

## 2. Класс (Class)

**Определение:**
Шаблон (чертёж), по которому создаются объекты. 

Пример:

```java
class Singer {

}
```

Класс ничего не хранит сам по себе — он описывает устройство будущих объектов.

---

## 3. Объект (Object)

**Определение:**
Конкретный экземпляр класса.

Пример:

```java
Singer singer = new Singer();
```

Класс:

```text
Singer
```

Объект:

```text
singer
```

---

## 4. Экземпляр класса (Instance)

**Определение:**
Другое название объекта.

```java
Singer singer = new Singer();
```

`singer` — экземпляр класса.

---

# Поля

## 5. Поле (Field)

**Определение:**
Переменная внутри класса, которая хранит состояние объекта. 

Пример:

```java
class Singer {

    String name;

    int age;

}
```

---

## 6. Состояние объекта (State)

**Определение:**
Текущие значения всех полей объекта.

Пример:

```java
Singer singer = new Singer();

singer.name = "Петя";
singer.age = 8;
```

Состояние:

```text
name = Петя
age = 8
```

---

## 7. Нестатическое поле (Instance Field)

**Определение:**
Поле принадлежит конкретному объекту. 

Пример:

```java
singer.name
```

У каждого объекта своё значение.

---

## 8. Статическое поле (`static field`)

**Определение:**
Поле принадлежит всему классу, а не отдельному объекту. 

Пример:

```java
class Singer {

    static int maxRating;

}
```

Использование:

```java
Singer.maxRating = 10;
```

---

## 9. Ключевое слово `static`

**Определение:**
Делает поле или метод общим для всех объектов.

Запомнить:

```text
обычное поле → у объекта

static → у класса
```

---

# Методы

## 10. Метод (Method)

**Определение:**
Функция внутри класса, описывающая поведение объекта. 

Пример:

```java
void sing() {

}
```

---

## 11. Поведение объекта (Behavior)

**Определение:**
Набор действий, которые объект умеет выполнять.

Пример:

```java
singer.sing();
```

---

## 12. Сигнатура метода (Method Signature)

**Определение:**
Описание метода через:

```text
имя
+
параметры
```

Пример:

```java
sing(String verse)
```

---

## 13. Возвращаемый тип (Return Type)

**Определение:**
Тип значения, которое возвращает метод.

Примеры:

```java
void
```

ничего не возвращает

```java
boolean
```

возвращает true/false

---

## 14. `void`

**Определение:**
Специальный тип — метод ничего не возвращает.

Пример:

```java
void print()
```

---

## 15. Параметр метода (Parameter)

**Определение:**
Входные данные метода.

Пример:

```java
void sing(String text)
```

Параметр:

```text
text
```

---

## 16. Аргумент метода (Argument)

**Определение:**
Конкретное значение, которое передали методу.

Пример:

```java
sing("Hello")
```

Аргумент:

```text
"Hello"
```

---

## 17. `return`

**Определение:**
Оператор завершения метода и возврата значения.

Пример:

```java
return true;
```

---

# Конструкторы

## 18. Конструктор (Constructor)

**Определение:**
Специальный метод создания объекта. 

Пример:

```java
public Singer() {

}
```

Особенности:

* имя = имя класса;
* нет возвращаемого типа.

---

## 19. Инициализация (Initialization)

**Определение:**
Заполнение объекта начальными значениями.

Пример:

```java
new Singer("Петя", 8)
```

---

## 20. Конструктор по умолчанию (Default Constructor)

**Определение:**
Конструктор без параметров, который Java создаёт автоматически. 

Пример:

```java
Singer()
```

---

## 21. Перегрузка конструктора (Constructor Overloading)

**Определение:**
Создание нескольких конструкторов с разными параметрами. 

Пример:

```java
Singer()

Singer(String name)

Singer(String name, int age)
```

---

## 22. `this`

**Определение:**
Ссылка на текущий объект. 

Пример:

```java
this.name = name;
```

Что означает:

```text
поле объекта = параметр метода
```

---

## 23. Вызов конструктора через `this()`

**Определение:**
Вызов одного конструктора из другого.

Пример:

```java
this(name, age, 3);
```

---

# Полезное из темы

## 24. Инкапсуляция (добавляю сверх курса)

**Определение:**
Сокрытие внутреннего устройства объекта.

Обычно:

```java
private
+
getter
+
setter
```

Потом отдельно будем изучать.

---

## 25. `Math.max()`

**Определение:**
Метод поиска максимального значения.

Пример:

```java
Math.max(5, 10)
```

Результат:

```text
10
```
