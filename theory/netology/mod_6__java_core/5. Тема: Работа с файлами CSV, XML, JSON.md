# Тема: Работа с файлами CSV, XML, JSON

## CSV

**Определение:**

`CSV` — это текстовый формат хранения табличных данных.

CSV расшифровывается как `Comma-Separated Values`, то есть «значения, разделённые запятыми».

Обычно каждая строка CSV-файла — это одна запись, а значения внутри строки разделяются специальным символом-разделителем.

CSV часто используют для:

* экспорта данных;
* импорта данных;
* обмена таблицами между программами;
* выгрузки отчётов.

**Пример:**

```java
String csvLine = "1,David,Miller,Australia,30";

String[] values = csvLine.split(",");

System.out.println(values[0]); // 1
System.out.println(values[1]); // David
```

---

## Разделитель CSV

**Определение:**

Разделитель CSV — это символ, который отделяет одно значение от другого.

По умолчанию в CSV часто используется запятая, но могут быть и другие разделители:

* `,`
* `;`
* `|`
* `\t`

Важно: если CSV-файл использует нестандартный разделитель, обычный `split(",")` уже не подойдёт.

**Пример:**

```java
String line = "1|David|Miller|Australia|30";

String[] values = line.split("\\|");

System.out.println(values[1]); // David
```

## OpenCSV

**Определение:**

`OpenCSV` — это библиотека для работы с CSV-файлами в Java.

Java не предоставляет удобного встроенного инструмента для полноценной работы с CSV, поэтому обычно используют сторонние библиотеки.

OpenCSV позволяет:

* читать CSV-файлы;
* записывать CSV-файлы;
* настраивать разделители;
* преобразовывать CSV-строки в Java-объекты;
* записывать Java-объекты в CSV.

**Пример:**

```java
try (CSVReader reader = new CSVReader(new FileReader("staff.csv"))) {
    String[] line;

    while ((line = reader.readNext()) != null) {
        System.out.println(Arrays.toString(line));
    }
} catch (IOException | CsvValidationException exception) {
    exception.printStackTrace();
}
```

---

## CSVWriter

**Определение:**

`CSVWriter` — это класс библиотеки OpenCSV, который используется для записи данных в CSV-файл.

Он умеет корректно записывать массивы строк в CSV-формат.

**Пример:**

```java
String[] employee = {"1", "David", "Miller", "Australia", "30"};

try (CSVWriter writer = new CSVWriter(new FileWriter("staff.csv"))) {
    writer.writeNext(employee);
} catch (IOException exception) {
    exception.printStackTrace();
}
```

---

## writeNext()

**Определение:**

`writeNext()` — это метод класса `CSVWriter`, который записывает одну строку данных в CSV-файл.

Обычно в него передают массив строк `String[]`.

Каждый элемент массива становится отдельной колонкой в CSV.

**Пример:**

```java
String[] row = {"1", "David", "Miller"};

try (CSVWriter writer = new CSVWriter(new FileWriter("staff.csv"))) {
    writer.writeNext(row);
} catch (IOException exception) {
    exception.printStackTrace();
}
```

## CSVReader

**Определение:**

`CSVReader` — это класс библиотеки OpenCSV, который используется для чтения CSV-файлов.

Он читает файл построчно и возвращает каждую строку как массив строк `String[]`.

**Пример:**

```java
try (CSVReader reader = new CSVReader(new FileReader("staff.csv"))) {
    String[] row = reader.readNext();

    System.out.println(Arrays.toString(row));
} catch (IOException | CsvValidationException exception) {
    exception.printStackTrace();
}
```

---

## readNext()

**Определение:**

`readNext()` — это метод класса `CSVReader`, который читает следующую строку CSV-файла.

Метод возвращает массив `String[]`.

Если строки закончились, метод возвращает `null`.

**Пример:**

```java
try (CSVReader reader = new CSVReader(new FileReader("staff.csv"))) {
    String[] row;

    while ((row = reader.readNext()) != null) {
        System.out.println(row[0]);
    }
} catch (IOException | CsvValidationException exception) {
    exception.printStackTrace();
}
```

---

## readAll()

**Определение:**

`readAll()` — это метод класса `CSVReader`, который считывает все строки CSV-файла сразу.

Метод возвращает список массивов:

```java
List<String[]>
```

Использовать `readAll()` удобно для небольших файлов. Для больших файлов лучше читать построчно через `readNext()`, чтобы не загружать всё в память сразу.

**Пример:**

```java
try (CSVReader reader = new CSVReader(new FileReader("staff.csv"))) {
    List<String[]> rows = reader.readAll();

    for (String[] row : rows) {
        System.out.println(Arrays.toString(row));
    }
} catch (IOException | CsvException exception) {
    exception.printStackTrace();
}
```

## CSVParser

**Определение:**

`CSVParser` — это класс OpenCSV, который отвечает за разбор CSV-строки на отдельные значения.

Он полезен, когда нужно настроить нестандартные правила чтения CSV, например другой разделитель.

**Пример:**

```java
CSVParser parser = new CSVParserBuilder()
        .withSeparator('|')
        .build();

try (CSVReader reader = new CSVReaderBuilder(new FileReader("staff.csv"))
        .withCSVParser(parser)
        .build()) {

    String[] row;

    while ((row = reader.readNext()) != null) {
        System.out.println(Arrays.toString(row));
    }
} catch (IOException | CsvValidationException exception) {
    exception.printStackTrace();
}
```

## CSVReaderBuilder

**Определение:**

`CSVReaderBuilder` — это класс OpenCSV, который помогает гибко создать `CSVReader`.

Через него можно подключить собственный `CSVParser`, например с нестандартным разделителем.

**Пример:**

```java
CSVParser parser = new CSVParserBuilder()

        .build();

CSVReader reader = new CSVReaderBuilder(new FileReader("staff.csv"))
        .withCSVParser(parser)
        .build();
```

## CSVParserBuilder

**Определение:**

`CSVParserBuilder` — это класс OpenCSV, который используется для настройки и создания `CSVParser`.

Например, через него можно указать, какой символ будет разделителем значений.

**Пример:**

```java
CSVParser parser = new CSVParserBuilder()

        .build();
```

## CsvToBean

**Определение:**

`CsvToBean` — это инструмент OpenCSV, который преобразует строки CSV-файла в Java-объекты.

Например, CSV-строку:

```text
1,David,Miller,Australia,30
```

можно превратить в объект класса `Employee`.

Это удобно, когда нужно работать не с массивами строк, а с нормальными объектами.

**Пример:**

```java
try (CSVReader reader = new CSVReader(new FileReader("staff.csv"))) {
    ColumnPositionMappingStrategy<Employee> strategy =
            new ColumnPositionMappingStrategy<>();

    strategy.setType(Employee.class);
    strategy.setColumnMapping("id", "firstName", "lastName", "country", "age");

    CsvToBean<Employee> csvToBean = new CsvToBeanBuilder<Employee>(reader)
            .withMappingStrategy(strategy)
            .build();

    List<Employee> employees = csvToBean.parse();

    employees.forEach(System.out::println);
} catch (IOException exception) {
    exception.printStackTrace();
}
```

---

## CsvToBeanBuilder

**Определение:**

`CsvToBeanBuilder` — это builder-класс, который помогает создать объект `CsvToBean`.

Через него можно указать стратегию сопоставления CSV-колонок с полями Java-класса.

**Пример:**

```java
CsvToBean<Employee> csvToBean = new CsvToBeanBuilder<Employee>(reader)
        .withMappingStrategy(strategy)
        .build();
```

---

## ColumnPositionMappingStrategy

**Определение:**

`ColumnPositionMappingStrategy` — это стратегия OpenCSV, которая сопоставляет колонки CSV-файла с полями Java-класса по позиции.

Например:

```text
1,David,Miller,Australia,30
```

Можно сопоставить так:

```text
id, firstName, lastName, country, age
```

То есть первая колонка попадёт в `id`, вторая — в `firstName`, третья — в `lastName`.

**Пример:**

```java
ColumnPositionMappingStrategy<Employee> strategy =
        new ColumnPositionMappingStrategy<>();

strategy.setType(Employee.class);
strategy.setColumnMapping("id", "firstName", "lastName", "country", "age");
```

## StatefulBeanToCsv

**Определение:**

`StatefulBeanToCsv` — это класс OpenCSV, который записывает Java-объекты в CSV-файл.

Он выполняет обратную операцию по отношению к `CsvToBean`.

`CsvToBean` читает CSV и создаёт объекты.

`StatefulBeanToCsv` берёт объекты и записывает их в CSV.

**Пример:**

```java
List<Employee> employees = List.of(
        new Employee(1, "Nikita", "Shumskii", "Russia", 25),
        new Employee(2, "Pavel", "Shramko", "Russia", 23)
);

try (Writer writer = new FileWriter("staff.csv")) {
    StatefulBeanToCsv<Employee> beanToCsv =
            new StatefulBeanToCsvBuilder<Employee>(writer).build();

    beanToCsv.write(employees);
} catch (IOException | CsvDataTypeMismatchException | CsvRequiredFieldEmptyException exception) {
    exception.printStackTrace();
}
```

## XML

**Определение:**

`XML` — это текстовый формат хранения и передачи данных с помощью тегов.

XML расшифровывается как `eXtensible Markup Language`.

Данные в XML представлены в виде дерева: один корневой элемент, внутри него дочерние элементы, внутри них другие элементы.

XML часто используют для:

* конфигураций;
* обмена данными;
* описания сложных структур;
* хранения иерархических данных.

**Пример:**

```java
String xml = """
        <employee id="1">
            <firstName>Ivan</firstName>
            <lastName>Ivanov</lastName>
        </employee>
        """;

System.out.println(xml);
```

---

## XML-тег

**Определение:**

XML-тег — это элемент разметки, с помощью которого описываются данные.

У открывающего тега должен быть закрывающий тег.

Например:

```xml
<name>Ivan</name>
```

Здесь:

* `<name>` — открывающий тег;
* `Ivan` — содержимое;
* `</name>` — закрывающий тег.

**Пример:**

```java
String nameTag = "<name>Ivan</name>";

System.out.println(nameTag);
```

---

## XML-атрибут

**Определение:**

XML-атрибут — это дополнительная информация внутри открывающего тега.

Атрибуты записываются в формате:

```xml
id="1"
```

Значения атрибутов обязательно заключаются в кавычки.

**Пример:**

```java
String employee = "<employee id=\"1\" firstName=\"Ivan\" />";

System.out.println(employee);
```

---

## Корневой элемент XML

**Определение:**

Корневой элемент XML — это главный элемент документа, внутри которого находятся остальные элементы.

У XML-документа должен быть один корневой элемент.

**Пример:**

```java
String xml = """
        <root>
            <employee id="1">Ivan</employee>
        </root>
        """;

System.out.println(xml);
```

## DOM

**Определение:**

`DOM`, или `Document Object Model`, — это объектная модель XML-документа.

DOM загружает XML-документ в память и представляет его как дерево объектов.

В этом дереве:

* весь документ — это `Document`;
* каждый тег — это `Node`;
* конкретный XML-элемент — это `Element`.

DOM удобен, когда нужно свободно перемещаться по XML-документу, читать узлы, атрибуты, изменять элементы или создавать новый XML.

**Пример:**

```java
DocumentBuilderFactory factory = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = factory.newDocumentBuilder();

Document document = builder.parse(new File("company.xml"));

System.out.println(document.getDocumentElement().getNodeName());
```

---

## Document

**Определение:**

`Document` — это объектное представление всего XML-документа в DOM.

Он находится на вершине DOM-дерева.

Через `Document` можно:

* получить корневой элемент;
* создавать новые элементы;
* добавлять узлы;
* изменять XML-структуру.

**Пример:**

```java
DocumentBuilderFactory factory = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = factory.newDocumentBuilder();

Document document = builder.newDocument();

Element root = document.createElement("root");
document.appendChild(root);
```

---

## Node

**Определение:**

`Node` — это узел DOM-дерева.

В XML-документе узлом может быть:

* элемент;
* текст;
* атрибут;
* комментарий;
* другой фрагмент документа.

При обходе XML-документа часто работают именно с объектами `Node`.

**Пример:**

```java
Node root = document.getDocumentElement();

System.out.println(root.getNodeName());
```

---

## Element

**Определение:**

`Element` — это конкретный XML-элемент в DOM.

Обычно `Element` соответствует тегу XML.

Через `Element` можно читать и изменять:

* имя тега;
* атрибуты;
* дочерние элементы;
* текстовое содержимое.

**Пример:**

```java
Element employee = document.createElement("employee");

employee.setAttribute("id", "1");
employee.setAttribute("firstName", "Ivan");
```

---

## NodeList

**Определение:**

`NodeList` — это коллекция узлов DOM.

Она часто возвращается методами:

* `getChildNodes()`;
* `getElementsByTagName()`.

По `NodeList` обычно проходят циклом по индексам.

**Пример:**

```java
NodeList employees = document.getElementsByTagName("employee");

for (int i = 0; i < employees.getLength(); i++) {
    Node employee = employees.item(i);
    System.out.println(employee.getNodeName());
}
```

---

## NamedNodeMap

**Определение:**

`NamedNodeMap` — это коллекция атрибутов XML-узла.

Она возвращается методом `getAttributes()`.

Через `NamedNodeMap` можно перебрать все атрибуты элемента.

**Пример:**

```java
NamedNodeMap attributes = employee.getAttributes();

for (int i = 0; i < attributes.getLength(); i++) {
    Node attribute = attributes.item(i);

    System.out.println(attribute.getNodeName() + " = " + attribute.getNodeValue());
}
```

## getChildNodes()

**Определение:**

`getChildNodes()` — это метод, который возвращает дочерние узлы текущего узла.

Важно: DOM может считать переносы строк и пробелы отдельными текстовыми узлами. Поэтому при обходе часто проверяют тип узла через `getNodeType()`.

**Пример:**

```java
NodeList children = root.getChildNodes();

for (int i = 0; i < children.getLength(); i++) {
    Node node = children.item(i);

    if (node.getNodeType() == Node.ELEMENT_NODE) {
        System.out.println(node.getNodeName());
    }
}
```

## getNodeType()

**Определение:**

`getNodeType()` — это метод `Node`, который возвращает тип узла.

Например, узел может быть:

* элементом;
* текстом;
* атрибутом;
* комментарием.

При работе с XML часто проверяют:

```java
Node.ELEMENT_NODE
```

Так можно отфильтровать именно XML-элементы и не обрабатывать лишние текстовые узлы.

**Пример:**

```java
if (node.getNodeType() == Node.ELEMENT_NODE) {
    Element element = (Element) node;

    System.out.println(element.getNodeName());
}
```

## JSON

**Определение:**

`JSON` — это текстовый формат обмена данными.

JSON расшифровывается как `JavaScript Object Notation`.

Он часто используется для передачи данных между клиентом и сервером.

Например, сервер может отправить клиенту информацию о пользователе в JSON-формате.

**Пример:**

```java
String json = """
        {
            "firstName": "Ivan",
            "lastName": "Ivanov",
            "age": 30
        }
        """;

System.out.println(json);
```

---

## JSON-объект

**Определение:**

JSON-объект — это структура данных в формате JSON, которая начинается с `{` и заканчивается `}`.

Внутри объекта хранятся пары:

```text
ключ: значение
```

**Пример:**

```java
String json = """
        {
            "city": "New York",
            "country": "United States"
        }
        """;

System.out.println(json);
```

---

## Ключ JSON

**Определение:**

Ключ JSON — это имя значения внутри JSON-объекта.

Ключ всегда записывается в двойных кавычках.

**Пример:**

```java
String json = """
        {
            "firstName": "Ivan"
        }
        """;
```

Здесь `"firstName"` — это ключ.

---

## Значение JSON

**Определение:**

Значение JSON — это данные, которые находятся справа от ключа после двоеточия.

JSON-значением может быть:

* строка;
* число;
* логическое значение;
* `null`;
* объект;
* массив.

**Пример:**

```java
String json = """
        {
            "name": "Ivan",
            "age": 30,
            "active": true,
            "address": null
        }
        """;
```

---

## JSON-массив

**Определение:**

JSON-массив — это список значений в JSON.

Он начинается с `[` и заканчивается `]`.

Массив может содержать строки, числа, объекты и другие значения.

**Пример:**

```java
String json = """
        {
            "phoneNumbers": [
                "812 123-1234",
                "916 123-4567"
            ]
        }
        """;

System.out.println(json);
```

---

## Json Simple

**Определение:**

`Json Simple` — это библиотека для простой работы с JSON в Java.

Она позволяет:

* читать JSON;
* создавать JSON-объекты;
* создавать JSON-массивы;
* записывать JSON в файл.

В современных проектах чаще встречаются `Jackson` или `Gson`, но `Json Simple` полезна для понимания базовой работы с JSON.

**Пример:**

```java
JSONObject object = new JSONObject();

object.put("name", "Ivan");
object.put("age", 30);

System.out.println(object.toJSONString());
```

---

## JSONParser

**Определение:**

`JSONParser` — это класс библиотеки Json Simple, который разбирает JSON-строку или JSON-файл и превращает их в Java-объекты.

Например, JSON-файл можно прочитать и привести к `JSONObject`.

**Пример:**

```java
JSONParser parser = new JSONParser();

try {
    Object object = parser.parse(new FileReader("data.json"));
    JSONObject jsonObject = (JSONObject) object;

    System.out.println(jsonObject);
} catch (IOException | ParseException exception) {
    exception.printStackTrace();
}
```

---

## JSONObject

**Определение:**

`JSONObject` — это Java-представление JSON-объекта.

В Json Simple `JSONObject` хранит пары:

```text
ключ — значение
```

По смыслу он похож на `Map`.

**Пример:**

```java
JSONObject object = new JSONObject();

object.put("firstName", "Ivan");
object.put("lastName", "Ivanov");

System.out.println(object.get("lastName")); // Ivanov
```

---

## JSONArray

**Определение:**

`JSONArray` — это Java-представление JSON-массива.

В Json Simple `JSONArray` хранит список значений.

По смыслу он похож на `List`.

**Пример:**

```java
JSONArray phoneNumbers = new JSONArray();

phoneNumbers.add("812 123-1234");
phoneNumbers.add("916 123-4567");

System.out.println(phoneNumbers);
```

## put()

**Определение:**

`put()` — это метод `JSONObject`, который добавляет пару ключ-значение в JSON-объект.

Если ключ уже существует, значение по этому ключу будет заменено.

**Пример:**

```java
JSONObject object = new JSONObject();

object.put("name", "Ivan");
object.put("age", 30);

System.out.println(object);
```

---

## toJSONString()

**Определение:**

`toJSONString()` — это метод, который преобразует JSON-объект или JSON-массив в строку JSON-формата.

После этого строку можно записать в файл.

**Пример:**

```java
JSONObject object = new JSONObject();

object.put("name", "Ivan");

String json = object.toJSONString();

System.out.println(json);
```

## GSON

**Определение:**

`GSON` — это библиотека от Google для работы с JSON в Java.

Она позволяет удобно преобразовывать:

* Java-объекты в JSON;
* JSON в Java-объекты.

Это называется сериализацией и десериализацией JSON.

**Пример:**

```java
Gson gson = new Gson();

Cat cat = new Cat("Murzik", 5);

String json = gson.toJson(cat);

System.out.println(json);
```

---

## GsonBuilder

**Определение:**

`GsonBuilder` — это класс для настройки и создания объекта `Gson`.

С его помощью можно задать дополнительные правила преобразования JSON.

Для простых случаев можно создать обычный `Gson` без настроек.

**Пример:**

```java
GsonBuilder builder = new GsonBuilder();

Gson gson = builder.create();
```

---

## Gson

**Определение:**

`Gson` — это основной класс библиотеки GSON.

Он выполняет преобразование Java-объектов в JSON и JSON обратно в Java-объекты.

Главные методы:

* `toJson()`;
* `fromJson()`.

**Пример:**

```java
Gson gson = new Gson();

String json = gson.toJson(new Cat("Murzik", 9));

System.out.println(json);
```

---

## toJson()

**Определение:**

`toJson()` — это метод класса `Gson`, который преобразует Java-объект в JSON-строку.

Это удобно, когда нужно отправить объект на сервер, сохранить его в файл или вывести в JSON-формате.

**Пример:**

```java
Cat cat = new Cat("Matroskin", 5);

Gson gson = new Gson();

String json = gson.toJson(cat);

System.out.println(json);
```

---

## fromJson()

**Определение:**

`fromJson()` — это метод класса `Gson`, который преобразует JSON-строку в Java-объект.

Это удобно, когда приложение получает JSON от сервера или читает JSON из файла.

**Пример:**

```java
String json = """
        {
            "name": "Murzik",
            "age": 9
        }
        """;

Gson gson = new Gson();

Cat cat = gson.fromJson(json, Cat.class);

System.out.println(cat.getName());
```

---

## Парсинг

**Определение:**

Парсинг — это процесс разбора текста по правилам определённого формата.

Например:

* парсинг CSV — разбор строки на колонки;
* парсинг XML — разбор тегов и построение DOM-дерева;
* парсинг JSON — разбор JSON-строки в объект.

По-простому: программа берёт текст и превращает его в структуру, с которой удобно работать в коде.

**Пример:**

```java
String line = "1,David,Miller";

String[] values = line.split(",");

System.out.println(values[1]); // David
```

---

## Сериализация JSON

**Определение:**

Сериализация JSON — это преобразование Java-объекта в JSON-строку.

Например, объект `Cat` можно превратить в строку:

```json
{"name":"Murzik","age":9}
```

Это удобно для отправки данных по сети или записи в файл.

**Пример:**

```java
Cat cat = new Cat("Murzik", 9);

Gson gson = new Gson();

String json = gson.toJson(cat);

System.out.println(json);
```

---

## Десериализация JSON

**Определение:**

Десериализация JSON — это преобразование JSON-строки обратно в Java-объект.

Например, строку:

```json
{"name":"Murzik","age":9}
```

можно превратить в объект класса `Cat`.

**Пример:**

```java
String json = "{\"name\":\"Murzik\",\"age\":9}";

Gson gson = new Gson();

Cat cat = gson.fromJson(json, Cat.class);

System.out.println(cat.getName());
```
