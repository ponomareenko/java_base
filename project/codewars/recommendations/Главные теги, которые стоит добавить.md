# Главные теги, которые стоит добавить

### 1. Strings

**Строки**

Очень важный тег. В Java строки встречаются постоянно: парсинг, валидация, форматирование, обработка данных.

Что прокачаешь:

```java
charAt()
substring()
split()
replace()
StringBuilder
```

Ставь обязательно.

---

### 2. Regular Expressions

**Регулярные выражения**

Полезно для задач на проверку формата: email, пароль, числа, шаблоны.

Пример навыка:

```java
str.matches("\\d+")
```

Для Junior это прям полезная база.

---

### 3. Sets

**Множества**

Очень важная тема после массивов. Помогает решать задачи на уникальность, дубликаты, пересечения.

Java-классы:

```java
HashSet
TreeSet
LinkedHashSet
```

Хороший тег для перехода от «просто массивов» к коллекциям.

---

### 4. Sorting

**Сортировка**

Да, часто будет пересекаться с массивами, но это уже другой тип мышления.

Прокачаешь:

```java
Arrays.sort()
Collections.sort()
Comparator
```

Особенно полезно для задач, где нужно отсортировать объекты или строки.

---

### 5. Recursion

**Рекурсия**

Очень полезно для развития алгоритмического мышления.

Примеры задач:

* сумма цифр рекурсивно;
* обход дерева;
* вложенные структуры;
* факториал;
* поиск вариантов.

Но не залипай только в неё, рекурсия любит превращать мозг в лапшу.

---

### 6. Data Structures

**Структуры данных**

Один из самых полезных тегов.

Там могут попадаться:

```java
Stack
Queue
Map
Set
List
LinkedList
Tree
```

Это уже ближе к реальному программированию, а не просто «покрути массив туда-сюда».

---

### 7. Object-oriented Programming

**ООП**

Очень важный тег именно для Java.

Прокачаешь:

* классы;
* объекты;
* наследование;
* интерфейсы;
* инкапсуляцию;
* полиморфизм.

Если хочешь становиться Java-разработчиком, этот тег нужен обязательно.

---

### 8. Streams

**Stream API**

Это уже Java-специфичная полезная тема.

Пример:

```java
list.stream()
    .filter(x -> x > 0)
    .map(x -> x * 2)
    .toList();
```

На собеседованиях и в продакшене Stream API встречается часто.

---

### 9. Number Theory

**Теория чисел**

Хороший тег для задач с числами.

Будут темы:

* простые числа;
* делители;
* НОД;
* НОК;
* цифровой корень;
* разложение на множители.

Очень полезно для Codewars.

---

### 10. Parsing

**Парсинг**

Полезно для задач, где нужно разобрать строку по правилам.

Например:

```java
"12 + 7".split(" ")
```

Или более сложные задачи: разобрать выражение, команду, дату, формат.

---

## Мой рекомендуемый набор фильтров

Для твоего уровня сейчас я бы поставил такие теги:

```text
Strings
Regular Expressions
Sets
Sorting
Recursion
Data Structures
Object-oriented Programming
Streams
Number Theory
Parsing
```

Это хороший баланс: и Java, и алгоритмы, и коллекции, и мышление.

---

## Второй уровень — когда станет легче

Когда эти темы пойдут нормально, добавляй:

```text
Linked Lists
Queues
Trees
Binary Trees
Graphs
Dynamic Programming
Memoization
Performance
```

Это уже ближе к Middle-алгоритмам.

---

## Пока лучше не трогать

На текущем этапе я бы не тратил много времени на:

```text
Monads
Esoteric Languages
ASCII Art
Riddles
Puzzles
Cryptography
Data Science
Linear Algebra
Concurrency
Reflection
```

Не потому что они плохие, а потому что сейчас они дадут меньше пользы для Java Junior. Особенно `Monads` — это портал в лес, где деревья смотрят на тебя с осуждением.

---

## Как я бы тебе распределил практику

На неделю:

```text
2 задачи — Strings
2 задачи — Sets / Data Structures
1 задача — Recursion
1 задача — Number Theory
1 задача — OOP или Streams
```

Так ты не будешь застревать только в массивах, но и не уйдёшь в хаос.
