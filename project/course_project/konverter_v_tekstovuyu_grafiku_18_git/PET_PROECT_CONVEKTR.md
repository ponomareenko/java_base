# Pet project: конвертер изображений в текстовую графику

## Краткое описание

Конвертер изображений в текстовую графику - это Java-приложение, которое загружает изображение по URL, масштабирует его, переводит в черно-белый формат и преобразует каждый пиксель в текстовый символ в зависимости от яркости.

Проект выполнен как первый курсовой проект во время обучения в Нетологии. На реализацию, отладку и доведение решения до рабочего состояния ушло около 2 недель без учета времени проверки преподавателями.

Главная идея проекта - показать, как с помощью базовых возможностей Java можно обработать изображение и представить его в виде ASCII/текстовой графики.

## Демонстрация результата

На вход приложение получает ссылку на изображение:

```text
https://raw.githubusercontent.com/netology-code/java-diplom/main/pics/simple-test.png
```

На выходе формируется многострочная строка, где темные участки изображения заменяются более "плотными" символами, а светлые - более "легкими":

```text
##$$@@%%**++--''
##$$@@%%**++--''
...
```

Результат можно получить двумя способами:

- через локальный веб-интерфейс по адресу `http://localhost:8888/`;
- через прямой вызов метода `convert(url)` и вывод результата в консоль.

В рамках проекта я реализовал основную бизнес-логику приложения:

Готовая часть проекта уже содержала сервер, интерфейсы и структуру приложения. Моя задача заключалась в том, чтобы написать реализацию по заданным контрактам и сделать так, чтобы сервер мог использовать мой конвертер без изменения своей логики.

## Что делает приложение

Приложение умеет:

1. Загружать изображение по URL.
2. Проверять допустимое соотношение сторон изображения.
3. Масштабировать изображение с сохранением пропорций.
4. Переводить изображение в черно-белый формат.
5. Читать яркость каждого пикселя.
6. Подбирать текстовый символ по степени яркости.
7. Собирать результат в многострочную строку.
8. Возвращать текстовую графику серверу или выводить ее в консоль.

## Архитектура решения

Проект построен вокруг двух основных интерфейсов:

```java
public interface TextGraphicsConverter {
    String convert(String url) throws IOException, BadImageSizeException;

    void setMaxWidth(int width);

    void setMaxHeight(int height);

    void setMaxRatio(double maxRatio);

    void setTextColorSchema(TextColorSchema schema);
}
```

```java
public interface TextColorSchema {
    char convert(int color);
}
```

Такое разделение делает код гибче:

- `TextGraphicsConverter` отвечает за общий процесс конвертации изображения;
- `TextColorSchema` отвечает только за выбор символа по яркости пикселя.

Это хороший пример принципа Single Responsibility Principle: каждый класс отвечает за свою часть логики.

## Основной алгоритм конвертации

Алгоритм в `TextGraphicsConverterPonom` работает по шагам:

1. Изображение загружается из интернета:

```java
BufferedImage img = ImageIO.read(new URL(url));
```

2. Вычисляется соотношение сторон:

```java
double imgRatioHorizon = (double) img.getWidth() / img.getHeight();
double imgRatioVertical = (double) img.getHeight() / img.getWidth();
```

3. Если изображение слишком вытянутое, выбрасывается исключение:

```java
throw new BadImageSizeException(imgRatioHorizon, maxRatio);
```

4. Рассчитывается новый размер изображения с учетом ограничений по ширине и высоте.

5. Изображение масштабируется:

```java
Image scaledImage = img.getScaledInstance(
        newWidth,
        newHeight,
        BufferedImage.SCALE_SMOOTH
);
```

6. Создается черно-белая версия изображения:

```java
BufferedImage bwImg = new BufferedImage(
        newWidth,
        newHeight,
        BufferedImage.TYPE_BYTE_GRAY
);
```

7. Каждый пиксель преобразуется в символ:

```java
int color = bwRaster.getPixel(w, h, new int[3])[0];
char c = schema.convert(color);
```

8. Символы собираются в итоговую строку через `StringBuilder`.

## Цветовая схема

Цветовая схема получает число от `0` до `255`, где:

- `0` - черный цвет;
- `255` - белый цвет.

Для преобразования используется массив символов:

```java
char[] stanChar = {'#', '$', '@', '%', '*', '+', '-', '\''};
```

Чем темнее пиксель, тем более плотный символ используется. Чем светлее пиксель, тем более легкий символ выбирается.

Пример:

```java
return stanChar[(int) Math.floor(color / 256. * stanChar.length)];
```

Такой подход позволяет не писать много `if-else`, а рассчитывать индекс символа математически.

## Обработка ошибок

Для ситуации, когда изображение не подходит по соотношению сторон, используется собственное checked-исключение:

```java
public class BadImageSizeException extends Exception {
    public BadImageSizeException(double ratio, double maxRatio) {
        super("Максимальное соотношение сторон изображения " + maxRatio
                + ", а у этой " + ratio);
    }
}
```

Это важно, потому что ошибка является частью бизнес-логики: приложение не аварийно падает, а сообщает, почему конкретное изображение не может быть обработано.
